# 아시 스킬

첨부 승인 이미지 6종을 원본 그대로 사용합니다. 액티브 아이콘은 웃는 아시가 결승선을 통과하는 최종본입니다. 중앙 연출은 양팔을 머리 뒤로 보내 머리끈을 매는 8프레임입니다.

## 조작과 효과

- 패시브 「마라톤」: 정상적으로 대쉬를 마친 뒤 3초간 발사체 +2, 공격속도 ×1.2(공격 쿨타임 ÷1.2). 재발동하면 3초로 갱신하고 중첩하지 않습니다. 별도의 패시브 쿨타임은 없습니다.
- 액티브 「단거리 경주」: R키 또는 화면 왼쪽 하단 액티브 아이콘 터치. 중앙 반투명 검정 띠에서 연출을 재생하는 동안 전투를 정지합니다. 기본 2초, 데이터의 cutinDuration을 3으로 바꾸면 3초입니다.
- 연출이 끝날 때 12초 강화와 45초 쿨타임이 함께 시작합니다. 발사체 수, 이동속도, 발사체 이동속도 ×2. 공격 빈도 ×2가 아닙니다.
- 동시 발동 시 `(현재 무기 발사체 수 + 마라톤 2개) × 2`. 무기별 추가 발사체와 침술진의 최종 수량에 배율을 적용합니다.
- 강화 수치를 기존 능력치에 저장하거나 빼지 않습니다. 강화 중 획득한 영구 증강은 종료 후에도 유지됩니다. 씬 이동에는 남은 시간이 보존됩니다.
- 사망 시 강화가 정리되고 사용 불가. TAB·일시정지 중 타이머는 정지합니다. 연출 도중 중복 입력과 기존 일시정지 버튼의 재개를 차단합니다.

## 표시

- 메인, 출전 준비, 잠금 해제 캐릭터 상세, TAB 프로필에 패시브/액티브 두 칸. 미구현 캐릭터는 동일한 두 칸에 준비 중으로 표시합니다.
- 인게임 미니맵은 숨기고 TAB 지도를 유지합니다. 왼쪽 아래 83px 수준의 아이콘 두 개. 모바일에서는 이동 스틱 위로 올려 겹치지 않게 합니다.
- 액티브 쿨타임은 검정 반투명 사각 덮개와 가운데 초 단위 숫자. 12시부터 시계방향으로 드러납니다. 아래 민트 막대는 12초 강화 잔여 시간입니다.
- 패시브 아이콘 숫자는 쿨타임이 아니라 3초 강화의 잔여 시간입니다.
- 기존 ApothecaryButtonFeedback을 재사용해 마우스, 터치 눌림, 크기·색 변화와 테두리 빛 효과를 통일합니다.

## 조정 위치

`Assets/Junhan/Resources/AshiSkills.asset`: 지속시간, 쿨타임, 연출 길이, 설명, 아이콘과 애니메이션.

CharacterBlueprint.skills: 캐릭터별 스킬 데이터 자리. 현재 아시만 연결했습니다. 다른 캐릭터의 실제 효과는 각 기획 확정 후 추가합니다.

이미지는 내장 image_gen으로 제작한 승인 원본입니다. Import 설정은 Point, alpha transparency, no mipmaps, uncompressed. 시트는 4×2, 위에서 아래로 재생합니다.

## 검증

`Vampire.Tests.Editor.AshiSkillPlayTests.Run`은 실제 메인·준비·게임·TAB 화면, R키와 터치 이벤트, 강화 조합, 원복, 씬 전달, 사망, 2초/3초 연출, 모바일 배치와 쿨타임 방향을 확인합니다. 화면 증거는 Library/AshiSkillProof에 생성됩니다.

2026-09-22 검증: EditMode 51/51, 스킬 플레이 점검 51건, 기존 UI 흐름 161건 통과. Windows Development 빌드 오류 0건, 실행 파일의 스킬 점검 12건 통과(`-ashiSkillsSmoke`). 모바일은 터치 이벤트와 이동 스틱 위 배치를 시뮬레이션했으며 실기기 검증은 별도입니다.

대물침은 기존 단발을 기준으로 스킬만 적용합니다: 마라톤 3발, 단거리 경주 2발, 동시 활성화 6발. 실제 6발 생성도 점검합니다. 침술진은 기본 원형 발사 수와 추가 발사체를 합친 뒤 액티브 배율을 적용합니다.

전체 회귀 점검 중 기존 Infinite Background.mat의 누락된 머리말·텍스처 참조를 마지막 정상 이력(51e3f4a)에서 복구하고 기존 수치·색상은 보존했습니다. 기존 공격 차단 테스트의 reflection 호출도 현재 선택 인자(rear=false)를 전달하도록 수정했습니다.
