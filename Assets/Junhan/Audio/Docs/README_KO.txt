사운드 추가 리스트 — 확정 항목 우선 제작본
=======================================

구성
- 효과음 33개
- 증강 선택 전용 BGM 1개
- 총 34개

재생 원칙
- 1회: 이벤트 발생 순간 한 번만 재생
- 반복: 발사체 생성·아이템 획득 등 개별 사건마다 한 번
- 루프: 상태가 유지되는 동안 재생하고 종료 즉시 Stop
- 전용 BGM: 현재 BGM Pause → 전용 BGM 재생 → 종료 후 기존 BGM Resume

구현 주의
- exp_pickup은 경험치 획득량과 관계없이 같은 파일을 사용합니다.
- field_event_start는 모든 필드 이벤트에 공통 사용합니다.
- critical_hit은 monster_hit을 대체하지 않고 위에 추가 재생하는 구조가 적합합니다.
- augment_selection_bgm은 증강 선택창이 완전히 나타난 후 루프 재생합니다.
- 이번 묶음은 문서의 '일단 추가 확정' 범위입니다.
- 보스 전체 사운드, 전설 증강별 사운드, 미니스테이지별 세부 기믹음은 후속 범위로 남겼습니다.
