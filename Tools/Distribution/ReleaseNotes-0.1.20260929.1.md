# 24시간의사투 — Windows 테스트 버전

아래 Assets에서 **24tu-Setup-0.1.20260929.1.exe**를 받아 설치하세요. Source code 파일은 게임 설치 파일이 아닙니다.

## 이번 배포

- Unity 없이 실행할 수 있는 Windows x64 설치형 테스트 버전.
- 바탕화면·시작 메뉴 바로가기, Windows 앱 제거 기능.
- 게임/설치 프로그램의 대표 이미지는 혁이 액티브 스킬 아이콘.
- 바로가기의 잘못된 별도 아이콘 경로 문제를 수정하여 게임 실행 파일의 아이콘을 상속하도록 변경.
- 현재 Junhan2의 캐릭터·스킬 및 롤케이크 달팽이/미니 달팽이 콘텐츠 포함.
- 설치 폴더에 플레이 안내와 기존 기반 코드의 라이선스/출처 안내 포함.

## 조작

WASD/방향키 이동, Shift 대시, R 액티브 스킬, E 상호작용, Tab 상태/기록, Esc 뒤로/기록, ZXCV 또는 1234 보유 소모품 사용. 기본 공격은 자동입니다. 전투 중 Insert는 보스 소환 테스트 단축키입니다.

## 저장과 업데이트

기존 로컬 재화·해금·유물 등 영구 성장을 보존합니다. 진행 중인 판은 재개하지 않습니다. Steam/Google 로그인, 클라우드 저장, 자동 업데이트 기능은 아직 없습니다. 다음 버전은 게임 종료 후 새 설치 파일로 업데이트하세요.

코드 서명 전 테스트 배포본입니다. 게임 데이터는 이전 로컬 검증 빌드(게임 코드 기준 902fb27)와 동일하며, 이번 수정은 아이콘 연결/배포 패키지/안내 문서입니다. 다양한 PC 및 장시간 플레이의 추가 QA가 필요합니다.

SHA-256 검증값은 함께 첨부한 `.exe.sha256` 파일에서 확인할 수 있습니다.
