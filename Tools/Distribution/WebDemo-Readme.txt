24시간의사투 — 웹 테스트판

[이 PC에서 바로 실행]
1. 압축파일을 폴더에 모두 풀어 주세요.
2. Launch-WebDemo.cmd를 실행해 주세요.
3. 브라우저가 열리면 로딩 후 게임을 플레이할 수 있습니다.
4. 게임 중에는 함께 열린 실행 창을 유지해 주세요. 창을 닫으면 로컬 서버도 종료됩니다.

index.html을 직접 더블클릭하면 게임이 실행되지 않습니다.
localhost 주소는 현재 PC에서만 열립니다. 지인에게 주소만 보내도 접속되지는 않습니다.

[지인에게 브라우저 링크로 공유하려면]
이 압축파일의 전체 내용을 웹 호스팅에 올려야 합니다.
index.html, Build, StreamingAssets 등 폴더와 파일을 모두 유지해 주세요.
이 안내는 로컬 배포 묶음 기준입니다. 외부 공개 여부와 현재 주소는 배포 담당자에게 확인하세요.
GitHub에는 생성된 게임 빌드나 설치파일을 올리지 않습니다.

[실버와 저장]
웹 데모를 새로 열 때 실버가 10,000개 미만이면 10,000개로 보충합니다.
캐릭터·무기·유물 해금은 직접 선택합니다. 이미 해금한 내용과 10,000개를 초과한 잔액은 유지합니다.
플레이 중 로비로 돌아오는 것만으로 실버가 다시 지급되지는 않습니다.
저장은 같은 브라우저와 같은 주소에서만 유지됩니다. 다른 기기와 동기화되지 않습니다.
시크릿 모드 또는 사이트 데이터 삭제 시 저장 내용이 사라질 수 있습니다.

[조작]
WASD / 방향키: 이동
Shift: 대쉬
R: 액티브 스킬
E: 상호작용
Tab: 탐험 기록·지도
Esc: 설정·뒤로
1 / 2 / 3 / 4 또는 Z / X / C / V: 사용 아이템

PC의 Chrome 또는 Edge 사용을 권장합니다.
전체화면은 페이지 아래 버튼을 사용해 주세요. 종료하려면 브라우저 탭을 닫으면 됩니다.
첫 접속 시 전체 게임 데이터를 내려받으므로 인터넷 속도에 따라 로딩이 걸릴 수 있습니다.
