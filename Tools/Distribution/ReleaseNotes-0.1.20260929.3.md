# 24시간의사투 — Windows 테스트 버전

Assets에서 **24tu-Setup-0.1.20260929.3.exe**를 받아 설치하세요. Source code는 게임 설치 파일이 아닙니다.

## 설치 및 변경 사항

- Windows x64용 설치형 테스트 버전으로, Unity 없이 실행할 수 있습니다.
- 설치 후 바탕화면의 **24시간의사투 (테스트)** 아이콘으로 실행합니다.
- 혁이 액티브 스킬 대표 아이콘을 사용합니다. Windows가 설치 경로를 재지정하는 환경에서도 실제 경로를 확인한 뒤 바로가기와 아이콘을 연결하도록 수정했습니다.
- 캐릭터·스킬, 롤케이크 달팽이 보스와 미니 달팽이 콘텐츠를 포함합니다.
- 설치 폴더의 PLAY_GUIDE.md에 조작법, 저장 및 업데이트 안내가 있습니다.

## 조작법

WASD/방향키 이동, Shift 대시, R 액티브 스킬, E 상호작용, Tab 상태/기록, Esc 뒤로/기록, ZXCV 또는 1234 보유 소모품 사용. 기본 공격은 자동입니다. 전투 중 Insert는 보스 소환 테스트 단축키입니다.

## 저장과 업데이트

현재는 같은 Windows 사용자 계정의 로컬 영구 성장만 저장합니다. 전투 도중 종료한 판은 재개하지 않습니다. Steam/Google 로그인, 클라우드 저장, 자동 패치는 아직 구현되지 않았습니다. 업데이트는 게임 종료 후 새 설치 파일을 실행하며 기존 로컬 저장을 삭제하지 않습니다.

코드 서명 전 테스트 버전입니다. 보안 기능을 끄지 마세요. 게임 데이터는 기존 로컬 검증 빌드와 같으며 이번 변경은 설치/아이콘/안내 문서입니다. 다양한 PC에서의 추가 테스트가 필요합니다. SHA-256은 함께 제공한 `.exe.sha256`에서 확인할 수 있습니다.
