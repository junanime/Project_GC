## 확인된 기존 차이 / 이번 변경 범위 밖

- 회피 본능 등 구 일반 증강 코드는 남아 있지만 현재 Ver.4 레벨업 풀은 별도 생성한다. 구현 코드 존재와 현재 보상 등장 여부를 구분한다.
- 아이템 전용 화상과 침 화상은 별도 시스템이다. 동일 이름만으로 중첩 공유를 가정하지 않는다.
- 로비 MerchantItemEffectUtility와 인게임 ShopStatApplier의 지원 필드가 다르다. 아이템 데이터만 보고 모든 획득 경로에서 발동한다고 표기하지 않는다.
- 포도당 링거: 설명 4%와 실제 고정 0.4 회복이 불일치. 별도 수정 대상이며 이번 스킬 타이밍 패치에서는 변경하지 않았다.
- 행운이 현재 6등급 확률을 올린다고 단정하지 않는다. 기존 AbilityManager의 행운 기반 등급 추첨과 Ver.4 추첨은 별도 경로다.
