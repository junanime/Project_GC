# 혁이 눈보라 타이밍 · 아리 대쉬 접촉 분리

2026-09-23 / Junhan2 / Unity 2022.3.62f3

## 변경

- 혁이: 기존 `TryActivate`에서 즉시 빙결하던 처리를 제거. 눈보라가 약해지기 시작하는 1.65초에 현재 범위 4의 적을 한 번 조회해 빙결한다. 눈보라는 3초까지 잦아든다. 빙결 최대 5초는 적용 시점부터 계산하며 빙결침의 조기 쇄빙은 유지한다.
- `IceSkillRules.BlizzardFreezeDelay`를 연출과 실제 효과가 공유한다. 지연은 게임 시간 기준이며 일시정지 동안 멈춘다. 기존 `SkillSummonRemaining` 저장 필드로 대기 중 복원하고, 이미 적용된 뒤 복원해도 재발동하지 않는다. 사망/비활성화는 대기를 취소한다. 중단된 필드의 몬스터는 제외한다.
- 혁이 스킬 데이터와 설치기의 설명도 함께 변경. 혁이 대기·대쉬 디자인은 변경하지 않는다.
- 아리: 기존 접촉 스윕은 이미 대쉬에 연결돼 있었고 침술진에 전용 밀치기를 주는 코드는 없었다. 이번에는 대쉬 타깃 판정의 침 무기 참조 의존성까지 제거했다. 실제 프로젝트의 Monster Full / Chest 레이어와 기존 피해 대상 유효성 검사를 사용한다.
- 침술진 원형 발사·기본 효과·기본 넉백은 변경하지 않는다. 아리 고유 밀치기는 실제 대쉬 경로, 적당 한 번만. 기본 피해 10 / 몸 너비 ×1.1 접촉 지름 / 거리 0.3, 성체 피해 35 / 성체 몸 너비 ×1.3 / 거리 0.6 유지.
