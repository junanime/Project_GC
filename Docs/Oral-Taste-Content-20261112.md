## 기존 이벤트와 병행

- 기본 칫솔: 가로 → 세로 → 가로 3회. 환타파도 폭의 1.2배, 혀 위 회차당 최대 8 피해. 치아·대쉬·공중 회피 유지.
- 딸꾹질: 아시 높이 3배 상승, 최고점에서 3초 유지. 그림자는 지면, 몸체만 상승한다.
- 풍선껌 보물배송: 미믹 방과 같은 레벨업 상자 외형. 풍선 피격 → 0.7초 낙하 → 상자 1개. 미니 스테이지·입천장에서는 잠시 숨긴다.
- 턱·칫솔·물살·입천장처럼 이동을 강제하는 기본 이벤트는 하나씩 실행한다. 맛 및 굴림돌·수호대는 별도 경로로 병행한다.
- 매운맛 예고와 활성 중에는 턱 닫힘을 막아 치아 대피로를 보장한다. 턱이 먼저 실행 중이면 매운맛을 연기한다.
- 기존 커피의 추격 가속과 혀 전체 화상이 대피 기회를 없애지 않도록 커피와 매운맛은 서로 끝난 뒤 시작한다. 다른 안전한 중첩은 허용한다.
- 입천장 전투, 미니 스테이지, 로딩 중 바닥 콘텐츠를 숨기고 진행시간을 멈춘다. 바닥 복귀 후 이어서 진행한다. 일시정지·증강 선택 중에도 게임 시간 기준으로 정지한다.
- 새 이벤트를 놓친 시간을 한 번에 보충하지 않는다. 오브젝트와 소환량에 상한을 두고 스테이지 해제 시 임시 상태를 복구한다.
- 딸꾹질 공중 복제에는 치석판 7개와 실제 탄산막 메시·박힌 침을 함께 넣는다. 레몬 반동은 원형 몸체와 부착물의 위치를 함께 갱신한다. 움직임이 없는 보호막은 메시를 다시 만들지 않고 재사용한다.
- 레몬 점프를 취소해도 미니 스테이지의 전역 몬스터 정지를 풀지 않는다. 소금 무리를 정리한 뒤 전용 이미지·설정을 해제하여 스테이지 전환 중 빈 이미지 참조를 남기지 않는다.

## 시간표

기본 이벤트는 12초부터, 맛/선택 콘텐츠는 24초부터 시작한다. 처음부터 두 목록을 각각 섞고 목록을 모두 돌면 다시 섞는다. 기본 이벤트 시작 간격은 18–27초, 맛/선택 콘텐츠는 20–28초 범위다. 진행 중인 강제 이동이나 충돌 조건에 따라 연기될 수 있으므로 모든 순간에 30초 이하를 강제하지 않는다. 긴 기본 이벤트 직후에는 최소 2초의 여유를 둔다. 치아에 계속 머물러 혀 뒤집기를 실행할 수 없으면 해당 차례를 건너뛰어 다른 이벤트가 막히지 않게 한다.

10분으로 늘어난 일반몹 단계는 약 3분 20초·6분 40초에 다음 2종을 더한다. 기존 구강 특수몹 첫 등장 시점은 유지하고 10분 출구 생성 시 신규 타이머 소환을 멈춘다. 일반 스폰 제한 90은 현재 살아 있는 전체 몬스터 수를 보므로 추가 소금 무리가 있으면 일반 생성이 자연스럽게 줄어든다. 기존 공통 8분 이후 생성량 30% 증가도 유지된다.

## 검증 및 재현

`Vampire.Tests.Editor.OralTasteContentSmoke.Run`은 실제 Unity 플레이 모드로 구강에 진입하여 유인·섭취, 소금 생성, 점프, 회복, 화상, 보호막 중첩, 굴림돌, 수호대 보상과 이벤트 중첩을 검사한다. 검토 GIF는 실제 게임 카메라를 촬영하되 이벤트 시작·배치·카메라를 제어한 재현 장면이다.

- 기능·연계 검사: 70개 통과. 실제 침 6발로 두 보호층을 순서대로 파괴하고 체력 22.5가 유지되는 것을 확인했다.
- 600초 자동 일정: 기본 이벤트 9종과 맛 5종 모두 실행, 통제된 시험의 최대 생존 개체 20. 이는 시간표와 정리 검증이며 사람 플레이 난이도·성공률·자연 스폰 밀도 측정이 아니다.
- 최종 크기·밀집 검사: 19개 통과. 120초 동안 정상 스폰을 켜고 수동 몬스터 추가·주기 삭제 없이 최대 91마리, 치석 갑옷 최대 12마리를 확인했다. 플레이어 무적·공격 중지·순환 이동을 사용한 기능 스트레스 검사이므로 승률이나 FPS 벤치마크로 해석하지 않는다. 이 실행에서 아시 실제 외형 폭의 2.2배 레몬과 소품·회복·수호대 최종 촬영도 다시 검증했다.
- 기존 딸꾹질·칫솔·풍선껌 배송 회귀: `OralEventAdditionsSmoke.Run` 53개 통과, 실행 오류 0건. 정상 보상 상자와 일시정지·풀 재사용·입천장 전환을 포함한다.
- 특수 시간표 회귀: `OralSpecialScheduleSmoke.Run` 113개 통과. 최초 등장·반복 간격·상한·10분 이후 소환 중단·구강에서 위장 복귀 및 대장 기존 시간표를 검증했다.
- 실제 게임 캡처: 새 콘텐츠 원본 960×540·15fps. 공유 GIF는 축소·10fps로 인코딩한다. 기존 세 이벤트는 20fps 원본을 별도 검증한다.
- 캐릭터별 추가 검사: 아리·혁이·신이를 각각 새 Unity 프로세스로 실행하여 8개씩 통과, 실행 오류 0건. 실제 캐릭터 선택·원형 스프라이트·레몬 반동과 물리 복구·쓴맛 안내와 회복·종료 정리를 확인했다. 아시는 위 전체 기능·밀집 검사에서 검증했다.
- 최종 성공 실행의 검증 항목 합계는 279개(70+19+53+113+24)다. 서로 다른 실행의 합이며 사람 플레이 난이도나 모든 기기에서의 무오류를 보장하는 수치는 아니다.
- 최초 한 에디터에서 캐릭터를 연속 재진입시키는 시험은 두 번째 진입 전에 Localization 리소스 재로딩 예외로 중단됐다. 해당 실패 기록을 보존하고 시험을 캐릭터당 독립 프로세스로 변경했다. 동일 기능의 독립 실행은 모두 통과했으며, 검증을 통과시키기 위해 게임 오류를 무시하는 처리는 넣지 않았다.
- 재현: `OralTasteContentSmoke.Run`의 기본 실행은 아시 전체 검사다. `-oralDensity`는 자연 스폰 밀집 검사, `-oralQuick -oralCharacter=1`, `=2`, `=3`은 아리·혁이·신이 추가 검사다. 각 실행은 별도 Unity 프로세스에서 수행한다.
- 레몬의 최종 크기는 투명 이미지 셀이 아닌 아시의 실제 보이는 몸체 너비로 다시 맞췄다. 11개 GIF를 인코딩 후 다시 디코딩하여 프레임 수·지속시간·이미지 정상 표시를 확인했다.
