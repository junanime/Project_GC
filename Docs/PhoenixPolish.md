# 봉황·눈보라 이펙트 개선

## 동작

- 혁이 대기: 새 다이아몬드 얼음 수정으로 수면 스택을 표시한다. 5스택당 1개이며 대기 상태에만 회전한다. 이동·대쉬 중에는 수정 회전 표시가 없다.
- 혁이 이동: 옅은 바람 자국과 눈송이를 실제 지나온 위치에서 흩날린다. 대쉬: 더 굵은 얼음 파편과 눈송이를 이동 반대 방향으로 빠르게 흩뿌린다. 이 입자들은 캐릭터를 따라 회전하지 않는다. 일반 이동의 연한 눈 효과는 꾸밈이며 이동 보너스 수치/지속시간을 바꾸지 않는다.
- 혁이 액티브: 사용자가 지정한 짙은 흰 눈보라를 새 텍스처로 반영하고 120개의 작은 눈송이·얼음 파편을 더한다. 짙은 안개가 먼저 걷히고 밝은 눈 자국이 뒤늦게 사라진다. 오른쪽 아래로 이동하며 눈보라가 걷힐 때도 같은 방향을 유지한다.
- 신이 액티브: 봉황 몸체는 신이 뒤, 왼쪽/오른쪽 날개는 신이 앞에서 표시한다. 소환 후 날개를 펼치고 조금 내려온 뒤 날개가 서서히 감싸며 끝부분이 교차한다. 교차 끝에 불꽃이 확 퍼지고 기존 불닭 활성화 모습이 드러난다.
- 신이의 3초 소환 후 활성화 15초·쿨타임 35초 시작 규칙, 혁이와 빙결침의 최대 빙결 5초 규칙은 유지한다.

## 아트·구현

- `Assets/Junhan/Art/PhoenixSkills/IceComponents.png`: 수정, 눈송이, 얼음 파편, 옅은 눈바람의 2×2 시트.
- `Assets/Junhan/Art/PhoenixSkills/FireWrapParts.png`: 봉황 몸체, 왼쪽 날개, 오른쪽 날개, 폭발의 2×2 시트.
- 내장 image_gen으로 생성했다. 생성 프롬프트는 `PhoenixPolish-ArtPrompts.json`에 보관한다.
- 불꽃 원본의 배경은 전용 셰이더로 제외한다. 이전 효과의 얇고 연한 표현을 줄이기 위해 붉은 깃털 가장자리와 넓은 불꽃 면을 더 유지한다.
- 날개는 36×14 구획의 입체 표면으로 구성한다. 어깨에서 앞으로 나오고 중간부터 굽어져 캐릭터를 감싸며 끝이 교차한다. 평면 날개 회전 방식은 사용하지 않는다. 불꽃은 시간에 따른 흐름·가장자리 밝기 변화·표면 흔들림과 상승하는 불티로 표현한다. 원본 캐릭터나 기존 활성화 상태 이미지를 새 이미지로 대체하지 않는다.

## 검증

기존 혁이·신이 스킬 Play 검증과 Windows 실행 검증으로 상태 전환, 스택, 이동·대쉬별 이펙트 구분, 전후 레이어, 눈보라 입자, 기존 활성화 타이밍을 확인한다. 모바일 입력은 기존 경로를 유지하며 실기기 성능 검증은 별도다.

- 눈보라 텍스처: Assets/Junhan/Art/PhoenixSkills/BlizzardReference.png
