# 이벤트·스폰·수집형 미니스테이지 통합

## 인스펙터 사용

### StageEventDirector

`편집할 이벤트`에서 감염 증식 / 골드 러시 / 위산 분비 / 산성 역류 / 연동운동 / 커피수혈 / 제산 반응을 선택한다.
각 종류의 기존 시간표와 수치, 프리팹·VFX 연결을 같은 컴포넌트에서 편집한다.
`일정 추가`는 선택한 종류의 일정을 추가한다. 기존 항목이 있으면 Unity 배열 편집 규칙에 따라 마지막 항목의 값이 복제되므로 시간을 확인한다.

### TimedSpecialMonsterSpawner

- **특수 몬스터**: 시간 지정 생성, 함정 개수 유지, 소화효소, 엘리트 생성 단계, 혈전.
- **보스**: 추가 미니보스 일정, 추가 최종보스 일정, LevelBlueprint 기본 보스 시간표.
- **필드 오브젝트**: 엘리트 소환 오브젝트 생성.

각 목록에 설정을 추가하며, `Module Enabled`는 해당 설정 묶음의 실행 여부다.
실행 중 끄고 켜면 타이머와 진행 중인 생성 루틴을 처음부터 재생성하지 않고 이어간다.
이미 생성된 몬스터를 삭제하는 스위치가 아니다. 이벤트별 개별 `Enabled`와 구분한다.
소화효소는 `Monster`가 아니라 `IDamageable` 계열이므로 전용 초기화·생성 경로를 유지한다. 공통 몬스터 풀로 억지로 형변환하지 않는다.

### MiniStageCollectionRoom

`수집 종류`를 Gold / Experience 중에서 선택한다. 선택한 자원의 가중치와 예비 프리팹만 노출된다.
시간 제한, 격자·전체 영역 배치, 간격, 확률, 흔들림, 중앙 빈 공간, 타이머 UI, 종료·귀환 처리는 공통이다.
기존 골드 방과 경험치 방 프리팹은 각각 기존 수치를 유지한 채 같은 컴포넌트를 사용한다.
이전 클래스명 두 개는 코드 호환용 얇은 어댑터로만 남겨두었으며 방 프리팹에서는 사용하지 않는다.

## 내부 구조

- 씬에서 Unity 업데이트를 받는 소유자는 이벤트 1개와 스폰 1개다.
- 기존 보조 디렉터/스포너는 직렬화 가능한 `RuntimeModule`이며 독립 컴포넌트가 아니다.
- `RuntimeModuleHost`가 초기화, 일반/물리 업데이트, 중첩 코루틴, 정지·재개·해제를 전달한다.
- `LevelManager`는 더 이상 보스를 직접 예약 생성하지 않는다. 기본 보스 시간표도 통합 스폰 소유자의 `LevelBossSchedule`에서 실행한다.
- 수동 최종보스 소환은 최종보스 예약만 취소하며 다른 몬스터 스폰을 끄지 않는다.
- 기존 위치 참조는 `[Placement]` 자식 오브젝트로 정리했다. 독립 스포너는 제거했지만 참조된 Transform은 파괴하지 않았다.
- 비활성 기존 함정 스포너는 꺼진 `TimedSpecialSpawnSchedule` 설정으로 이관했다. 중복 함정 유지 구현은 제거했다.
- 기존 enum 저장 숫자, 몬스터 인터페이스, 전투 AI, 아트, VFX 에셋은 변경하지 않았다.

## 이관과 안전 장치

기준 커밋: `a89aaf0c37dacc51efae51b0ba35185bb25642d3`.

메인 씬, 복구용 씬, 기존 테스트 씬의 관련 컴포넌트와 수집형 방 프리팹 2개를 이관했다.
기존 직렬화 설정 22개 묶음의 수치·참조를 대조했다. 비활성 함정 설정은 별도로 모드·풀 인덱스·수량·거리·재생성 간격을 대응시켰다.
테스트 씬의 이미 폐기된 직렬화 필드도 원문 데이터는 남겼다. Unity에서 그 씬을 저장하면 현재 클래스에 없는 필드는 Unity가 제거할 수 있다.

함정 생성과 수집형 방의 생성·회수는 실제 EntityManager 메서드를 직접 호출한다.
아이템은 생성 세대 번호로 소유권을 확인해, 이미 회수되어 다른 곳에서 재사용된 아이템을 이전 방 종료가 제거하지 않도록 했다.
코인·경험치 풀 반환 시 자석 수집 목록도 정리한다. 시간 종료 전에 수집 중이던 아이템은 획득을 마친다.

## 검증 실행

Unity 2022.3.62f3 기준. 아래 정적 메서드를 `-executeMethod`로 실행한다.

- `Vampire.Tests.Editor.DirectorConsolidationTestRunner.RunAll`: 구조·씬·프리팹·보상 위치·기존 캐릭터/몬스터 검사. `-batchmode -nographics -quit` 사용.
- `Vampire.Tests.Editor.DirectorConsolidationPlaySmoke.Run`: 실제 Level 1, 공통 스폰 시계 정지·재개, 설정 토글, 골드/경험치 생성·종료, 풀 재사용, 이벤트 시작 경로, 보스 예약 취소. Play Mode 종료를 자체 처리하므로 `-quit`은 넣지 않는다.
- `Vampire.Tests.Editor.MonsterRemakePlaySmoke.Run`: 기존 미역 포획, 공격 차단, 탈출, 저격 발사·반동 회귀. `-quit`은 넣지 않는다.

모든 테스트 픽스처 변경은 Play Mode에서만 수행한다. 테스트 방·몬스터는 씬 에셋에 저장하지 않는다.

## 기존 이슈 / 범위

메인 씬의 비활성 지도 UI `MapPanelRoot`와 `MapViewport`에는 기준 커밋부터 Missing Script가 각각 하나 있다.
이 두 항목은 이번 범위 밖이므로 삭제하지 않았다. 검사는 해당 기존 항목 외의 새 누락을 허용하지 않는다.

이번 작업은 관리 구조 통합이다. 기존 이벤트 중첩 규칙, 등장 확률, 몬스터 수치 등 게임 밸런스는 새로 설계하지 않았다.
