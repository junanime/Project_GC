# 메인 UI와 출전 흐름

## 사용

Unity 2022.3.62f3에서 빌드 목록의 `Main Menu`를 실행합니다. `ApothecaryUIConfig`가 있으면 새 UI가 기존 메인 캔버스를 대신합니다. 원본 씬과 구형 컴포넌트의 직렬화 참조는 유지합니다.

- 게임 시작 → 출전 준비. 캐릭터는 이 화면에서 변경합니다.
- 출전 준비: 기본 능력치 / 향후 고유 스킬 1종 자리, 유물 1개와 서로 다른 아이템 2개를 한 줄에 표시합니다.
- 장착·구매 버튼은 각 선택 패널 안에 있으며 출전 버튼은 계속 유지됩니다.
- 구매 한도·중복·잔액 검사는 기존 `LobbyLoadoutData`와 `SilverWallet`을 사용합니다. 출전 시 목록을 한 번만 전달합니다. 소모품은 재도전에 재사용되지 않습니다.
- 잠금 해제: 기존 캐릭터·유물의 가격과 저장 키를 사용합니다. 아이템과 증강은 현재 사용 가능한 콘텐츠를 안내합니다. 새로운 해금 조건이나 가격은 임의로 추가하지 않았습니다.
- 실버 잔액은 출전 준비와 잠금 해제에서만 표시합니다. 탐험 기록과 결과의 골드는 인게임 획득 골드입니다.
- TAB / 화면 오른쪽 위 상태 버튼 → 상태·유물·아이템·도감. 시간 정지는 이 화면에서 열었던 경우에만 복원합니다. 다른 선택창이 시간을 정지시킨 동안에는 열리지 않습니다.
- 성공·실패 결과 → 출전 준비 또는 메인. 실패 아트는 아시 원본을 참고한 X 눈 쓰러짐 포즈입니다.
- 설정: 그래픽·사운드·편의 기능을 구분합니다. 메인과 탐험 기록에서 열 수 있으며, 탐험 중에는 일시정지를 유지합니다. Escape / Android 뒤로는 저장하지 않은 변경을 취소하고 이전 화면으로 돌아갑니다.

## 설정

- 그래픽: 실제 Unity 품질 단계(낮음/보통/높음), 30/60/120/제한 없음 프레임, PC 수직 동기화, 전체 화면/창 모드, 디스플레이 해상도 목록. 모바일에서는 화면 모드·해상도·VSync 항목을 숨깁니다.
- 사운드: 전체 음량은 AudioListener, 배경음/전투 효과음/UI 효과음은 각 AudioSource로 분리합니다. 전투·UI 효과음에는 듣기 버튼이 있습니다. 전체 음량을 두 번 곱하지 않습니다.
- 편의 기능: 버튼 움직임 줄이기, 실제 FPS 표시, 다른 창으로 이동 시 일시정지/음소거.
- 슬라이더는 즉시 미리 듣기, 적용은 저장, 뒤로는 마지막 적용 상태 복구입니다. 기본값은 설정 초안만 초기화하며 캐릭터·재화·해금 저장은 변경하지 않습니다.
- PC 화면 모드/해상도는 적용 후 15초 내 유지하지 않으면 이전 설정으로 복구합니다. 확인 시간은 게임 일시정지와 무관하게 흐릅니다.
- `GamePreferences`는 `Apothecary.Settings.v2`에 설정을 저장하고 기존 전체 음량/움직임 줄이기 값을 처음 실행 시 이어받습니다.

## 아트와 입력

메인·준비 화면의 아시는 `Main Character Blueprint`의 기존 스프라이트와 대기 애니메이션을 직접 표시합니다. 제목 배경, 빈 패널 프레임, 실패 포즈, 빈 버튼은 별도 PNG입니다. 버튼 글자·아이콘·실버·슬롯·상태는 Unity UI 요소입니다.

수정된 출전 준비·잠금 해제·탐험 기록은 펼친 책 배경을 사용합니다. 캐릭터 무대, 두루마리 정보판, 붉은 이름표, 나무 슬롯, 분홍 주 버튼을 각각 별도 스프라이트로 배치합니다. 글귀를 지운 가장자리는 꽃·약초·목재 장식으로 이어집니다. 슬롯 안의 아이콘과 글자도 버튼의 시각 효과와 함께 움직입니다.

모든 버튼은 `ApothecaryButtonFeedback`을 공유합니다. 기존 `TitleMenuSurface`의 테두리를 도는 빛을 재사용하며 호버 확대, 색 변화, 누름 축소, 선택 상태, 비활성화를 통일합니다. 보이는 요소만 확대하고 클릭 영역은 고정합니다. 터치 해제·영역 이탈·비활성화·앱 포커스 상실 시 누름 상태를 초기화합니다. 애니메이션은 일시정지 중에도 동작합니다.

화면은 가로 비율을 유지하며 안전 영역 안에 배치합니다. 더 넓거나 좁은 화면의 여백은 어두운 테두리로 채워 인게임 화면과 버튼이 뒤에서 노출되지 않도록 합니다.

## 수정 위치

- `Assets/Junhan/Resources/ApothecaryUIConfig.asset`: 실제 콘텐츠와 이미지 참조.
- `Assets/Junhan/Art/ApothecaryUI`: 원본 아트. 버튼은 Unity 스프라이트 경계와 9분할로 크기를 조정합니다.
- `Tools / Apothecary UI / Install or refresh catalog`: 원래 메인 씬의 캐릭터·상점 목록과 게임 씬의 증강 목록에서 참조를 다시 만듭니다.
- 캐릭터 고유 스킬은 아직 게임에 없으므로 '?'와 '추후 공개'로 표시합니다. 효과를 구현한 것처럼 안내하지 않습니다.

## 검증

`Vampire.Tests.Editor.ApothecaryUIPlaySmoke.Run`은 실제 메인과 게임 씬을 실행하고 버튼 위치를 레이캐스트하여 클릭합니다. 호버·누름·터치 해제·영역 이탈, 구매 및 차감, 중복/한도/잔액 거절, 아이템 전달, 유물 적용, TAB 시간 정지/복원, 성공/실패와 복귀를 검사합니다. 테스트 저장값은 종료 시 복원하고 화면 캡처는 `Library/ApothecaryUIProof`에 저장합니다.

`Vampire.Tests.Editor.ApothecaryBuildCheck.Run`은 활성 빌드 씬을 Windows 개발 플레이어로 빌드합니다. 결과는 `Builds/ApothecaryPlayer`에 남습니다. 모바일 입력은 에디터의 터치 이벤트와 화면 비율로 점검하며 실제 휴대폰 테스트와 구분합니다.

설정 검증은 음량별 AudioSource 값, 적용/재읽기, 기본값 취소, 화면 변경 취소와 자동 복구, 씬 전환 후 유지, 게임 중 설정 복귀를 포함합니다. 개발 빌드에만 포함되는 `-apothecarySmoke` 옵션으로 실제 Windows 화면 모드·해상도 변경과 타임아웃 복구도 확인할 수 있습니다. 검증 후 기존 설정 저장을 복원합니다.
