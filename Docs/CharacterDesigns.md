# 캐릭터 디자인 적용 (2026-09-22)

## 범위

아시·아리·혁이·신이 모두 즉시 선택 가능. 캐릭터별 패시브, 액티브,
시작 침 차이, 대쉬 피해/밀치기/스택은 이번 적용에서 제외한다.
신규 3종은 아시의 기본 능력치와 시작 공격을 공유한다. 콜라이더와 대쉬 거리는 바꾸지 않는다.

## 확인 방법

메인 → 잠금 해제 → 캐릭터 → 카드 선택 → 선택하고 출전 준비 → 출전하기.
출전 준비의 좌우 화살표로도 변경 가능하다. 로비로 돌아와도 현재 선택을 유지한다.
왼쪽 카드에는 별도 프로필, 오른쪽 설명에는 전신 대기 애니메이션을 표시한다.

|캐릭터|대기|대쉬|걷기/대기/대쉬 프레임|
|---|---|---|---|
|아시|기존 호흡·머리띠|기존 다리 회전|8/8/8|
|아리|큰 좌우 뒤뚱거림|알 구르기·대쉬 전용 >< 눈·뒤쪽 바람|8/8/8|
|혁이|수면안대·빨강/검정 체크 이불·두꺼운 흰 테두리|반대쪽을 바라보며 모자/장갑 착용, 두 자세 문워크|8/8/2|
|신이|날개를 허리에 짚고 호흡|불꽃 박차기|8/8/8|

포획은 각 캐릭터의 XX 표정으로 전환하며 기존 방향 고정·공격 중단 규칙을 재사용한다.
혁이 취침은 현재 정지 상태의 시각 연출일 뿐 공격 사거리/스택 패시브가 아니다.
바람과 불꽃은 그림에 포함된 연출이며 새로운 피해 판정이나 지속 장판은 없다.

## 원본과 연결

승인된 PNG 16개를 `Assets/Junhan/Art/CharacterDesigns`에 원본 그대로 보관한다.
프로필 4개와 신규 3종의 Walk/Idle/Dash/Captured 각 4개이다.
걷기 키 기준은 아리 0.43, 혁이 0.59, 신이 0.51 월드 단위(공통 자식 스케일 적용 전).
다른 자세는 머리 폭 기준으로 크기를 맞추고 발밑을 동일하게 정렬한다.
혁이 취침의 푸른 매트는 머리 크기 측정에서 제외한다.
Point 필터·투명 배경·밉맵 없음·비압축을 사용한다.

`Tools/Characters/Install approved designs`로 임포트를 재현할 수 있다.
주의: 이 메뉴는 외형 검수용 기본 능력치, 캐릭터 목록과 프레임 설정을 다시 적용한다.
향후 개별 스킬/해금 정책 도입 후에는 해당 정책에 맞춰 설치 코드를 먼저 수정한다.

## 검증

Unity 2022.3.62f3에서 실행:

- `Vampire.Tests.Editor.CharacterDesignTests.Run`: 카탈로그·프레임·이미지 설정·동일 기본 능력 및 아시 회귀 검사.
- `Vampire.Tests.Editor.CharacterDesignPlaySmoke.Run`: 실제 UI 카드 선택, 출전 준비, 뒤로가기 후 선택 유지,
  게임 진입, 대기/걷기/대쉬, 문워크 두 번째 자세, 포획/해제, 일시정지, 로비 복귀.
  증거 화면은 `Library/CharacterDesignProof`에 생성한다.
- `Vampire.Tests.Editor.ApothecaryBuildCheck.Run`: Windows 개발 빌드.

Android/iPhone 실기기 검증과 캐릭터별 스킬 구현은 이번 완료 범위가 아니다.

2026-09-22 결과: Play Mode 검증 357항목 통과, 런타임 오류 없음.
Windows 개발 빌드 `Succeeded errors=0`. 기존 보스 코드의 미사용 필드 경고는 남아 있다.
크기 검수 중 혁이 매트/날개 오인식을 수정했고, 대쉬 마지막 프레임 되감기를 방지했다.
스크린샷 직후 UI 레이캐스트 검사에는 실제 렌더 프레임 대기를 추가했다.

## 손 발사점 / 침술진 / 신이 크기 보정 (2026-09-22)

- 네 캐릭터 Blueprint에 대기/이동 손 위치를 별도로 저장한다. 혁이는 취침 자세도 별도 위치를 쓴다.
- 발사점은 좌우 외형 반전에 맞추며 수직 조준 때문에 몸 주위를 회전하지 않는다. 귀환 위치도 같은 발사점을 사용한다.
- 손 위치 사용 시 침의 기존 추가 전방 이동을 생략하여 실제 생성 위치와 발사 직후 위치가 일치한다.
- 침술진은 대쉬 중 일반 공격 차단 규칙에 막히던 문제를 수정했다. 보유한 침술진의 대쉬 발사만 허용하며 포획 중에는 여전히 차단한다.
- 푸른 원형 VFX는 침술진 투사체가 실제 발사됐을 때만 재생한다. 일반 대쉬에서는 재생하지 않는다.
- 신이 대쉬는 원본 픽셀/형태를 변경하지 않고 표시 크기를 1.16배 보정했다. 발밑 정렬도 유지한다.
- Play Mode 자동 검증 425항목 통과: 네 캐릭터 손 위치/반전/수직 조준/실제 투사체 시작점,
  일반 대쉬 VFX 없음, 침술진 설정 개수 발사 및 VFX 1회, 포획 차단, 대쉬 외 발사 차단, 기존 선택/모션 회귀.
- Windows 개발 빌드 성공 (`Succeeded errors=0`). 모바일 실기기는 이번 검사에 포함하지 않았다.
