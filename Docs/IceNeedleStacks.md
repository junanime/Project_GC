# 빙결침 냉기 스택 (2026-09-22)

## 최종 규칙
- 빙결침 보유 중 유효 적중 1회당 냉기 1스택.
- 1/2/3스택: 원본 이동속도의 80%/70%/60%. 이전 감속 결과에 다시 곱하지 않는다.
- 4번째 적중은 확정 빙결. 그 전에도 매 적중 5% 확률로 즉시 빙결.
- 빙결 발생 시 냉기 스택을 소모한다. 스택 자체는 시간 경과로 사라지지 않는다.
- 최대 빙결 5초와 기존 얼음 수정 연출 유지. 다음 침은 기존 쇄빙 피해 +20% 후 해제하고 새 스택을 시작한다.
- 기존 재빙결 대기 중 적중을 무시하는 제한은 제거한다.
- 보스의 기존 완전 빙결 저항은 유지한다.
- 조건부 증강 「냉기 침투」: 기존 빙결 확률 증가를 스택당 감속 +5%p로 전환. 확정 적중 횟수와 기본 즉시 빙결 확률은 변하지 않는다.

## 공통 시각 효과
- 몬스터의 현재 스프라이트 알파를 그대로 사용한 옅은 하늘색 덧씌우기.
- 이동/공격 프레임, 좌우 반전, 크기를 실시간으로 따라간다. 몬스터별 새 이미지 불필요.
- 작은 눈 입자 9개가 주변에 가볍게 내린다. 기존 공통 눈송이 아트를 재사용한다.
- 빙결 중에는 슬로우 효과를 숨기고 기존 얼음 수정을 표시한다.
- 사망/풀 반환 시 스택과 감속을 정리한다.

## 검증
- Windows 실행 검사에서 1~3회 스택과 감속 비율, 4회 확정 빙결, 5% 즉시 빙결 분기, 5초 빙결, 쇄빙, 중복 감속 복원, 풀 초기화를 확인한다.
- 모바일 실기기 성능 검증은 별도.
