# 스테이지 0 추가 이벤트 · 2026-11-11

## 이번 적용

- 딸꾹질: 1.2초 예고 → 0.45초 상승 → 최고점에서 3초 유지 → 0.45초 착지. 상승 높이는 아시 기본 대기 이미지의 실제 높이 3배. 몸체만 올리고 그림자는 원래 바닥 위치에 둔다. 공중에서는 이동·접촉 물리를 중지하고 착지/취소 시 복구한다. 혈전, 함정, 보스는 대상에서 제외한다.
- 기본 칫솔 청소: 가로 → 세로 → 가로 총 3회. 각 회차 1.2초 경고, 환타파도 기준 통과시간(기본 1.4초), 0.4초 간격. 유효 폭은 환타파도의 실제 폭 2 × 1.2 = 2.4. 각 경고 시점의 플레이어 위치를 기준으로 경로가 고정된다. 혀 위 플레이어는 회차당 최대 1회 8 피해, 대쉬/공중/이빨 위에서는 회피 가능. 일반·특수 몬스터는 밀려나며 회차당 8 피해.
- 풍선껌 보물배송: 플레이어 근처 혀 위에 나타나 천천히 부유한다. 풍선 부분을 공격하면 터지고 0.7초 동안 상자가 떨어진다. 착지 시 기존 레벨업 상자를 정확히 한 개 생성한다. 미니 스테이지 미믹 방과 같은 `RemakeBalance.levelUpChest` 외형과 보상 처리 사용. 공중에서는 상자를 열 수 없다.

## 충돌 방지

- 기존 구강 이벤트 관리자가 진행 이벤트를 하나만 허용한다. 딸꾹질·칫솔·턱 닫힘·액체·혀 뒤집기가 동시에 시작되지 않는다.
- 일시정지/증강 선택 중에는 진행 시간을 멈춘다. 미니 스테이지·로딩·스테이지 이동 중에는 새 이벤트를 시작하지 않는다.
- 배송 풍선은 등장 안내가 끝나도 남아 있으므로 다음 이벤트를 막지 않는다. 입천장·미니 스테이지·이동/로딩 중에는 숨기고 피격도 막는다. 복귀 후 다시 보인다. 아직 터뜨리지 않은 풍선이 있으면 중복 생성하지 않는다.
- 스테이지 종료/이벤트 해제 시 공중 몬스터의 렌더링·물리 상태를 복구하고 칫솔/배송 임시 오브젝트를 제거한다.
- 독립 랜덤 보급 카테고리와 확률표는 이번 작업 범위에 포함하지 않는다.
