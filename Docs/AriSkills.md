# 아리 — 데굴데굴 / 나 멋지지

## 적용 규칙 · 2026-09-23

| 항목 | 기본 아리 | 성체 아리 |
|---|---|---|
| 시작 증강 | 실제 침술진 프리팹 보유 | 그대로 유지 |
| 대쉬 접촉 피해 | 10 | 35 (10에 더하지 않음) |
| 접촉 지름 | 기본 몸 기준 폭 × 1.1 | 성체 몸 기준 폭 × 1.3 |

- 액티브는 8초 지속, 재사용 35초. 사용 즉시 대쉬 1회를 충전하며 최대 보유량을 넘지 않는다.
- 소환수가 아니라 기존 플레이어의 시각 외형만 교체한다. 이동·침·대쉬 입력을 잠그지 않는다.
- 기본 몸 기준 폭은 기본 대기 첫 스프라이트의 월드 폭을 한 번 측정한다. 성체 기준 폭은 여기에 외형 배율 1.5를 적용한다. 대쉬 중 펼친 날개·꼬리·먼지는 접촉 범위를 늘리지 않는다. 원형 반지름은 지름의 절반이다.
- 대쉬 경로를 스윕하여 빠른 이동 중 누락을 방지한다. 같은 적은 대쉬 1회당 한 번 적중한다.
- 밀치기는 침술진 발사체가 아니라 아리의 대쉬 경로 접촉이다. 침술진의 원형 발사·기본 넉백은 변경하지 않는다. 대쉬 판정은 침 무기 참조 없이 독립 실행되며 침술진/침 발사를 끈 실행 테스트로도 확인한다.
- 밀치기는 0.12초 동안 거리 제한 이동. 벽 앞에서는 더 짧게 멈춘다. 보스·저격·함정·혈전·고정 강체는 피해만 받고 밀리지 않는다. 풀 반환 시 미완료 밀치기는 초기화된다.
- 버프 만료 즉시 다음 대쉬의 충전 성능은 기존값으로 돌아간다. 이미 진행 중인 강화 대쉬는 피해·범위·외형을 끝까지 유지하고 복귀 0.56초 후 기본 외형으로 돌아간다. 후속 기본 대쉬는 기존 알 구르기를 즉시 사용한다.
- 변신·복귀 중에도 HP와 피격 콜라이더는 바뀌지 않는다. 포획은 기존 X X 표정을 우선하고 사망 시 성체 외형을 해제한다.
