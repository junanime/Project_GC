# 신이: 불닭의 시작 / 불닭의 끝

## 동작

- 신이는 시작 침과 함께 화염침 특수 증강을 보유한다. 보유 목록과 조건부 증강 진행에도 등록되며, 다른 캐릭터의 시작 장비는 바뀌지 않는다.
- 패시브 **불닭의 시작**: 실제 대쉬 이동 좌표에 연속 불꽃길을 남긴다. 장애물에 막힌 목적지까지 미리 생성하지 않는다. 각 선분은 생성 시각부터 3초 후 개별 제거된다.
- 액티브 **불닭의 끝**: R 또는 모바일 스킬 버튼으로 즉시 발동한다. 15초 동안 일반 이동에도 같은 불꽃길을 남기며, 시작 시 35초 쿨타임이 시작된다. 아시의 컷인·이동속도·공격속도·발사체 배수는 적용되지 않는다.
- 활성 상태에서 승인된 불타는 대기·걷기·대쉬 8프레임으로 교체한다. 원래 몸의 높이와 발 기준점을 유지하며, 불꽃 여백은 몸 크기 계산에서 제외한다.
- 발 위치에서 바닥 불꽃을 생성하고 불기둥은 이동 방향과 관계없이 월드 위쪽으로 올라온다. 원형 장판을 연속 배치하는 방식은 사용하지 않는다.
- 일시정지/TAB에서는 지속시간, 쿨타임, 불꽃길 수명이 멈춘다. 장면 이동 시 스킬 잔여시간을 복원하며 이전 장면의 장판은 제거한다. 사망 시 스킬과 장판을 정리한다.

## 피해와 화상

- 불꽃길 직접 타격은 현재 침의 유효 피해량, 일반 공격 능력치/치명타 계산, 대상 부식 배율을 사용한다. 경로 길이/선분 겹침으로 피해가 곱절이 되지 않도록 같은 대상의 재타격 간격은 현재 침 공격 간격으로 제한한다. 이동거리 기반 침 효과나 다른 특수침의 연쇄 효과는 장판에 추가하지 않는다.
- 화상은 화염침의 `Ver4NeedleStatus.ApplyFire`를 공유한다. 타격 시 25% 확률, 기본 3초, 1초 간격으로 대상 최대 체력의 0.5% 피해, 기본 최대 3중첩이다. 화염침의 조건부 증강으로 피해·지속시간·중첩 상한이 함께 강화된다. 보스에는 화염침의 기존 틱 피해 상한을 적용한다.
- **화염침과 불꽃길이 부여한 중첩은 같은 목록에 합쳐진다. 각 중첩은 자기 피해량·틱 시점·만료시점을 유지하며, 모든 중첩이 각각 틱 피해를 준다.** 같은 시각·피해의 중첩은 저장 공간만 묶고 피해 호출은 중첩 수만큼 실행한다.
- 서로 다른 생성 시점의 중첩이 다른 중첩의 틱 시점을 초기화하지 않는다. 최대 중첩에 도달하면 기존 화염침 규칙대로 가장 오래된 한 중첩을 교체한다.
- 화상 VFX는 몬스터 몸 크기에 맞춘 3개의 위치 변경 프레임을 1초 간격으로 재생한다. 시연용 녹색 몬스터는 포함하지 않고 불꽃만 분리해 사용한다.

## UI

- 게임 시작/잠금 해제/설정/종료가 있는 메인 페이지의 패시브·액티브 아이콘을 제거한다.
- 출전 준비, TAB 및 캐릭터 정보의 두 스킬 슬롯은 유지한다.
- 스킬 상세 패널은 왼쪽 아이콘, 오른쪽 이름과 설명, 아래 닫기 버튼으로 구성한다.
- 인게임 액티브 버튼은 기존 R/터치 입력, 숫자 쿨타임 및 12시 기준 시계 방향 해제 마스크를 유지한다.

## 검증

Unity 2022.3.62f3. `ShiniSkillPlayTests`는 실제 게임 장면에서 시작 화염침, R 발동, 지속시간·쿨타임, 아시 효과 분리, 실제 대쉬와 일반 이동 경로, 구간별 만료, 실제 몬스터 피해/공유 화상 3중첩의 틱 합계, 풀링 정리, TAB, 모바일 HUD, 사망 정리를 확인한다. 화면 캡처는 `Library/ShiniProof`에 저장한다. 모바일 검증은 입력/레이아웃 시뮬레이션이며 실기기 검증은 별도다.

- EditMode 전체: 51/51 통과.
- 신이 실제 장면: 39개 확인 통과. 겹친 경로 직접 피해 중복 방지와 일반 이동의 실제 좌표 변화 포함.
- 아시 실제 장면 회귀: 51개 확인 통과.
- Windows Development 빌드: 오류 0건.
- 실행 파일 검증: 통과, 런타임 오류 0건. `-shiniSkillsSmoke` 옵션. 시작 화염침, 변신, 경로 생성/만료, 효과 셰이더 포함 여부, 좌/상/하 방향 경로의 위쪽 분출을 검사한다.

- 몬스터 부착 화상: `exec-fe708d01-3c8b-4048-ae1b-bbf960b7fbbd.png`의 3개 프레임에서 불꽃색만 추출. 몬스터/배경 픽셀 제외.
