# 키보드 설정 · 2026-10-27

설정의 세 번째 **키보드** 메뉴에 승인된 키보드 그림형 화면을 적용한다. 기존 탐험 설정의 스티치 패널, 민트/코랄 버튼과 책갈피를 유지하며 키캡은 해상도에 따라 선명하게 그린다.

## 사용 방법

1. 키보드 그림을 클릭하거나 실제 키를 눌러 키를 선택한다. 숫자패드 등 그림에 없는 키도 실제 입력으로 선택할 수 있다.
2. 오른쪽에서 기본 키/보조 키와 전투·이동·소모품·메뉴 분류를 선택하고 연결할 기능을 누른다.
3. 다른 기능에 연결된 키 또는 이미 채워진 할당 칸을 교체할 때 확인 창이 표시된다.
4. **적용**으로 저장한다. 적용하지 않고 계속하기/닫기/캐릭터정보로 나가면 마지막 저장 상태를 유지한다.

민트 키는 이동, 노랑은 연결된 기능, 코랄은 현재 선택한 키다. 기본 키와 보조 키는 동시에 사용할 수 있지만 하나의 키를 여러 기능에 중복 할당하지 않는다. Esc는 설정 열기·뒤로 가기의 고정 키이며 시스템 키는 할당하지 않는다.

**키 설정 초기화**는 키보드 탭에서 키 설정만 바꾼다. 적용 전에는 취소할 수 있다. 이동·대쉬·액티브·상호작용·혈전 과충전·탐험 기록에 키가 하나도 없으면 저장을 막고 해당 기능을 안내한다. 소모품은 개별 해제가 가능하다.

## 연결 범위

| 기능 | 기본 / 보조 |
|---|---|
| 이동 | W/A/S/D, 방향키 |
| 대쉬 | 왼쪽 Shift / 오른쪽 Shift |
| 액티브 | Space |
| 상호작용 | E |
| 혈전 과충전 | Q |
| 탐험 기록 | Tab |
| 설정·뒤로 | Esc · 고정 |
| 소모품 1–4 | Z/X/C/V, 1/2/3/4 |

설정은 기존 `Apothecary.Settings.v2`에 포함되어 함께 복사·저장·복구된다. 이전 저장 파일에는 기본 키를 채우며 잘못된 키 데이터는 안전한 기본값으로 복구한다.

이동/소모품의 PlayerInput 키보드 바인딩만 실행 시 재지정한다. 터치, 마우스, 게임패드 바인딩은 유지한다. 캐릭터 액티브(신이의 누르고 유지 포함), 대쉬, 모든 공통 상호작용, 혈전 과충전, 함정 탈출 방향 입력, 탐험 기록도 같은 저장 값을 읽는다. 소모품 UnityEvent는 performed 단계에 한 번만 실행하며 일시정지·키 설정 중에는 사용하지 않는다.

액티브/소모품 HUD, 상호작용 안내 키캡, 혈전 안내, 탐험 기록 도움말도 저장한 키를 표시한다. 테스트용 단축키에 기능을 할당한 경우 그 키의 디버그 기능은 실행하지 않는다.

## 검증

Unity 실행 항목: `Vampire.Tests.Editor.KeyboardBindingsSmoke.Run`.

실제 Level 1 UI 클릭과 Input System 키 입력으로 저장·취소·초기화, 충돌 확인, 필수 키 누락, 기본/보조 키, 이동·대쉬·액티브·소모품, 메뉴 전환, 설정 중 Space/Tab 오작동 방지, 화면 크기별 표시를 검사한다. 테스트 전 설정을 백업하고 종료 후 복구하며 랭킹 기록에서는 제외한다. 화면 증거는 `Library/KeyboardBindingsProof`에 저장한다.

이번 변경은 Junhan2 소스에만 반영한다. 바탕화면의 일반 실행판·페스티벌 데모 실행판과 웹 배포는 갱신하지 않는다.

검증 결과: 2026-10-27 Unity Editor의 Level 1에서 65개 검사 통과. 변경한 키의 실제 이동·대쉬·액티브·소모품 동작과 상호작용 안내, 과충전 입력, 일반/축소 화면을 확인했다.
