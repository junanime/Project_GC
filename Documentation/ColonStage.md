## 초기 배치와 이동

상자24 / 상인12 / 혈전14 / 엘리트제단8 / 골드병20 / 실버병8 = 86개를 로딩 아래에서 모두 배치한다. 벽·구멍·이동 불가능 영역을 피하고 내부 벽을 포함한 여유 거리를 확보한다. 혈전 HP는180이며, 격파·미니스테이지 입장·원래 혈전 옆 귀환을 지원한다. 미니방 귀환 시 전체 배치를 다시 생성하지 않는다. 미리 배치하는 필드에서는 여러 혈전의 입구가 각각 유지되고, 다음 필드로 넘어갈 때 이전 필드의 남은 입구를 제거한다.

## 임시 출전 선택 / 스테이지 2 직접 입장 — 2026-11-09

출전준비에서 출전하기를 누르면 위장(1) / 대장(2)을 선택한다. 취소하면 선택한 장비와 아이템이 유지된다. 대장 직접 입장은 출전준비의 캐릭터·장비·기본 능력치로 시작하며, 기존 입구 열림 → 캐릭터 퇴장 모션 → 1초 대기까지 게임 시간을 멈춘다. 86개 필드 오브젝트와 선택 미니보스 거주지 6곳의 배치 완료 후 시작한다.

직접 입장은 별도 난이도이며 정상적인 스테이지 1 클리어 후 진입은 위의 기존 성장형 수치를 그대로 사용한다. 웹 1스테이지 한정 빌드에서는 대장 선택을 막는다. 임시 직접 입장은 일반 랭킹에 제출하지 않는다.

- 일반몹 등장 시점·비율: 직접 입장은 스테이지 1 시간표를 스테이지 2의 대응 8종으로 매핑한다. 기존 성장형 스테이지 2의 빠른 후반종 도입 때문에 같은 시각의 난이도가 과도하게 올라가는 것을 방지한다.
- 일반몹: 스테이지 1 일반몹 8종의 순서별 체력에 1.10~1.20배. 접촉 피해·이동 속도·경험치 보상은 대응하는 스테이지 1 몬스터 기준. 스테이지 2 외형과 크기는 유지.
