## 현재 구현

스테이지 1에서 사용하던 플레이어·증강·스킬·아이템·유물 런타임을 유지한 채 대장으로 이동한다. 이동 수단과 첫 보스 격파 대화는 [수륙양용 캡슐](AmphibiousCapsule.md)을 따른다. 예전 부스러기 잠수복 경로는 사용하지 않는다.

- 승인된 첫 대장 시안의 외형, 독립 S자 내부 능선, 오른쪽 돌출벽을 유지한다.
- 위장과 동일한 203.2381 × 135.4921 월드 영역, 18-unit 청크, 0.05084381-unit 바닥 픽셀을 사용한다. 96개 청크가 절대좌표 UV를 공유한다.

- 일반 8종, 특수 9종(새 외형 6종 + 재사용 3종), 일반에 대응하는 엘리트 8종. 기존 음식 보스 5종을 그대로 사용한다.
- 런타임 Blueprint 복제만 사용하며 스테이지 1 원본 데이터는 바꾸지 않는다. 미니스테이지는 원래 Blueprint·스프라이트·크기·투사체를 복원한다.
- 오리지널 9강 이후 지존 확정 규칙은 추가하지 않는다.
- 두 필드의 혈전 합계28개에 맞춘 랭킹 서버 검증 소스도 포함한다. 원격 게시는 이번 범위에 포함하지 않았으며 다음 온라인 QA 배포 시 `CloudCode/QaRun.js`를 게시해야 한다.

새 종류의 비중은 30초 동안 부드럽게 전환한다. 최신 종류 64%, 직전 종류 24%, 이전 종류 합계 12%를 기준으로 정규화한다. 한 종류만 열려 있으면 그 종류가 100%다. 스테이지 1의 시간별 총 스폰량과 8분 이후 +30%를 유지한다. 아직 등장하지 않은 종류를 앞당겨 생성하지 않는다.

일반 경험치는 2·10·50 중 하나다. 초반은 2(50%)/10(50%), 마지막 종류는 2(10%)/10(80%)/50(10%)이며 중간 종류는 확률을 선형 보간한다. 평균 경험치는 6→13.2다. 위장 후반의 누적 레벨에 필요한 경험치를 고려해 대장에서도 추가 강화를 얻을 수 있도록 했다. 재화 확률은 1골드 36%, 2골드 18%, 5골드 6%, 미드랍 40%다. 플레이어의 현재 공격력에 맞춰 적 HP를 자동 증가시키지 않는다.

## 엘리트

- 대응 일반 몬스터 몸체의 2배 크기, 체력 4.5배, 공격력 1.45배, 이동 속도 1.06배.
- 실버 1~2를 3회 지급(총3~6), 기본 5골드 + 추가 5골드×4 = 25골드, 경험치10(25%)/50(75%), 평균40. 실버병 전용 추적기만 활성화된 씬에서도 대장 엘리트 보상이 지급되며 일반 몬스터의 실버 지급 규칙은 바꾸지 않는다. 기존 제단 완료 보상은 별도 유지한다.
- 혈전 과충전과 제단은 현재 시간에 열린 대장 엘리트만 선택한다. 초반에 종류가 부족해도 현재 종류를 반복해 요청된 동시 등장 개수를 유지한다.
- 일반·엘리트 모두 동일한 승인 스프라이트와 크기 기반 피격·바닥 충돌을 사용한다.
