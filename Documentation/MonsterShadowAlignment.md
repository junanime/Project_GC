# 몬스터 바닥 그림자 정렬 — 2026-10-05

죠스바의 그림자를 발 사이로 올리고 폭을 줄였다. 함께 확인된 정예 초록 슬라임의 머리 쪽 그림자, 무지개 벌레의 작은 그림자, 소금·후추의 가로 치우침도 보정했다.

실제 필드 프리팹과 블루프린트 조합 25개를 비교했다. 15개 외형에 착지 중심·폭·두께를 지정하고, 원본 외형을 공유하는 정예 6개에도 같은 비율을 적용한다. 각설탕과 미니 달팽이의 기존 전용 그림자 처리는 유지한다. **자폭 몬스터와 도넛은 공중 몹이므로 본체와 그림자 사이의 기존 세로 간격을 유지한다.** 세균형 부유 몬스터도 기존 바닥 높이를 유지한다.

## 동작 기준

- `MonsterBlueprint`의 `groundShadowCenterUV`와 `groundShadowSizeUV`는 이미지 사각형 내부의 정규화 좌표다. 투명 여백, 무기와 날개 대신 발·몸통의 접지 부분에 맞춘 값이다.
- 처음 걷기 프레임을 기준으로 착지 위치를 고정한다. 점프·걷기·반동 때문에 스프라이트 모양이 변해도 그림자가 위아래로 튀거나 늘어나지 않는다.
- 좌우 반전 시 비대칭 발 위치를 함께 반전하고, 정예 크기 및 성장 배율은 그림자에도 동일하게 적용한다.
- 재사용되는 몬스터는 다음 생성 전에 원래 그림자 위치·크기·정렬 순서를 복구한다. 다른 외형이나 전용 그림자 처리로 이전 보정이 넘어가지 않는다.
- 필드와 미니스테이지가 공유하는 생성 경로에서 각 몬스터의 초기화 완료 후 보정한다.
