# 스테이지 1·2 특수 몬스터 개편 — 2026-11-10

이번 Junhan2 소스 변경은 기존 대장 특수몹을 유지하면서 신규 능력 5종을 추가하고, 팝콘 포메라니안 자리의 외형·행동을 비트 두더지로 교체한다. 신규 능력 5종과 교체 두더지를 합치면 새 제작 대상은 6종이다. 최종 구성은 일반 8종 / 특수 14종 / 대응 엘리트 8종 / 선택 미니보스 6종이다. 변비왕은 필수 최종보스로 예약하며 아직 구현하지 않는다.

소수 개수는 확률적으로 올림한다. 예를 들어 원래 2마리라면 연속 입장에서는 평균 2.5마리다. 매 회차에 항상 25%가 정확히 추가되는 뜻은 아니다. 버퍼는 두 종류 합계 예산을 보존하면서 검은목이 1 + 흰목이 1을 같은 프레임에 가까운 유효 바닥에 배치한다. 버퍼 하나의 종류만 나오는 회차는 없다. 신규 상한에 걸리면 밀린 몬스터를 쌓아 한 번에 생성하지 않고 다음 주기로 넘긴다.

- 신규 5종 접촉 피해: 직접 입장 5 / 연속 입장 10. 신규 고유 피해는 기포 9.1 / 14, 결정 파편 11.7 / 18, 똥폭탄 15.6 / 24다. 방어·무적 등 기존 피해 규칙을 거친다.
- 균사: 처음 연결할 때 벽 가림을 검사한다. 연결 후 거리나 벽 때문에 끊기지 않고 시전자를 처치해야 해제된다. 이미 부활한 몬스터·엘리트·보스·특수몹·혈전·체력 버프 중인 대상은 새로 연결하지 않는다. 연결된 대상은 체력 버프 중복 대상에서도 제외한다.
- 부활 대기 때 점수·처치 이벤트·전리품을 지급하지 않는다. 최종 처치 때 1회만 지급한다. 대기 도중 봉합사가 죽으면 부활을 취소하고 정상 처치로 마무리한다. 같은 적을 반복 부활시켜 보상을 얻을 수 없다.
- 소금 파편은 4방향으로 최대 4유닛, 1.15초 동안 이동하고 벽에서 멈춘다. 하나의 파편은 플레이어에게 한 번만 피해를 준다. 기존 투사체 봉인/반응 등록을 따른다.
- 쇠똥구리는 투척 준비 중 피격하면 똥을 바닥에 떨어뜨리고 도망간다. 떨어뜨린 똥은 무해하며 착지 후 3초 안에 사라진다. 정상 투척 적중은 이동속도 30% 감소와 갈색 묻음 효과를 2.5초 적용한다. 다시 준비할 때까지 6초의 간격이 있다.
- 신규 5종은 각 50점, 경험치 10, 50% 확률로 5골드를 드랍한다. 보호막 대상 일반몹으로 분류하지 않는다.

## 버퍼 4종 공통

- 스테이지 1 소금 / 스테이지 2 검은목이: 이동속도 +20%, 파란 `+` 표시.
- 스테이지 1 후추 체력 버퍼 / 스테이지 2 흰목이: 최대·현재 체력 +25%, 빨간 `+` 표시. 피해 감소 방식은 제거했다. 별도 공격속도 디버프 몬스터는 기존 기능을 유지한다.
- 시전 0.9초, 적용 반경 1, 버프 5초, 재사용 4초. 재시전은 남은 시간만 갱신하고 배율 중첩이나 반복 회복은 만들지 않는다. 종료 시 현재 체력 비율을 유지하며 최대 체력을 원복한다.
- 두 효과가 겹치면 파란색과 빨간색 `+`가 함께 보인다. 벽 너머·보스·혈전에는 적용하지 않는다.
- 소금·후추는 본체를 크게 흔드는 헤드뱅잉과 가루 낙하, 버섯은 겹친 윗부분이 좌우로 펴지고 떨리는 모션을 사용한다. 사망·풀 반환 시 변형과 표시를 정리한다.

## 비트 두더지와 상어 연출

두더지는 기존 경험치·골드 탐색 및 저장 보상을 계승하고 크기/속도 성장만 제거했다. 한 개를 먹으면 2초간 멈춰 씹고, 0.35초 잠수 → 1.5초 이동 → 0.35초 재등장한다. 땅속에서 직접 타격·넉백은 막고 지속 피해는 받는다. 이동·섭취·반환 보상 좌표 모두 벽 판정을 거친다. 먹은 보상은 1회 반환하며 특수몹 처치 점수도 정상 집계한다. 스테이지 1 팝콘 포메라니안의 성장 기믹은 유지한다.

바게트상어는 대기 지느러미와 소환/패턴 지느러미 모두 하단에 납작한 연속 물결 3겹과 작은 거품을 표시한다. 지느러미의 실제 바닥점과 이동 방향을 따라 효과가 이동하며 원근/폭은 지느러미 크기에 맞춘다.
