# 첫 발견 튜토리얼 — 게임 적용

## 범위

선택한 **크림 카드** 기본형([무기 시안](Concepts-v1/01-cream-card.png) · [이벤트 시안](Concepts-v1/09-stage-event-cream-card.png) · [몬스터 시안](Concepts-v1/10-special-monster-cream-card.png))으로 패널을 한 종류만 사용한다. 상단 띠에 `새 무기` / `스테이지 이벤트` / `특수 몬스터`를 구분하고, 왼쪽에는 혁이가 등장하는 12프레임 반복 동작 예시, 오른쪽에는 **발생 효과**와 **대응 방법**을 각각 한 문장으로 표시한다. 뒤쪽 전투 화면은 어둡게 가리고, 패널이 열린 동안 전투 시간을 멈춘다. `확인` 또는 `Esc`로 닫고 `다시 보기`로 예시를 처음부터 재생한다.

## 발생 시점과 저장

| 종류 | 첫 표시 시점 | 구분 기준 |
|---|---|---|
| 특수 증강 21종 | 출전 후 새 특수 무기를 처음 획득한 뒤, 증강 선택창이 닫힌 직후 | 증강 종류별 |
| 스테이지 이벤트 7종 | 해당 이벤트가 시작된 직후 | 이벤트 종류별 |
| 특수 몬스터 10종 | 해당 필드 몬스터가 처음 생성된 직후 | 몬스터 에셋 종류별 |

동일한 콘텐츠는 해당 기기의 저장값에 한 번만 기록된다. 한꺼번에 여러 콘텐츠를 발견하면 순서대로 표시한다. 시작 장비는 새 획득으로 취급하지 않는다. 미니스테이지용 몬스터 스폰은 필드 첫 발견을 소모하지 않는다. 예를 들어 타코야키 저격수 안내를 본 뒤에는 저격수가 다시 나와도 안내가 없지만, 소금 버프 몬스터는 처음 나타날 때 별도 안내가 열린다.

계정 저장 기능을 도입할 때는 `tutorial.first-discovery.v1.*` 키를 영구 성장 데이터에 포함해야 다른 PC에서도 본 안내가 반복되지 않는다. 개발 중에는 해당 키만 지우면 첫 등장 검증을 다시 할 수 있다.

## 영상 자산

- 실제 게임의 혁이·몬스터 PNG를 합성하고, 게임 규칙에 맞춘 발사체·범위·경고 효과를 그린 **동작 예시**다. 실제 플레이 화면을 녹화한 영상은 아니다.
- [GIF 38종](Demos/)은 팀의 검토용이며 게임 빌드에는 넣지 않는다. 게임 안에서는 같은 12프레임을 담은 [시트 38종](../../Assets/Resources/TutorialClips/Sheets/)을 시간에 따라 순환 표시한다. GIF 디코더가 필요하지 않다.
- [콘텐츠별 문구와 영상 키](../../Assets/Resources/TutorialClips/catalog.json)가 단일 목록이다. [생성 스크립트](../../Tools/TutorialClips/generate.py)를 다시 실행하면 GIF와 시트가 함께 갱신된다.
- 확인하기 좋은 예시: [빙결침](Demos/ice.gif), [화염침](Demos/fire.gif), [위산분비](Demos/acid_event.gif), [타코야키 저격수](Demos/sniper.gif), [소금 버프 몬스터](Demos/salt.gif).

## QA

1. 처음 특수 무기 선택 후 카드가 열리고, 닫은 뒤 게임 시간이 다시 흐르는지 확인.
2. 같은 무기·이벤트·특수 몬스터는 재등장 시 열리지 않는지 확인.
3. 다른 콘텐츠는 각각 별도로 열리는지 확인.
4. 증강 선택창, 출전 준비 및 설정 화면을 가리지 않는지 확인.
5. 16:9 이외 해상도, UI 확대, `Esc` 닫기, 타이틀 복귀 후 시간 배율 복구 확인.

자동 검사는 `TutorialGuideTests`의 목록/영상/키 검증과 `TutorialGuidePlaySmoke`의 실제 게임 패널 열기·일시정지·중복 방지·다른 몬스터 표시 검증으로 구성했다. 향후 계정 저장과 영상 표현을 확장할 때는 튜토리얼 완료 키 버전과 각 애니메이션의 실제 패턴 일치 여부를 함께 검토한다.
