# 아이템 상자 보상과 획득 연출 — 2026-10-14

## 일반 아이템 상자

| 보상 | 확률 |
|---|---:|
| 체력 회복 | 53% |
| 자석 | 14% |
| 빨간 물약 | 12% |
| 폭탄 | 8% |
| 골드 30 | 8% |
| 골드 80 | 5% |

총합 100%. 기존 체력 회복 100% 때문에 폭탄 추첨 구간에 도달하지 못하던 설정을 수정했다.
골드 80은 기존 큰 주머니 이미지를 사용하며 실제 기본 지급량은 80이다. 골드 획득 배율은 기존 규칙을 따른다.
다른 보상 풀의 골드 50 및 특별 상자 확률은 유지했다.

## 획득 동작

- 공통 Chest 경로에서 상자를 열면 기존 튀어나오는 모션을 끝까지 재생하고 바닥에 놓인다.
- 플레이어의 현재 획득 범위와 겹치면 캐릭터에게 흡수된다. 상자 보상은 자동 수집 유물이 있어도 등장 모션과 획득 범위를 지킨다.
- 소모품이 보관함 UI까지 날아가는 경로를 제거했다. 캐릭터 위치에 도착하면 보관 수량만 갱신한다.
- 흡수 중에도 보관 공간을 예약하므로 동시에 주워도 최대 보유량을 초과하지 않는다. 가득 찼으면 바닥에 남고, 공간이 생기면 다시 획득 가능하다.
- 폭탄은 기존 연결된 도트 이미지를 사용한다. 획득 시 저장되며 자동으로 폭발하지 않는다.
- 일반 필드 경험치/골드의 자동 수집은 유지한다. 풀 재사용 시 상자 전용 획득 제한이 초기화된다.

## 검증

Unity 2022.3.62f3에서 ChestLootSmoke 실행 PASS.
Level 1 실제 상자 생성/열기/물리 트리거/보관 경로를 사용해 6종 전부 검증했다.
10만 회 추첨: 골드 30 8.114%, 골드 80 4.912%, 물약 11.814%, 자석 13.916%, 회복 53.221%, 폭탄 8.023%.
골드 30/80 실제 지급, 등장 중 획득 차단, 범위 밖 대기, 캐릭터 흡수, 초과 보유 방지, 공간 확보 후 재획득, 일반 골드의 자동 수집을 확인했다.
폭탄 드랍 스크린샷은 Proof/bomb-pop-out.png, 확인 항목은 Proof/checks.txt에 저장했다.
공유 링크 배포 및 모바일 압축 빌드는 실행하지 않았다.
