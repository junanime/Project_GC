## 아이콘 후속 수정 · GitHub 배포 패키지

- 사용자가 바탕화면 아이콘이 흰색으로 나온다고 보고했다. 실행 대상은 실제 리디렉션된 설치 경로였으나 별도 IconLocation은 이전 경로여서 불일치했다. 이전 검사만으로 Windows 셸 표시까지 검증됐다고 볼 수 없었다.
- 실제 바로가기 대상 폴더에 원본 기반 ICO를 배치하고 바탕화면/시작 메뉴 참조를 수정했다. 사용자가 **혁이 아이콘으로 보임**을 확인했다.
- 다음 설치 패키지는 별도 아이콘 경로 대신 실제 exe 아이콘을 상속한다. 검증 도구도 실제 바로가기 대상을 기준으로 검사하도록 수정했다.
- GitHub 배포 패키지 v0.1.20260929.1: **447,683,291 bytes**, SHA-256 `D9CAD0D27028BBF3AF7256A905013DE07E985EE1CAE1BEE9D3992B504DA5770B`.
- 빠른 zlib 패키징 사용. 게임 exe/데이터는 이전 검증 빌드와 동일하며 플레이 안내/기존 라이선스/출처 문서를 추가했다.
- 수정 패키지의 업데이트 설치 성공. 문서를 포함한 173개 파일 SHA-256, 실제 바로가기 대상/작업 폴더, 제거 등록 검증 통과.
- 사용자는 직접 게임을 확인한 결과 게임 안에서는 문제가 없다고 보고했다. 아래의 에이전트 단기 QA 기록은 당시 관찰을 보존한다.

- 짧은 조작 테스트에서 Insert 키 입력 후 보스 소환을 확인하지 못했다. 자동 입력 전달 문제인지 게임 조건 문제인지는 구분하지 않았으며, 성공으로 집계하지 않는다. 실제 키보드 재검증 필요.
- 기존 Level 1 `MapPanelRoot`, `MapViewport`의 missing-script 경고 2건을 확인했다. 이번 설치/아이콘 작업에서는 맵 구조나 게임 로직을 수정하지 않았다.
- 장시간 플레이, 보스 전체 패턴, 여러 PC, Steam 클라이언트 설치·업데이트·동기화는 이번 검증 범위 밖이다.
- 계정 인증/클라우드 동기화는 미구현. 사용자가 영구 성장만 저장하고 진행 중인 판은 이어하지 않기로 확정했다. 기존 로컬 저장 체계를 보존했으며 새 저장 형식이나 서버를 구현했다고 주장하지 않는다.
- 설치 파일은 미서명 테스트 배포본이다. Windows 보안 경고 우회나 보안 설정 변경은 수행하지 않았다.
