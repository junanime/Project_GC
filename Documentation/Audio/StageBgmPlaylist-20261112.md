# 스테이지 공용 BGM · 2026-11-12

Junhan2의 기존 필드 음악에 승인된 네 편곡을 추가한다. 스테이지 0·1·2는 아래 다섯 곡에서 각각 같은 확률(20%)로 한 곡을 선택한다. 새 스테이지 진입 때만 다시 선택하고 선택된 곡을 반복한다. 연속해서 같은 곡이 선택될 수도 있다.

기존 음원은 수정하지 않는다. 신규 편곡도 승인 선율의 음정·시점·길이·템포·악기를 유지한다. 기존 게임 음원을 밑음으로 합성하지 않고 별도로 연주한 편곡이다.

## 음질 검수 및 보정

- 신규 네 곡: 44.1 kHz, 스테레오, PCM 16 bit WAV.
- 클리핑 샘플 0, 루프 끝/시작 샘플 차이 0, MIDI 피치벤드 0. 기준 선율의 노트 시점·음정·길이 일치.
- 태엽·포자·물방울은 기존 필드곡과 음량을 맞추기 위해 약 -0.56~-0.57 dB 선형 게인만 적용했다.
- 달빛 B는 18.095~30.000초 사이 기타 응답 11음의 강한 어택만 완화했다. 각 어택에 4ms 진입·20ms 약 -5dB·40ms 복귀 음량 곡선을 적용했다. 최대 인접 샘플 변화는 약 0.830에서 0.464로 감소했다. 멜로디·악기·템포를 바꾸지 않았다.
- EQ·리미터·전체 컴프레서·피치 조정은 추가하지 않았다.
- 이는 파형·주파수·악보에 따른 기술 검수다. 사람의 청취를 대신하거나 모든 청취 환경의 주관적 불쾌감 부재를 보증하는 결과는 아니다.

## 재생과 전환

- 기존 `GameAudioManager`의 기본/보스·미니/증강 BGM 채널을 그대로 사용한다.
- 증강 선택 → 직전 필드곡 또는 보스·미니곡 일시정지 → 선택 완료 시 같은 곡의 같은 위치에서 재개한다.
- 혈전 미니 스테이지 → 필드곡 일시정지 → 기존 미니곡 재생 → 퇴장 시 필드곡 재개한다.
- 보스 전투/메인화면/인트로/음악 설정의 기존 규칙을 유지한다.
- 스테이지 0→1, 1→2는 Unity 씬을 재사용하므로 `LevelManager.BeginNextStage`에서 별도 곡 선택을 요청한다. 로딩 오버레이가 끝나기 전에는 필드곡 재생을 보류한다.
- 게임 종료 시 음악 및 대기 중인 재생 요청을 취소한다.
- 음악 전용 난수기를 사용하므로 음악 추첨이 몬스터·보상 등의 Unity 난수 진행에 영향을 주지 않는다.
- null 및 중복 추가 클립은 추첨에서 제외한다. 새 곡이 연결되지 않은 이전 설정에서는 기존 곡으로 동작한다.

## 임포트

기존 필드 BGM과 동일한 스트리밍·Vorbis 품질 1.0·원본 샘플레이트·스테레오 설정이다. 무압축 WAV를 원본으로 보관하고 플레이어 빌드에서는 Unity가 압축한다. 신규 WAV 원본 네 개의 합계는 약 43.0 MiB이며 이것이 배포 용량을 뜻하지는 않는다.

## 검증

실행 검사: `Vampire.Tests.Editor.StageBgmPlaylistSmoke.Run`

Unity 2022.3.62f3 실제 Editor Play Mode 실행: **149개 확인 통과, 실패 0**. 실제 메뉴에서 스테이지 0·1·2로 진입해 필드 음악 선택, 증강/미니/보스 전환과 중첩, 재생 위치 복귀, 볼륨·일시정지·종료를 확인했다. 128회 추첨에서 다섯 곡 모두 선택되었고 게임 난수 상태가 유지됐다. 이 결과는 Windows/WebGL 배포 빌드 재검증이나 인간 청취 평가를 뜻하지 않는다.

음질 및 실행 검사 요약은 [StageBgmQA-20261112.json](StageBgmQA-20261112.json), 승인 편곡 악보는 `Scores/`의 MIDI 네 개에 보관한다.
