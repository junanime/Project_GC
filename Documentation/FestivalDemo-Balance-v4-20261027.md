# 페스티벌 v4 · 45초 밸런스 재검증

2026-10-27. 행사 전용 feature/festival-demo의 로컬 검토안이다. 사용자 확인 전 커밋·푸시·설치판 갱신은 진행하지 않는다. 원본 Junhan2 브랜치에는 적용하지 않는다.

## 목표와 해석

목표는 중급자 기준 각 캐릭터 약 10회 중 2회 완주다. 아래 수치는 실제 Unity 장면·물리·피해·스폰·스킬을 실행한 자동 입력 결과이며, 사람의 숙련도를 검증한 모델이나 실제 참가자의 성공률 추정치가 아니다. 캐릭터별 10회는 작은 표본이므로 행사 참가자에게 20% 성공률을 보장하지 않는다.

## 적용 전 판단

현재 중급형 자동 입력 결과는 전체 40회 중 10회 완주(25%)이고, 아시·혁이는 각 4/10, 아리·신이는 각 1/10이다. 목표인 캐릭터별 약 2/10에 정확히 맞춘 상태는 아니다. 자동 입력의 아리 돌진 경로 선택과 신이 연료 회수·분사 판단에는 한계가 있으므로 이 숫자를 사람의 실력별 성공률로 해석하지 않는다. 시작 체력 후보(아시 65 / 혁이 80 / 아리 300 / 신이 170)는 검토 대상이며 사용자 확인 전 배포하지 않는다.

실제 행사 전에 짧은 수동 체감 확인을 권장한다. 한 표본의 성공 횟수만 맞추기 위해 난수 결과나 판별 난이도를 바꾸지 않았으며 모든 참가자에게 같은 설정을 적용하는 구조다. 수치를 다시 조정하면 해당 설정으로 별도 검증 기록을 남겨야 한다.

## 입력 조건

- 두 입력 프로필은 같은 게임 설정을 사용한다. 프로필에 따라 체력, 적 공격력, 스폰량, 무적, 보상을 바꾸지 않는다.
- 이동·대시·화염 조준 방향은 행사 PC의 WASD처럼 8방향으로 제한한다.
- 각 프로필·캐릭터에 공통 초기 난수값 10종을 사용했다. 전투 행동과 VFX에 따라 이후 난수 소비는 달라질 수 있으므로 완전히 동일한 후속 적 배치를 뜻하지 않는다.
- 초심형: 약 0.85~1.25초마다 이동 판단, 가까운 적만 피하고 대시는 적어도 7초 간격, 첫 액티브는 10초 이후 사용한다.
- 중급형: 약 0.3~0.45초마다 주변 위험과 통행 가능한 방향을 비교한다. 대시는 약 2.8초 간격으로 쓰고, 아리 변신 중에는 가까운 적을 향해 대시하되 충전 사이에는 안전한 방향으로 걷는다.
- 신이는 실제 연료를 소비한다. 중급형은 가까운 불씨를 안전한 방향에서 회수하고, 화염 중에는 적을 바라보다 밀접한 위협이 생기면 회피한다. 적 탄환이나 미래 위치를 미리 읽지는 않는다.
- 획득한 소모품은 실제 보관함을 통해 사용한다. 중급형은 체력이 30 이상 부족하면 회복하고 주변 적이 많을 때 폭탄을 쓴다. 초심형은 5초 간격으로 확인하고 체력이 40% 미만일 때 회복한다. 보관함에 없는 아이템을 만들거나 지급하지 않는다.
- 벽, 대시 충전, 스킬 쿨타임, 고귀 과제, 피격, 실제 게임 종료 판정을 그대로 사용한다. 체력 보충·무적·강제 성공은 없다.
- 사용자 요청에 따른 네트워크 이동 중단 전 완료한 22회와 재개 후 58회를 합쳤다. 재개 시 동일 설정을 확인하고 완료한 판은 건너뛰며, 중단된 판의 미완료 스폰 로그는 제외했다.
- 반복 비교는 30Hz 고정 진행 간격을 사용했다. 해당 로그의 프레임 시간은 성능 측정으로 사용하지 않는다.

## 기능 검증

- 기능 검사 145개를 통과했고 최종 반복 전투 80회를 실행했다. 이는 기능 오류 검사 통과를 뜻하며 목표 성공률 달성을 뜻하지 않는다. 오류 로그는 비어 있으며, 아래 요약에는 사용한 설정·검증 코드의 해시를 함께 보관한다.
- 로딩 뒤 안내가 타이머·전투를 멈추고, 클릭/Space 해제 후 재개한다. 안내를 닫은 입력으로 액티브가 중복 발동하지 않는다.
- 아시 액티브 10초, 아리·혁이 사용 시작부터 20초 재사용을 검사했다. 실제 스킬 상태를 0·20·40초 순서로 진행해 세 번 사용할 수 있고 20초 전에는 사용할 수 없는지 검사했다.
- 신이 준비 0.3초·기본 140 DPS, 혁이 준비 0.6초·상태이상 대상 25% 추가 피해를 검사했다. 일반 모드의 원래 수치가 유지되는지도 별도로 검사했다.
- 실제 산성몹 자폭을 완료시켜 특수 처치 점수가 증가하지 않음을 확인했다. 직접 타격으로 처치하면 특수 처치가 정확히 한 번 증가한다. 일반 30점 / 특수 150점이다.
- 보스 제단 비활성, 골드 이벤트 제외, 양쪽 재화 병과 드랍 차단, 일반 동전 생성 차단을 검사했다. 캐릭터별 1,000개 등간격 확률 입력에서 폭탄 300개 / 체력 회복 700개를 확인하고, 실제 무작위 추첨 100회씩에서도 두 종류만 나오는지 검사했다. 일반 모드 동전 생성은 유지된다.
- 반복 실행에서는 허용한 두 특수몹만 등장하는지, 저격 실제 생성 거리가 3.8~5.2인지, 완주마다 저격 2마리·산성몹 5마리가 등장하는지, 적 95마리 상한·레벨 1·재화 미생성이 유지되는지 검사했다.
- 참가자 기록과 분리된 Library 테스트 저장소를 사용했다. 종료 기록 저장 재시도, 캐릭터별 로딩·게이지, 냉기 장판 수명·불투명도 등 기존 기능도 함께 검사했다.
