# 처방전·혈전 리메이크 검증 — 2026-10-01

대상: Junhan2, Unity 2022.3.62f3, Windows / RTX 3060. 본 기록은 자동 검사와 실제 Unity 화면 확인이며 장시간 수동 플레이를 완료했다는 의미가 아니다.

## 최종 에디터 검증

- EditMode 전체 **68/68 통과**, 실패·누락 0. 기존 63개 + 처방전 전용 5개.
- 실제 Level 1 Play Mode **132개 검사 통과**, 검사 중 Error/Exception/Assert 없음.
- 실행 로그: `remake-editmode-final.xml`, `remake-play-acceptance.log`.

### 확인 범위

- 지정 태그 안에서만 서로 다른 목표 3개 추첨, 진행 상한, 상태 복사/복원, 완료 취소선·접기/펼치기.
- 네 캐릭터의 강화 단계와 상한, 반복 복원 시 중복 배율 방지, 패시브/액티브 두 카드, 중복 선택 차단, 모두 최대 레벨일 때 회복·귀환.
- 실제 몬스터 사망 이벤트로 플레이어 안/적 밖 인정, 플레이어 밖/적 안 불인정 확인. 체류형 자동 누적·이탈 정지·재진입 재개·일시정지 정지 확인.
- 입구의 격화 상태 전달, 기존 엘리트 생성, 일반 수집 방 2개 및 격화 방 4개의 보상→귀환 연결.
- 격화 미스터리 전부 당첨·하나 선택, 네 번째 자폭 몬스터 구분, 음식 폭발 예약, 저격 발사 후 재배치.
- 비활성 방 3종이 일반/상위 후보에서 빠지는 규칙과 자산 유지.
- 전설 후보 3개, 중복 수령 방지, 선택 중 HUD 숨김, 전설 12종 이름/설명 영역 내 표시.

방 완료·목표 누적 일부는 직접 호출해 검사 시간을 줄였다. 미니스테이지 전체를 정상 조작으로 매번 클리어한 기록은 아니다. 수집으로 추가 레벨업 선택창이 뜨면 자동으로 하나를 선택한 뒤 다음 검사를 진행한다.

## Windows 빌드·실행

- Development Windows x64 빌드 **Succeeded, errors=0**. 최종 로그 `remake-windows-build-final.log`.
- 실행 파일: `Builds/ApothecaryPlayer/24tu.exe` (빌드 산출물은 Git에 넣지 않는다).
- 기존 캐릭터 실행 회귀 **161개 검사 통과**: 아시 12, 혁이 37, 신이 58, 아리 54. 네 실행 모두 종료 코드 0.
- 아시·신이·아리는 같은 게임 코드의 첫 빌드에서 확인했다. 이후 혁이 검사 초기화만 보완해 재빌드하고 혁이 37개를 최종 확인했다.
- 혁이는 기본 Lv.1 확률 10%, Lv.5 확률 28.561%, 쿨타임 ÷2.8561, 최대 레벨 차단, 실패 누적/확정 빙결 분리·저장 복원을 확인했다.
- 혁이 검사에서 숨긴 창의 실행 중단을 막고, 테스트 시작 전 자동 공격이 누적했을 수 있는 실패 횟수를 초기화했다. 플레이용 기본 확률을 검사에 맞춰 낮추거나 바꾼 것은 아니다.
- 실행 로그: `ashiSkillsSmoke-remake.log`, `hyukiRemakeSmoke-remake-final.log`, `shiniSkillsSmoke-remake.log`, `ariSkillsSmoke-remake.log`.

위 로그는 작업 폴더에 보관한다. 68개는 NUnit 테스트 수, 132/161개는 자동 플레이 검사 내 검증 항목 수이며 모두 서로 다른 수동 플레이 사례라는 뜻은 아니다.

## 검사 중 해결한 문제

- 죽는 중인 자폭 몬스터를 귀환 정리 시 생존 목록에서 다시 제거하던 오류 수정.
- 저격 방 정리 시 소유 몬스터와 예약 재배치도 해제.
- 보상 선택 중 기존 일시정지 버튼으로 전투가 재개되지 않도록 보호.
- 전설 카드에 처방전/설정 버튼이 겹치던 문제 수정.
- 기존 카드의 음수 텍스트 여백과 한 줄 설명 영역 때문에 긴 설명이 제목/버튼으로 넘치던 문제 수정.
- 상자 애니메이션과 수집 경험치로 늦게 뜨는 선택창을 자동 검사가 기다리도록 보완.
- 화면 밖으로 크게 나가던 과충전 원을 반경 4.5에서 2.5로 조정.

## 시각 검증

처방전, 스킬 강화, 과충전, 전설 선택을 1280×720 실제 씬 렌더로 확인했다. 이미지와 초기 수치는 [구현 기준](PrescriptionRemake.md)에 포함한다. 기존 한지 패널·책 배경·스킬 아이콘을 재사용했고 외부 이미지나 실행 파일을 추가하지 않았다.

## 남은 QA

- 일반 플레이에서 전설 획득까지 걸리는 시간과 태그별 난도 편차, 캐릭터별 Lv.5 효율, 혈전 25마리/25초 체감 난도.
- 낙하 음식 폭발 회피, 저격 재배치 압박, 여러 상태이상·전설 조합의 장시간 검증.
- 모바일 터치 경로는 연결했지만 Android/iOS 실기기 조작·가독성·성능 검증은 미실시.
- 기존 Level 1의 `MapPanelRoot`, `MapViewport` 미연결 스크립트 경고 2건이 빌드에 남아 있다. 이번에 해당 씬의 기존 컴포넌트를 임의 삭제하지 않았다.
