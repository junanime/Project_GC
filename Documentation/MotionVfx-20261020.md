# 이동 잔상 / 침 소멸 VFX 확정 (2026-10-20)

- 이동 잔상: B안(짧은 궤적). 아시=민트 바람, 아리=크림색 깃털, 혁이=청색 서리 궤적, 신이=주황 불꽃.
- 침 소멸: A안 공용 금빛 별. 시안의 선형 크기 2/3 (.48 → .32 world units; 확대·소멸 곡선 전체에 동일 비율 적용).
- 실제 이동 시 .21초 간격, .6초 동안 축소·페이드. 이동 방향을 따라 발뒤에 남으며 텔레포트 구간을 채우지 않음. 정지·포털 이동·사망 시 새 잔상 없음.
- 침 소멸 .28초. 기존 침의 범위 종료/소멸 경로에서 재생되며 적 탄환에는 적용하지 않음. 기존 관통·유도·귀환 판정은 유지.
- 기존 흰색 이동 파티클과 침 소멸 파티클 재생을 대체. 새 원화는 `MotionVfxPrompts.json`에 기록한 image_gen 생성물, CharacterTrails=B atlas, NeedleEnd=A atlas에서 승인한 부분만 Sprite로 등록.
- VFX는 게임 시간에 따라 일시정지되고, 씬 소유 128개 제한 풀로 재사용됨. 증강 전용 이펙트가 아니므로 증강 투명도 설정 대상에는 추가하지 않음.

## 검증

실제 Main Menu → 로딩 → Level1 진입 후 네 캐릭터 모두 확인. 캐릭터별 실제 침 사거리 끝 소멸 4회(총 16회), 캐릭터별 잔상 이미지, 이동/정지 후 소멸, 좌/상/하 방향, 일시정지, 200회 동시 발생 시 128개 풀 상한과 소멸 검사 통과. 각 캐릭터의 실제 화면 캡처로 시각 확인.

재검증: Unity `-batchmode -executeMethod Vampire.Tests.Editor.MotionVfxSmoke.Run` (그래픽 활성). 결과와 캡처는 `Library/MotionVfxQA`에 기록. 테스트는 랭킹 제외, 튜토리얼 열람 상태/재화는 종료 시 복원. 테스트에서 배경 몬스터·자동 전투를 중지하여 VFX만 검증하며, 전투 밸런스나 플랫폼 빌드를 검증한 것은 아님.
