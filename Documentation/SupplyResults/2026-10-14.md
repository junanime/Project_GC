# 보급 캡슐과 탐험 결과 통계

## 적용 범위

- 개발 브랜치 Junhan2. 공유 링크 빌드·서버에는 반영하지 않는다.
- 새로고침(민트)과 건너뛰기(코랄)는 기존 중심에서 좌우 같은 간격으로 배치한다. 호버/선택/누름에 따라 본체 색을 바꾸지 않고 금빛 테두리 효과를 유지한다. 소진된 새로고침은 비활성 표시한다.
- 건너뛰기는 현재 제안만 소비하며 증강을 지급하지 않는다. 레벨과 이어지는 보상 대기열은 유지한다.

## 보급 흐름

- 초기 밸런스: 한 판에 두 번, 플레이 중 4~6분과 9~11분 사이 무작위 예고. 일시정지 및 미니스테이지 안에서는 보급 시간이 흐르지 않는다.
- `잠시 후 보급 캡슐이 드랍됩니다!` → 4초 대기 → 6초 낙하 → 총 10초 후 착지하며 `보급 캡슐이 드랍되었습니다!`.
- 위치는 예고 시 플레이어 주변 6~9 월드 단위에서 장애물을 피하여 고른다. 착지 후 지도에 보급 아이콘을 표시한다.
- 원본 캡슐 PNG를 유지하며 크기는 아시 기준 가로 약 4배(3.28). 양 끝 둥근 부분이 시작되는 어깨에 작은 낙하산을 각각 연결한다.
- 낙하와 착지는 같은 스프라이트·크기를 사용한다. 착지 후에만 상호작용 콜라이더와 기존 E 키캡이 활성화된다. 착지에 분홍색 물방울, 낙하산 페이드 연출이 나온다.
- 상호작용하면 원본을 두 부분으로 나눈 메시의 오른쪽 부분이 아래쪽 연결부를 축으로 회전한다. 틈에서 황금 구슬이 튀어나오고, 착지한 구슬은 플레이어의 획득 범위에 들어오면 흡수된다.
- 상점 UI의 배너·배경·아이콘 프레임·버튼을 재사용한다. 왼쪽 유물 후보를 고르면 오른쪽에 해당 설명이 표시되고, 획득 버튼으로 확정한다.
- 현재 보유하지 않은 유물 중 중복 없는 3개를 제안한다. 취소해도 구슬과 후보는 유지한다. 획득은 기존 유물에 추가되며 영구 해금·로비 장착값을 바꾸지 않는다.
- 추가 유물은 탐험 기록과 런 스냅샷에 포함된다. 동일 유물 중복 획득은 막는다.

## 결과창

- 전투 기록: 플레이 시간, 처치 수, 코인, 레벨, 공격 기여도 합계, 받은 피해, 실제 회복량, 실버.
- 공격 기여도: 기존 피해 추적에 기본 침을 추가. 피해 상위 4개와 나머지 합계(기타 증강), 백분율 문자 없이 피해 수치만 표시한다.
- 막대 색은 양 결과창 모두 빨강 → 주황 → 노랑 → 초록 → 회색. 막대 길이는 전체 기록 피해에 대한 비율이다.
- 이벤트 기록: 미니스테이지 성공, 엘리트 처치, 일반 몬스터 처치, 보급 유물 획득 횟수. 실패 후 귀환만 허용된 미니스테이지는 성공으로 세지 않는다.
- 기존 4개 탐험 기록 칸은 실버·아이템·유물·증강으로 유지한다. 실버는 아이콘과 실제 재화 수치, 나머지는 보유한 오브젝트의 아이콘을 표시한다.
- 아이콘은 위에서 아래로 채운 뒤 옆 열로 이동한다. 항목이 많으면 모든 셀을 함께 축소하며 마스크로 영역 밖 표시를 막는다. 마우스를 올리면 이름/설명을 확인할 수 있다.
- 성공의 섹션 제목은 분홍색, 실패는 보라색으로 통일한다.

## 검증 실행

Unity 2022.3.62f3에서 `Vampire.Tests.Editor.SupplyResultsSmoke.Run`을 실행한다. 결과 및 실제 플레이 캡처는 `Library/SupplyResultsProof`에 저장된다. 테스트가 변경하는 재화·튜토리얼 확인 값은 종료 시 복원한다.

원본 캡슐 및 새 낙하산은 무압축 PNG이며, 런타임 스프라이트 영역은 투명 여백을 제외하도록 메타데이터에서 지정한다.

## 검증 결과 (2026-10-14)

Unity Editor Play Mode 검증 PASS. 실제 씬에서 버튼 클릭, 낙하 중 입력 차단, 정지 시 낙하 정지, 착지 후 키캡, 개봉과 구슬 생성, 획득 범위 내 구슬 자동 획득, 유물 선택 중 레벨업 대기, 취소 후 동일 선택지, 추가 유물 효과·런 저장 복원·탐험 기록 표시를 확인했다. 피해 합계와 기타 합산, 1~150개 아이콘의 영역 내 배치, 성공·실패 화면도 검증했다. 수치는 화면 밀도 검증용 테스트 데이터이며 밸런스 측정 결과가 아니다.
