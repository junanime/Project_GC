# 2026-10-21 스테이지 1 웹 배포

## 변경 사항

- 탐험 기록의 지도에 마우스 휠 및 두 손가락 확대·축소(1~5배), 드래그 이동을 추가했다. 지도와 위산 표시·발견한 오브젝트의 위치가 함께 확대된다. 아이콘 자체는 최대 1.35배로 제한해 서로 가리지 않도록 했다.
- 모바일 HUD 오른쪽 아래에 액티브 스킬 버튼을 복구했다. 기존 아이콘, 쿨타임, 신이의 길게 누르기 입력을 사용한다. PC는 R키를 사용하며 패시브·상호작용·대쉬 버튼을 다시 표시하지 않는다.
- 구 스테이지 2의 달팽이·크림 배경, 정의, 설치/테스트 도구 및 진행 로직을 제거했다. 스테이지 1 보스 보상 상자와 탈출구는 보존했다. 탈출구에 들어가면 성공 결과로 종료한다. 위산에 잠긴 탈출구는 사용할 수 없다.
- 웹 그림 압축 적용 범위를 256×256 이상으로 확대했다. PC는 DXT Crunch, 모바일은 ASTC 4×4를 사용하며, 그림의 원본 해상도와 프레임을 유지한다. Gzip 및 해시 파일명을 사용한다.
- 기기 선택 페이지와 모바일 조작 안내를 현재 HUD에 맞게 수정했다. 인트로 동영상의 MIME 형식도 배포 서버에서 제공한다.
- 실제 PC 브라우저에서 Unity Services Wire의 `getDynCaller` 누락 오류를 발견했다. `Prepare-WebPortal.cjs`가 프레임워크의 기존 `dynCall`을 사용하는 호환 함수를 연결한다. 함수 인수·반환값, 압축 해제, Unity Gzip 식별자와 재실행 안전성을 검사한다. 원본 C# 게임 로직은 변경하지 않는다.

## 검증

- Unity 실제 Level 1: `MobileHudSmoke` 42개 검사 통과. 액티브 실제 발동, 조이스틱과 버튼의 간섭, 세 화면 비율의 안전 영역, 휠·두 손가락 입력, 확대 상한/하한, 일시정지 입력 해제, 스테이지 1 탈출 성공을 확인했다.
- 모바일 웹 로딩 셸: 17개 검사 통과.
- 모바일 다운로드 메모리 처리: 10개 검사 통과.
- 웹 콜백 호환 처리: ABI 및 Unity 압축 식별자 검사 통과.
- 기기 선택 페이지: PC, Android, iPhone Safari/Chrome, 인앱 브라우저 안내 등 48개 검사 통과. 배포 서버 16개 검사 통과.
- 실제 PC WebGL에서 입장 및 지도 휠 확대·축소를 확인했다. 모바일 WebGL은 Chrome 터치 에뮬레이션으로 입장, 아시 액티브 발동, 두 손가락 확대·축소를 확인했다.
- 삭제된 Stage 2 GUID가 남은 씬·프리팹·에셋·재질·애니메이터에 참조되지 않는지 확인했다.
- 데스크톱 Chrome의 터치 에뮬레이션은 실제 iPhone Safari의 메모리·발열·성능 검증을 대체하지 않는다.

## 배포

빌드 출력:

- `Builds/WebDemo-PC-20261021-stage1`
- `Builds/WebDemo-Mobile-20261021-stage1`

새 임시 주소: https://uses-jenny-exchange-bridges.trycloudflare.com

기존 주소는 만료되었다. 새 주소의 기기 선택 페이지에서 PC/Android/iPhone을 고르면 해당 빌드만 다운로드한다. 호스트 노트북과 터널을 종료하면 연결되지 않는다.

| 빌드 | 압축 게임 데이터 | 전체 빌드 크기 |
| --- | ---: | ---: |
| PC | 514,992,465 B (약 515 MB) | 559,983,129 B (약 560 MB) |
| 모바일 | 351,249,017 B (약 351 MB) | 396,244,080 B (약 397 MB) |

전체 크기는 Unity 빌드 시점 기준이며 배포 페이지/호환 처리 파일에 따라 소폭 달라진다. 두 빌드의 포함 씬은 메인 메뉴와 Level 1이며 `stageCount=1`, `stageTwoAssetsExcluded=true`를 확인했다. 외부 주소에서 선택 페이지, PC/모바일 시작 페이지, 빌드 정보 및 압축 데이터 부분 다운로드 응답을 확인했다.
