특수몬스터 추가 제안: 요구르트 기포는 폭발 직전 실제 반경 0.6의 링, 가스주머니균은 밀어내는 방향을 보여주는 짧은 가스 흔적. 쇠똥구리 오염/감속은 현재 피해가 무적으로 막혀도 적용되는 정책을 유지했으며, 회피 시 상태이상까지 피할지는 별도 결정 가능하다.

신규 실제 화면 검수에서 추가로 남은 구도 개선점:

- 상어 수직 도약 정점에서는 일부 본체가 화면 위로 나간다. 착지 그림자는 유지되지만 공중 위치 표시나 높이·카메라 조정으로 읽기 쉽게 만들 수 있다.
- 일부 소환·공격 장면에서 상단 발견 알림이나 보스 체력바가 머리를 가린다. 알림 표시 우선순위와 보스 카메라 여백을 조정할 후보이다.
- 배매너티 본체·꼬리와 거주지의 그림 테마는 신규 화면에서 확인했다. 문 닫힘·구멍 출입 일부는 이번 캡처 구도에서 화면 밖에 있어, 그 접합까지 시각 검수를 완료했다고 보지는 않는다.

## 저장 보호

자동 에디터 검사에서 계정 인증·랭킹 전송·기존 대기 점수 전송을 차단한다. 일반 실행파일에는 적용하지 않는다. 진행도·장비·발견 기록은 검사 전 별도 백업과 검사 종료 후 비교로 보존했다. 확인한 74개 값에서 에디터·일반 게임 진행 데이터 모두 시작 전과 동일했고, 강제 복원이나 삭제가 필요한 값은 없었다. 일반 게임 저장 영역에는 쓰지 않았다. [확인 결과](checks/progress-preserved.json)

개인정보와 인증 캐시는 이 문서 및 저장소에 포함하지 않는다. 검수 과정에서 에디터가 자동 변경한 폰트 캐시·기존 이미지 플랫폼 설정·프로젝트 설정의 재직렬화는 최종 변경에서 제외했다.
