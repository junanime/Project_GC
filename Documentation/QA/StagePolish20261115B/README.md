회전용 그림은 내장 이미지 생성 도구로 기존 `Pose_003`의 색·외형을 참조해 새로 만든 8방향 시트이며 `Spin.png`로 추가했다. 기존 원화를 그대로 돌리거나 사진의 일부를 변형한 것으로 설명하지 않는다. 시트 PNG는 생성 결과를 그대로 보관하고, 게임에서 8개의 부분 영역을 잘라 사용한다. 새 3D 모델은 사용하지 않는다. [원화 출처와 생성 기록](asset-source.md)

밤 회수는 외형 복제나 체력 회복이 아니다. 실제 S02 개체의 남은 체력·피격 판정·상태이상·생성 세대를 유지한다. 귀환 대상은 보스가 소환한 살아 있는 밤이며, 14 이내에서 이동 속도 4.3으로 접근하고 0.42초 동안 올라간다. 4.5초 안에 도달하지 못하면 벽을 통과시켜 강제 안착하지 않고 제어를 풀어준다. 보스 중단·사망에서도 살아 있는 밤의 일반 동작으로 복구한다. 회수·방출만으로 처치 점수가 생기지 않으며, 실제 처치는 기존 보상을 한 번만 지급한다. 풀 반환 후 남은 이전 제어가 새 개체를 막거나 덮어쓰는 경우도 별도로 검사했다.

공격 종류를 새로 늘리거나 체력·공격력을 다시 조정한 작업은 아니다. 기존 공격의 접촉 시점과 그림을 맞추고 준비·회복 연출을 다듬었다. 기존 보스 이미지 파일은 유지하면서 거북이 회전용 시트를 추가했다. 따라서 회전 중 모든 그림이 이전 원화와 완전히 동일하다는 의미는 아니다.

## 촬영 방식과 적용 범위

GIF의 입력은 Unity 실제 플레이 모드에서 게임 카메라가 렌더링한 프레임이다. 별도로 흉내 낸 애니메이션이나 프레임 보간을 사용하지 않았다. 보스 상호작용과 실제 패턴 실행 함수를 사용하며, 재현을 위해 선택 보스·플레이어 위치·무적·카메라 중심 등을 검사 코드로 통제한다. 사람이 게임 창을 직접 조작하며 전 구간을 플레이한 수동 검수와는 구분한다.

- 보스 촬영은 실제 게임 시간 기준 30fps다. 거북이 및 대부분의 스테이지 2 보스는 기본 확대를 유지하고 중심을 맞춘다. 상어는 도약을 볼 수 있게 구도를 조정하고, 매너티는 집·경고·플레이어가 화면 UI에 가려지지 않도록 검사 카메라를 맞춘다. 게임의 일반 카메라 설정은 바꾸지 않는다.
- 스테이지 2 검사 장소는 다른 보스 거주지가 장면을 가리지 않는 열린 공간으로 잡았다. 일반 플레이의 보스 배치를 제거하거나 바꾸는 작업은 아니다.
- 매운맛은 15fps, 원 사이 통로를 확인하기 위한 맵 전체 시점이다. 배치 비교 GIF는 이후 두 이벤트의 예고 장면을 이어 붙인 것이다.
- 스테이지 1 액체 촬영은 1280×720, 검사 시 카메라 확대를 7.6으로 맞췄다가 촬영 후 복구한다.
- GIF는 촬영 프레임의 색을 GIF 팔레트로 변환하므로 원본 화면과 미세한 색 차이가 있을 수 있다. 재생 속도는 원래 게임 시간에 맞춘다.

구현·실제 실행 검수·GIF 갱신은 완료했다. 개인 플레이 진행값은 편집기와 데스크톱 양쪽에서 원래 값과 같음을 확인했다. 재임포트 과정에서 생긴 무관한 파일은 변경 대상에서 제외했다. 구현과 이 검수 자료를 같은 `Junhan2` 커밋에 포함한다. 이번 요청에는 데스크톱 실행파일 패치나 노션 업데이트가 포함되지 않는다.
