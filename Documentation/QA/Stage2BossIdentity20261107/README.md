# 두 중간보스 외형 정합 수정 · 2026-11-07

밤송이고슴도치와 배매너티의 소환 원형을 모든 파생 애니메이션의 기준으로 통일했다. 외형이 다른 이동/공격 시트를 섞던 것이 원인이었으며, 높이만 맞추는 대신 동일한 원본·몸체 배율·기준점으로 다시 만들었다.

| 대상 | 적용 내용 |
|---|---|
| 밤송이고슴도치 | 큰 얼굴, 귀, 넓은 황금 가시, 짧은 발 유지. 소환·대기·20프레임 보행·밤알 없는 보행·8개 공격 자세 교체. 실제 S02 밤알 3개를 자세별 부착점에 배치하고 가시 전경이 밑단을 가림. |
| 배매너티 | 둥근 배 몸통, 큰 볼, 짧은 앞지느러미, 부채꼬리 유지. 소환·대기·40프레임 유영·8개 자세 교체. 꼬리 연결점을 고정한 연속 변형과 동일한 피벗 사용. |
| 파이프 얼굴 | 매너티 원본 기준 (84,108)을 얼굴 중심으로 삼아 눈과 볼이 함께 보이게 보정. 열린 입구 하나에서만 노출. 입 발사 위치도 원본에 맞춤. |
| 상태색 | 독·부식·빙결·화염의 공통 색상 순환이 고슴도치 가시 전경보다 위에 표시되도록 처리. 다른 대상의 기존 정렬값을 낮추지 않음. |
| 침 부착 | 새 원형의 알파에서 부착 마스크 34개를 재생성. |

## 범위와 유지 사항

기준 몸체 폭 고슴도치 4.0 / 매너티 4.4 유닛. 체력 28,000 / 30,000, 피해·이동 속도·기술 구성·보상·배치 확률은 변경하지 않았다. 다른 4종의 아트는 교체하지 않았다. 실제 전투 시작 판정과 등장 중 무적 등 기존 규칙을 유지한다.

## 검증 자료

- `asset-result.txt`, `asset-checks.txt`: Unity가 임포트한 1,048개 검사. 프레임 사각형·기준점·PPU·Point·FullRect·투명 여백·중립 픽셀 일치·알파와 침 마스크 전체 비교.
- `capture-result.txt`, `capture-errors.txt`: 실제 Unity 등장·이동·고슴도치 4개 기술·매너티 5개 기술의 완주 결과.
- `identity-runtime-checks.txt`: 실제 독/부식을 함께 부여한 고슴도치에서 색상 교대와 전경보다 높은 정렬 확인. 독 피해도 확인하며 실패 시 캡처 전체를 FAIL 처리한다.
- `smoke-result.txt`, `smoke-checks.txt`, `smoke-errors.txt`: 6종·25개 기술의 기능 회귀 검사. 상태이상·시간 정지·침 부착·기술 도중 사망·복수 보스·클리어 분리 포함.
- `capture-geometry/`: 촬영 프레임의 스프라이트·피벗·배율·월드 좌표·가림 상태 기록.
- `art-provenance/`: 원본과 파생 시트의 정체성 검사 결과.

GIF는 실제 게임 카메라를 사용하되 검수를 위해 일반몹을 멈추고 플레이어를 무적으로 설정했다. 구간 사이 관찰 위치는 조정했다. 보행 자체는 실제 추격 이동이며 보스 몸체를 임의 경로로 옮긴 시뮬레이션이 아니다. 상태색 확인 스크린샷은 별도 검증 포즈다. 자동 검사 수는 사람의 플레이 횟수나 밸런스 성공률을 뜻하지 않는다.

실행: `ColonBossPresentationCapture.Run -colonIdentityReview=1` 및 `ColonBossSmoke.Run`. 특정 보스만 재검증할 때 `-colonCapture=Hedgehog` 또는 `-colonCapture=Manatee`를 추가한다.
