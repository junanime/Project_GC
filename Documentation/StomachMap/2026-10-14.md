## Scale

The attached reference is 1177×805; its image interior is approximately 1164 pixels wide. The central yellow mark occupies 7×6 pixels. The requested half-width is 3.5 pixels at that overview scale.

Ashi's opaque idle width is approximately 330 source pixels (alpha > 128), at 675 PPU and the actual 1.25 visual scale: 0.611111 world units. Map image width is therefore 0.611111 × 1164 / 3.5 = **203.2381 world units**, or **332.571 visible Ashi widths**. Height is **135.4921** units. Character and gameplay camera scale have not been changed.

The latest floor reference (`codex-clipboard-05094d95-eb0a-4b33-ad89-5b741cca04a3.png`, 891×894) supersedes the initial needle-handle pixel sizing. Its yellow box spans 56×86 pixels. Use its **height** as Ashi's visible idle height (276 source pixels / 675 PPU × 1.25 = 0.511111 world units); the box is a proportion guide, not a request to stretch Ashi into a tall rectangle.

One full material tile now spans **5.313178 world units** (0.511111 × 894 / 86). With 104.5 painted cells per tile, the terrain grid is **0.050844 world units** per cell, approximately **5.93×** the first needle-based version. Map dimensions and character size are unchanged.

## Rendering

- A cleaned AI-authored macro layout preserves the approved bean silhouette, upper-right esophagus, lower-left outlet and curved walls. All slime/bubble/sparkle decoration is removed.
- The existing AI-authored material texture supplies the exact approved peach/rose motif colors at the new reference size. Its original contrast and density are preserved using one sample, rather than washing out the colors or adding a second rotated motif. Macro shading controls the bowl/rim lighting; the low-resolution map is not enlarged with nearest-neighbor filtering.
- 12×8 mesh chunks (96 total), up to 18×18 units, share one material and absolute world coordinates. Frustum culling avoids submitting the entire map at ordinary gameplay zoom. No huge full-map bitmap allocation is required.
- Mirrored detail samples avoid wrap discontinuities. Fine detail fades at subpixel scale in overview captures to avoid shimmer.
- Textures are imported uncompressed, with mipmaps for the macro/detail layers. Source images remain intact.
- Legacy infinite-background component remains available to existing systems and Stage 2; its renderer is disabled on the Stage 1 field. Detached mini-stage room visuals remain separate.
