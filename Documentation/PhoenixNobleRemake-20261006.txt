- 족자 3개를 클릭으로 함께 말아 올리고 빛나며 공개하는 기존 연출 유지.
- 첫 클릭은 공개만 수행하며 공개가 끝난 다음 선택 가능. 일시정지 중에도 공개 연출 진행.

- 피해량, 공격 주기, 사거리, 발사 수, 보호막 수, 판정 범위 변경 없음.
- 비활성 고귀증강인 독 전염은 제외.

이름 / 연출 의도 / 유지하는 기능
생명연소 → 봉심연소
먹색 날개와 가슴의 작은 붉은 불씨. 체력 1 및 회복 불가, 공격 강화 유지.
분신배양 → 쌍봉분신
옅은 잔영 날개로 분신과 본체 구분. 분신 추종 및 현재 침 기반 공격 유지.
고슴도침 → 봉익윤무
수직으로 세운 깃털의 원형 공전. 충돌 시 잔깃 결계가 맥동.
회전 위치와 피해 판정은 유지하고 깃털 자체의 월드 회전만 고정.
잔깃은 장식이며 새로운 발사체/추가 피해를 만들지 않음.
대물침 → 천공봉침
하나의 긴 봉우와 붉은 끝점에 기운이 모이는 차지 연출. 기존 차지/발사 유지.
이기어침 → 유영봉우
묽은 먹의 8자 비행 궤적과 깃털 잔광. 실제 구현인 8자 궤도 유지.
주의: 이전 현지화 설명의 마우스 추적은 현재 동작과 달라 설명에서 제거.
신경차단 → 봉명진혼
봉황 깃털 인장과 작은 청록 가로 울림. 기존 화면 내 적 정지 유지.
장기압착 → 봉인흡진
안으로 말려드는 먹 나선과 봉익 인장. 기존 흡인 및 지속 피해 유지.
위산 연동파 → 봉황파동
바깥으로 퍼지는 깃털 파문. 기존 피해와 밀치기 유지.
점막 요새 → 삼중봉익
겹친 날개막과 작은 비취 봉인점. 기존 실드 누적/피격 소모 유지.
헝그리정신 → 고고한 봉황
길어진 꼬리 깃과 작은 붉은 중심점. 기존 픽업 미획득 누적/획득 초기화 유지.
샷건침 → 산개봉우
부채꼴 깃털 잔광. 기존 침의 단거리 일제사격/장전/대쉬 재장전 유지.

표현 방식
전투 VFX는 Unity 메시로 날개, 깃털, 파문을 구성한다.
패널/아이콘은 내장 이미지 생성기로 제작한 비트맵을 사용한다.
Assets/Resources/PhoenixNoble/Scroll.png: 공통 한지 족자.
같은 폴더의 11개 타입별 PNG: 투명 배경 먹 그림 겸 아이콘.
검정/회색 먹을 주색으로, 심장의 적색 또는 작은 비취/금색 점을 제한적으로 사용.
텍스트는 그림에 합성하지 않고 실제 UI로 렌더링하여 수정 가능성과 배치 일관성을 확보.
원본 생성 파일은 보존하고 이미지 프롬프트는 PhoenixNobleArtPrompts-20261006.txt에 기록.
기존 VFX가 수명, 좌표 추종, 실제 반경 기반 크기, 렌더링 순서를 계속 관리한다.
먹색/회색에 얇은 한지색 외곽선을 두어 어두운 바닥에서도 읽히게 한다.
기존 VFX 풀을 재사용하며, 새 효과에는 Collider와 피해 처리를 넣지 않는다.
효과 종료 및 씬 전환 때 메시는 부모 수명에 따라 종료/정리한다.
동작 줄이기 설정에서는 추가 회전/맥동을 생략한다.
