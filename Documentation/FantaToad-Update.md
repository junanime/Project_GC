# 환타 두꺼비 — 2026-10-06

## 적용 범위와 의도

사용자가 선택한 중간 도트(B) 주황색 탄산 두꺼비 시안을 기준으로 기존 위산 두꺼비를 교체했다. 크림색 배, 볼 속 액체, 등의 탄산 방울, 얼굴과 네 발의 특징을 유지한다. 픽셀을 흐리지 않도록 Point 필터와 비압축 텍스처를 사용한다.

- 이동 8 + 대기 8프레임: `Assets/Resources/ToadUpdate/ToadLocomotion.png`
- 볼 팽창 8 + 발사/수축 8프레임: `ToadAttack.png`
- 준비/도약/착지 8프레임: `ToadJump.png`
- 화면 가장자리 얼굴 16프레임, 미니맵·화면 밖 방향 표시 공용: `ToadHead.png`
- 탄산액 줄기 4 + 구체 4프레임: `AcidFx.png`

이름·최초 등장 안내·지도 표기를 환타 두꺼비로 변경하고, 공유 얼굴 및 발사체를 사용하는 스테이지 이벤트도 탄산액 발사로 일치시킨다. 줄기 내부 색과 착지 파문 역시 주황 계열이다. 다른 위산 장판·무기 효과는 변경하지 않는다.

## 유지되는 동작과 호환성

달팽이 보스 대비 80% 크기, 체력 1200, 7분~7분 30초 사이 1회 등장, 구체 3발/점프/연속 발사 패턴과 피해량·속도는 유지한다. 각 모션 첫 프레임 기준 월드 폭과 지면 피벗을 맞추고 교체 후 가시 외형 판정 데이터를 다시 생성한다.

기존 클래스명과 리소스 경로, 에셋 GUID는 직렬화 연결 보존을 위해 유지한다. `monster/acid-toad`, `event/acid-reflux` 튜토리얼 저장 키도 유지하므로 이미 확인한 안내가 재등장하지 않는다. 기존 사용자 설정 및 관련 없는 이미지 메타데이터 수정은 커밋에 포함하지 않는다.

## 이미지 제작

내장 이미지 제작 도구를 사용했다. 승인 시안을 외형·스타일 기준으로, 기존 5개 시트를 프레임 배치·동작 기준으로 제공해 각각 제작했다. 전체 프롬프트는 `FantaToad-art-prompts.json`에 보관한다. 생성 원본을 남기고 프로젝트 에셋에 복사했다.

## 검증

Unity 2022.3.62f3에서 에셋 검사 36개, 미니보스 전투 회귀 검사 34개, 최초 안내·지도·판정 회귀 검사 44개, 총 114개를 통과했다. 컴파일 오류 없이 두 플레이모드 검사 모두 정상 종료했다.

프레임 수·주황색 팔레트·투명도·Point 필터·스프라이트 참조·크기 기준·이름·저장 키를 확인했다. 실제 플레이 캡처에서 기본 공격/연속 발사/점프/화면 가장자리 얼굴과 튜토리얼·방향 표시를 확인했고, 새 이미지의 입 위치에 맞춰 발사 시작점을 보정했다. 줄기 시작의 둥근 캡이 얼굴 위로 돌출하지 않도록 제거했다.

검사 로그: 프로젝트 상위 `work/fanta-smoke2.log`, `work/fanta-discovery.log`. 캡처: `Library/ToadUpdateProof/`, `Library/DiscoveryProof/`. 독립 실행 설치본은 이번 요청 범위가 아니므로 다시 빌드하지 않았다.
