# 대장행 수륙양용 캡슐 — 2026-10-23

기존 보스 부스러기 드랍·잠수복 착용을 대체한다. F 시안의 민트 튜브와 C 시안의 후방 프로펠러를 조합했다. 바퀴와 부스터는 없다.

## 플레이 흐름

1. 스테이지 1 보스를 쓰러뜨리면 기존 보스 도주 구멍과 보상 상자를 남기고, 플레이어 근처 안전한 바닥에 새 캡슐을 낙하산으로 내린다. 낙하 2.6초, 착지 후 낙하산이 접혀 사라진다. 그림자는 바닥에 있고 착지 물방울은 접촉 후 발생한다.
2. 최초 1회에만 착지 후 하단 한의사 대화를 표시한다. 첫 문장: `{캐릭터 이름}! 위장의 일을 해결했구나. 정말 수고 많았다!`. 다음 버튼을 누르면 `계속 수고해라.`. 끝 버튼으로 닫는다. 아시/아리/혁이/신이 이름을 사용한다. 표시 기록은 `24tu.tutorial.first-boss-capsule.v1` PlayerPrefs에 즉시 저장해 재실행·다른 캐릭터에서도 반복하지 않는다.
3. E / 모바일 오브젝트 터치로 탑승한다. 중앙 양문이 열리고 캐릭터가 안으로 들어가며 문이 닫힌다. 승객의 외부 그림자·전투 게이지를 숨긴다.
4. 프로펠러가 회전하며 8초 동안 좌측 하단 출구까지 이동한다. 바닥에서는 튜브로 미끄러지고 위산에서는 튜브 중간을 수면으로 삼아 하반부를 가린다. 접촉 물결과 부유 흔들림이 이어지고 위산 피해·침식은 받지 않는다. 위산 정리 로직은 캡슐을 삭제하지 않는다.
5. 출구 앞에 정차하고 구멍을 연다. 화면 전체가 5갈래 곡선 나선으로 2초 동안 닫힌 뒤 기존 로딩창이 나온다. 추가 출구 상호작용은 필요 없다.
6. 대장 필드 오브젝트 배치를 완료한 뒤 검은 화면에서 역순으로 2초 동안 열린다. 이후 기존 대장 입구 개방, 캐릭터별 혈전 퇴장 모션, 1초 정착 및 시간 재개를 유지한다.

연출 중 게임 진행과 몬스터를 일시 정지한다. 위산 수위는 유지하되 수면·비 애니메이션은 계속 재생한다. 튜토리얼은 버튼을 누를 때까지 기다리고, 대화가 끝나면 캡슐 탑승 전까지 평상시 조작으로 돌아온다. 보스 추격 구멍은 향후 스페셜 보스 스테이지용으로 유지한다.
