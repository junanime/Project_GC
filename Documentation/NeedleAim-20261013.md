# 기본 침 자동 조준 / 유도침 곡선 추적

## 확정 동작

- 기본 침은 발사 시 사거리 안의 가까운 공격 가능 몬스터를 조준한다. 발사 후에는 직진하며 재조준하지 않는다.
- 표적이 없으면 마지막 자동 조준 방향을 유지한다. 캐릭터 이동, 대쉬, 액티브 스킬 방향은 변경하지 않는다.
- 필드를 한 번 클릭하거나 터치하면 다음 **한 발**의 발사 방향만 지정한다. 추가 투사체는 자동 조준과 기존 부채꼴 분산을 적용한다. 발사 간격과 피해량은 유지한다.
- UI 버튼, 조이스틱, 일시정지 화면의 입력은 방향 지정을 하지 않는다. 아이템 추가 발사는 예약한 한 발을 소비하지 않으며, 이기어침·산탄·대물침의 수동 조작은 유지한다.
- 유도침은 **발사 직후부터** 비행 중 적을 향해 부드럽게 회전한다. 표적이 유효한 동안 유지하고 죽거나 탐지 범위 밖으로 나가면 재탐색한다. 사거리 끝에서 추적을 시작하는 안은 폐기했다.

## 거리와 강화

실제 스테이지 1 아시 대기 스프라이트의 가로 크기는 약 0.82037 월드 단위(443px / 675 PPU × 씬 비주얼 배율 1.25)다.

| 항목 | 기본값 | 기준 |
| --- | ---: | --- |
| 침 최대 비행 거리 | 2.733333 | 아시 약 3⅓개 길이, 이전 4.1의 ⅔ |
| 유도침 탐지 반경 | 3.28 | 아시 약 4개 길이, 이전 4.92의 ⅔, 비행 중 침 위치 기준 |

- 사거리 강화는 최대 비행 거리에 적용된다. 비행 거리는 곡선 궤적을 따라 누적하며, 유도침이라고 무한히 날아가거나 추가 거리를 얻지 않는다.
- 기존 `추적 시야`는 탐지 범위 +14%, `유도 선회`는 회전 반응 속도 +6%, `추적 정밀도`는 유도 대상 적중 피해 +8%를 유지한다. 탐지 강화와 비행 사거리 강화는 별도다.
- 일반 침의 사거리 끝 소멸 효과와 침귀환의 기존 귀환 분기는 유지한다.
- 특수 증강의 한국어/영어 설명, 튜토리얼, 오리지널 설명, 탐험 기록의 기본 침 설명을 갱신했다.

## 검증

Unity 2022.3.62f3의 실제 스테이지 1 씬에서 `Vampire.Tests.Editor.NeedleAimSmoke.Run`을 실행한다.
검증 대상은 아시 실제 크기와 거리 강화, 표적 유효성, 실제 다중 발사 중 수동 방향 1회 소비, 아이템 추가 발사의 예약 보존, 마우스 누름/유지, UI 터치 제외, 다른 손가락을 누른 상태의 필드 터치, 정지 중 입력 제거, 기본침 직진, 움직이는 표적에 대한 즉시 곡선 추적, 탐지 범위 이탈, 정확한 거리 종료, 기존 소멸 파티클이다.

로그: `Library/NeedleAimSmoke.log`, 결과: `Library/NeedleAimProof/result.txt`.
실기기 모바일 QA 및 공유 링크 빌드/배포는 이번 변경에 포함하지 않는다.

## 아시 액티브 / 상호작용 표시

- 아시 액티브는 사용 즉시 버프를 적용하고 봉황·바람 연출을 캐릭터에 붙여 재생한다. 이동, 공격, 게임 시간은 계속 진행된다. 설정창 등 일반 일시정지에서는 연출과 지속시간도 함께 멈춘다.
- 상자·상인·포털 등 공통 E 키캡의 중심은 보이는 그림 위쪽에서 0.41 월드 단위(아시 가로 크기의 약 절반)에 배치한다. 스프라이트의 투명 여백, 그림자, 부가 증강 효과는 기준에서 제외한다.
- `PromptGeometryBaker`가 원본 PNG의 알파 영역을 읽어 161개 상호작용 스프라이트 경계를 저장했다. 데이터는 이름·경계만 보관하므로 다른 스테이지의 그림을 한꺼번에 로딩하지 않는다. 상호작용 그림을 교체하면 Unity의 `Tools/Junhan2/Bake interaction prompt bounds`로 다시 계산한다. 런타임 텍스처 읽기 설정이나 이미지 압축 변경은 필요 없다.

## 증강 효과 불투명도

- 설정 → 그래픽 → 디스플레이 항목 아래에 0~100% 슬라이더를 추가했다. 기본값과 이전 저장 데이터의 누락값은 100%다. 드래그 즉시 미리보기, 적용 시 저장, 뒤로 시 원래 값 복구, 기본값 복원을 지원한다.
- 플레이어 증강 효과의 고정 반투명 계수는 100%로 올렸다. 이미지 자체의 투명 가장자리, 등장·소멸 페이드와 스택별 출현 애니메이션은 유지한다.
- 소화액낭침 장판, 일반 침 증강 효과, 봉황 계열 귀족 증강, 목침/빙침 장판, 부식/표식, 분신 등 증강 전용 그림에 적용한다. 필드 이벤트 장판과 캐릭터 자체의 액티브 연출은 대상이 아니다. 0%에서도 피해·충돌·수명 계산은 그대로 실행된다.
- 공통 태그는 `AugmentVfxTag`다. 새 효과는 `SyringeAugmentVfx`/`PhoenixRadianceLayer` 공통 생성 경로를 사용하거나, 증강 전용 비주얼 루트에 `AugmentVfxTag.Mark(root)`를 호출한다. 이미지 교체 시에도 태그는 그대로 유지된다. 캐릭터/적/필드 이벤트 전체 루트에 붙이지 않는다.
- 기본 스프라이트 셰이더는 태그가 불투명도 대응 셰이더로 전환한다. 별도 커스텀 셰이더는 `_AugmentOpacity` 값을 최종 알파와 premultiplied RGB에 곱하도록 구현해야 한다. 렌더러의 기존 색상·애니메이션과 다른 MaterialPropertyBlock 값은 보존한다.

추가 실행 검증: `Vampire.Tests.Editor.LiveSkillPromptSmoke.Run`. 실제 아시의 이동·발사·봉황, 일시정지/취소, 실제 아이템 상자, 161개 경계 배치, 설정창 조작, 생성 전후 효과의 불투명도, 필드 효과 제외, 저장/복원을 확인한다. 결과와 화면은 `Library/LiveSkillPromptProof`에 저장한다.
