# 페스티벌 v6 Windows 전달본

게임 소스: `7125b309d650a9a27804c9645ca14ef120c4a3a0` (`feature/festival-demo`). Unity 2022.3.62f3 Windows x64 빌드, 45초 규칙 `festival_pc_v6_45`, Steam 기능 비활성화. 일반 Junhan2는 수정하지 않았다.

전달 폴더에는 다음 두 파일만 포함한다.

| 파일 | 크기 | 역할 |
|---|---:|---|
| `24tu-Festival-Setup-20261027-v6.exe` | 723,458,268바이트 | 게임과 필수 Unity 데이터를 포함한 설치 프로그램 |
| `인트로무한반복_기존BGM.mp4` | 4,377,140바이트 | 별도 재생용 행사 대기 영상, 사용자 원본 그대로 |

EXE 실행 → 설치 → 바탕화면 `페스티벌데모버전` 실행. 게임은 캐릭터 선택으로 시작하며 MP4를 게임 인트로로 삽입하지 않았다. 필요한 파일은 설치 시 자동으로 풀리므로 Unity/개발 도구를 따로 설치할 필요가 없다. 64비트 Windows용이며 실제 다른 행사 PC의 성능이나 보안 정책은 해당 PC에서 확인해야 한다.

## 확인한 내용

- 일반 1단계 기준 속도는 이전의80%, 2단계75%, 최종3종70%. 체력/피해/스폰량은 동일.
- 기능 검사233개와 캐릭터별 두 조작 프로필 총8회 실제 Unity 전투 완료, 오류0건. 사람의 완주율/하드웨어 FPS 추정치는 아니다.
- Windows 빌드 성공. 로컬 빌드 중 발생한 TMP 동적 글리프 캐시 및 코드 커버리지 파일 변경은 원복했다. `desktop-build.json`의 `localChangesIncluded`는 이 자동 생성 변경 때문에 true이며 게임 소스는 위 커밋과 일치한다.
- NSIS 설치 EXE 생성 완료. 데이터 압축은 무손실이며 게임 이미지/오디오나 MP4를 재인코딩하지 않았다.
- 이 노트북의 새 설치 폴더에서 실제 설치 완료. 배포 대상 파일201개를 원본 빌드와 SHA-256으로 모두 대조했다.
- 바탕화면·시작 메뉴 바로가기, 작업 폴더, 아이콘, 제거 등록 확인. 기존 행사 바로가기는 검증된 새 설치본을 가리키며 이전 바로가기 사본은 작업 출력 폴더에 보존했다.
- 설치본을 직접 실행하여 45초 캐릭터 선택 화면 및 캐릭터 전환 확인. 로비 BGM의 Loaded/READY 상태와 오류 없는 종료 로그 확인. 이 설치 확인에서는 참가자 기록을 새로 등록하지 않았다.
- 설치 전후 기존 리더보드 파일 해시가 동일하다. 게임 저장·QA 폴더는 설치 및 제거 목록에 포함하지 않는다.
- 전달 폴더의 파일 수2개, EXE/MP4 복사본 해시 확인 완료.
