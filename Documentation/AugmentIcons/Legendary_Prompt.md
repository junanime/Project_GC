# 전설증강 전용 프롬프트

《24시간의 사투》 전설증강 [증강 이름]의 정사각 아이콘. 실제 효과는 [확인된 한 문장 효과]. 승인된 전설 이미지의 도트풍 외곽, 장식 밀도와 광원을 기준으로 한다. 그림자 캐릭터가 능력을 사용하는 독창적인 장면을 중심에 구성하고, 능력에 맞는 독립적인 실루엣과 강한 발광·오라로 사각 화면 전체를 채운다. 주 동작과 효과는 작은 UI에서도 읽히게 한다. 침 자체를 중심 상징으로 반복하지 않는다. 글자·숫자·희귀도 테두리·워터마크·현대 총기·야구방망이·수류탄을 넣지 않는다. 다른 전설의 그림을 그대로 재사용하거나 색만 변경하지 않는다. 이 규칙은 전설에만 적용하며 특수증강의 고정 침 합성 규칙과 혼용하지 않는다.

이번 확정 원본: 신경차단, 장기압착, 헝그리정신, 샷건침, 위산연동파, 점막요새. `manifest.json`의 SHA-256으로 원본 파일이 변경되지 않았음을 확인한다.
