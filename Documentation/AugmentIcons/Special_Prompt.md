# 특수증강 / 보침·사침 제작 규칙

침을 생성하거나 다시 그리지 않는다. `ArtSource/AugmentIcons/NeedleMaster.png`를 고정 원본으로 사용한다. 금빛 고리, 손잡이, 은색 침의 상대 길이·두께는 변경 금지. 전체 침에 동일 배율의 확대·축소와 회전만 허용한다. 보조 효과를 별도 투명 레이어로 제작한 뒤 원본 침과 합성한다.

## 효과 레이어 생성 프롬프트

《24시간의 사투》의 [증강 이름] 아이콘용 효과 레이어. 실제 효과는 [확인된 한 문장 효과]. 이를 읽을 수 있는 보조 상징 하나 또는 두 개를 중앙에 배치한다. 기존 도트풍 장식, 픽셀풍 가장자리, 선명한 윤곽과 높은 명암 대비를 유지한다. 침은 후처리로 합성하므로 침·금고리·손잡이·은색 막대를 그리지 않는다. 투명 배경의 정사각 캔버스, 사방 안전 여백을 통일한다. 작은 UI에서 식별 가능한 고유 실루엣을 사용한다. 글자·숫자·희귀도 테두리·워터마크·현대 총기·야구방망이·수류탄 금지. 다른 증강을 색상만 바꾸어 재사용하지 않는다.

목·화염·빙결·질풍·진동은 현재 기획용 파일이다. 이미지의 상징만으로 미구현 효과나 수치를 확정하지 않는다.
