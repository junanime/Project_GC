# 캐릭터별 고귀 증강 패널 · 2026-10-15

아시·아리·혁이·신이의 승인 일러스트를 각 10종, 총 40종 연결했습니다. 혁이는 마지막으로 승인한 파란 머리·검정/흰색 W 재킷·책상 구도 수정본입니다. 아시의 바람/잎, 아리의 깃털/거품, 신이의 불씨/불꽃 등 각 캐릭터의 구도와 동작을 유지합니다.

## 표시 규칙

- 현재 Level1 플레이어의 Blueprint를 기준으로 그림을 선택합니다. 로비 선택값이 달라도 실제 플레이 캐릭터가 우선이며, 다른 캐릭터 그림으로 대체하지 않습니다.
- 40종 모두 같은 크림색·금색·민트 보석 프레임과 제목/효과명/설명 배치입니다. 카드 루트 360×540, 원본 그림 비율 유지. 캐릭터 몸을 가로로 늘리지 않습니다.
- 승인 PNG 40장은 원본 그대로 보존하고 Unity sprite rect로 그림 영역만 표시합니다. 프레임을 넘는 소품이 있는 8종은 투명 PNG로 분리해 무기 끝/깃털/불꽃을 보존했습니다. 일반 그림 영역의 좁은 가장자리만 UI 메시 알파로 연결하며, 흰 소매/깃털에 색상 키를 적용하지 않습니다.
- 이름과 설명은 이미지에 구워진 글자가 아니라 실제 능력의 최신 텍스트를 표시합니다. Cafe24 폰트, 짙은 청록색 고귀 제목·금색 그림자, 자동 크기 조정과 공통 여백을 적용합니다.
- 기존 첫 클릭 공개(0.85초)→다음 클릭 획득 흐름과 선택 잠금은 유지합니다. 공개 전에는 오버프레임 그림도 숨깁니다. 하단 건너뛰기 버튼은 큰 카드와 겹치지 않도록 별도 행에 둡니다.
- 등장 후보 10종, 획득 조건·효과·전투 VFX·저장 ID·HUD/도감 아이콘은 이번 작업에서 변경하지 않습니다. 산개봉우는 기존대로 후보 제외입니다.

## 자산·제작 기록

- `Assets/Resources/CharacterNoblePanels`: 공통 Frame.png, 승인 카드 40장, 투명 Cutouts 8장.
- `CharacterNoblePanelImporter`: 무압축·원본 해상도와 sprite rect. 웹/모바일용 압축은 이번 작업에 포함하지 않습니다.
- `ApprovedSources.json`: 승인 원본 경로·SHA-256·제작 프롬프트.
- `Artwork.json`: 프레임 밖 소품 보존을 위한 이미지 편집 프롬프트와 생성 출처. Hyuki/HeavySnipe 및 Shini/HeavySnipe는 이후 W 재킷 문양 복원본으로 적용했습니다.

## 검증 범위

Unity 2022.3.62f3의 실제 Main Menu→캐릭터 출전→Level1에서 네 캐릭터를 각각 실행했습니다. 실제 고귀 추첨/첫 클릭/공개/획득을 검사하고, 이어 각 캐릭터의 10종을 강제 표시하여 크기·그림 경로·종횡비·텍스트 잘림·공통 프레임·일반 카드 재사용을 확인했습니다. 로비 선택을 일부러 다른 캐릭터로 바꿔 실제 플레이 캐릭터가 우선하는지도 검사합니다.

최종 검사 **685개 통과**. `CharacterNoblePanelSmoke.Run` 검사 결과는 `Validation.txt`에 기록합니다. `QA/*-reward.png`는 실제 추첨 보상 화면, `QA/*-0/3/6/9.png`는 전체 디자인 확인을 위해 후보를 지정한 화면, `QA/*-sealed.png`는 공개 전 화면입니다. 캡처는 PC Unity GameView이며 모바일 실기기·자연 플레이 밸런스·전체 전투 회귀 검증은 아닙니다.

이번 작업은 Junhan2 소스/자산 적용이며 공유 링크·웹/모바일 배포를 변경하지 않습니다.
