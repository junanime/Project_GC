# 페스티벌 45초 업데이트 검증

## 범위

45초 종료, 시작 오리지널 효과 12개(각 효과 최초 획득 1회), 추가 강화 0, 모든 경험치 획득 차단, 특수몹 시간표, 전체 기록 스크롤, 이번 기록 고정, 메달, 입력란·버튼 테마, 캐릭터 능력 요약.

Unity 2022.3.62f3 에디터 플레이 모드에서 캐릭터 4종 모두 기능 검증을 진행했다. 기본 기능 검증은 198개 항목을 통과했다. 마지막 빌드 전에는 피해 배율·일반 모드 분리 검증을 추가한 동일 테스트를 다시 실행한다. 검증 장부는 Library/FestivalQA의 별도 파일이며 실제 참가자 장부에 기록하지 않는다.

## 자동 전투

초기 조정 12회와 최종 설정 20회를 진행했다. 최종 결과는 아래와 같고 원시 측정값은 [CSV](QA/Festival-45s-20261027.csv)에 보관한다. 각 전략은 같은 캐릭터 능력·생성량·체력·피해량을 사용한다. 전략에 따라 게임 난이도를 몰래 변경하지 않는다.

| 조작 전략 | 횟수 | 완주 |
|---|---:|---:|
| 느린 반응 · 드문 스킬 사용 | 4 | 0 |
| 가까운 적을 피하는 조작 | 8 | 4 |
| 주변 공간·이동 경로를 평가하는 조작 | 8 | 5 |

이 전략들은 사람의 초심자·중급자·숙련자 등급을 검증한 모델이 아니다. 자동으로 적 위치를 알며 피로·키 실수·학습 과정이 없으므로 위 성공률을 실제 참가자 성공률로 사용할 수 없다. 사람 기준 전체 약 10%, 중급자 약 10%, 숙련자 약 70%는 설계 목표이며 달성 여부는 행사 QA에서 숙련도별로 측정해야 한다.

## 최종 난이도

- 45초. 시작 일반 적 18, 일반 적 생성량 초당 10→18, 일반·특수 총 상한 95, 특수 상한 8.
- 일반 적 체력 1.25→2.4배, 이동속도 1.05→1.6배. 추가 피해는 12초까지 1배이고 45초에 3배가 되도록 완만하게 증가.
- 저격 / 이동속도 버퍼 / 방어 버퍼 / 공격속도 디버퍼를 7·13·20·27·34·40초에 순차 배치.
- 대시·보호막·방어력 판정 유지. 필드 이벤트 피해 배율 유지. 일반 모드의 피해·경험치 변화 없음.
- 신이의 행사 보정: 공격 피해 +35%, 공격속도 +20%, 최대 체력 +45. 나머지 프리셋은 기존 시작 보정을 유지.

## 확인한 경계 조건

- 시작 지급을 두 번 호출해도 오리지널이 [2,2,2]로 추가 강화되지 않음.
- 직접 경험치 지급, 모든 색상 구슬 획득 모두 레벨업 차단. 일반 모드에서는 기존 경험치 유지.
- 로딩·일시 정지 중 타이머와 추가 상자 생성 정지. 45초 종료 직후 상자 추가 생성 및 결과 뒤집기 차단.
- 저장 직후 별도 고정 기록 및 정식 순위 동시 표시, 36개 테스트 기록 전체 스크롤, 1·2·3위 메달.
- 입력값·플레이 기록 중복 등록·원본 장부 백업·기존 게임 재화·유물 저장 보존.
- 기존 60초 기록은 보존하며 성공 기록에 이전판 표시. 규칙이 다른 기록을 동일 보드에 보존한다.

에디터의 프레임 시간은 개발 도구와 메모리 사용량의 영향을 받으며 실제 시연 PC 성능 수치가 아니다. 릴리스 실행판에서도 화면·입력·종료 흐름을 별도로 확인한다.
