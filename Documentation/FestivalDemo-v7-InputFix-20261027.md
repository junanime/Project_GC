# 페스티벌 v7 — 한글 입력 및 덮어쓰기 업데이트

학과·이름 입력칸에서 한글을 조합할 때 `</u>` 등의 문자열이 노출되던 문제를 수정했다. TMP 입력 필드는 rich text가 켜져 있었으나 표시용 텍스트는 꺼져 있어, 조합 중 밑줄 태그가 실제 글자로 표시되는 설정 충돌이었다. 입력 필드와 표시 텍스트를 모두 일반 텍스트로 맞췄다. 같은 구성의 닉네임 입력칸에도 적용했다.

## 업데이트 방법

1. 행사 게임을 종료한다.
2. 기존에 설치한 Windows 계정에서 위 설치 EXE를 실행한다. 구버전을 제거하지 않는다.
3. 기존 `페스티벌데모버전` 실행 아이콘으로 실행한다.

설치 프로그램은 기존 등록 경로가 유효하면 그 위치에 파일을 덮어쓴다. 신규 설치는 기존의 사용자별 `Programs/24tuFestival` 위치를 사용한다. 설치본은 별도 백업 게임 폴더를 만들지 않는다. 순위와 QA 기록의 저장 폴더는 설치 대상에 포함하지 않는다. 설치 후 전달받은 설치 EXE는 삭제할 수 있다.

## 검증

- Unity 실제 결과 UI/TMP 경로를 사용하는 입력 회귀 검사 39개 통과. 이전 설정에서 `<u>…</u>`가 보이는 현상을 재현하고 수정 설정에서 사라지는 것을 확인했다.
- 조합 단계 `ㅈ → 주 → 준`, 확정 한글, Backspace, 커서 이동 후 삽입, 선택 교체, 붙여넣기, 글자 수 제한, 화면 재진입, 격리된 테스트 순위 파일 저장/읽기를 검증했다.
- 조합 검사는 `BaseInput`을 통해 TMP에 조합 문자열을 공급했다. 별도로 Windows 실행본에서 실제 플레이 후 학과·이름 한글 텍스트 입력, 전체 선택 교체, 삭제와 표시를 확인했다. Windows 키보드 IME 조합 자체의 수동 검증은 포함하지 않는다.
- Windows 빌드 성공. 네이티브 실행 로그에서 예외·오류 없음.
- 최종 설치 프로그램 종료 코드 0. 기존 설치 경로 유지.
- 201개 설치 파일을 원본 빌드와 SHA256 비교: 전부 일치.
- 순위·QA 저장 파일 29개: 설치 전후 SHA256 일치.
- 추가 설치 폴더 0, 남은 구버전 파일 0, 기존 바탕화면 바로가기 대상 일치.
- 게임 규칙은 `festival_pc_v6_45` 유지. 45초, 캐릭터/몬스터 밸런스, 점수, 기존 기록 형식을 바꾸지 않았다.
