# 원본 프로젝트 이미지 교체 — 2026-09-29

## 범위와 식별 방법

사용자 승인에 따라 기존 오픈소스의 이미지 파일을 직접 생성한 단순 도형 임시 이미지로 교체한다. 기준은 이 저장소에 남아 있는 원본 프로젝트의 마지막 커밋 `01f8c76`이다. 파일 이름뿐 아니라 Git blob 해시와 Unity GUID를 함께 대조해 이름이 바뀐 동일 이미지도 탐색했다.

검사 결과 원본 이미지 58개가 현재 프로젝트에 원본 바이트 그대로 남아 있었고, 별도 동일 바이트 복사본은 발견되지 않았다. 58개 모두 기존 경로에서 제거하고 새 픽셀 데이터로 교체했다. 참조가 없는 이미지도 같은 규칙으로 교체해 향후 누락된 동적 참조가 드러날 가능성에 대비했다.

## 교체 방식

- 새 파일 위치: `Assets/Art/Placeholders/LegacyReplacement/`.
- `Assets/Editor/UpstreamImageMigration.cs`가 수학적 도형과 고정 시드 노이즈를 생성한다. 원본 픽셀을 읽거나 베껴 그리지 않는다. AI 이미지 생성이나 외부 이미지 다운로드는 사용하지 않았다.
- 이미지 크기, PPU, 스프라이트 영역, pivot, border, GUID 및 local fileID를 유지한다. 405개 스프라이트 식별자와 배치 속성을 비교 검증했다.
- `.meta`와 슬라이스 이름은 연결 호환성을 위한 기술 정보로 보존한다. 같은 GUID를 가진 이미지가 두 경로에 존재하지 않게 이동 후 새 픽셀로 교체했다.
- 흐름 텍스처와 노이즈는 셰이더용 수치 데이터로 재생성했다. 배경·기존 몬스터·무기 외형 및 일부 효과 질감은 의도적으로 단순화되어 이전과 같지 않다.
- TMP의 JSON 시트 설명 파일도 새 이미지 옆으로 옮겼다. 문자/슬라이스 식별자는 기존 TMP 리소스와의 호환성을 위해 유지한다.
- 달팽이, 미니 달팽이, 최신 캐릭터/스킬 등 기타 이미지 689개는 이전 HEAD 대비 바이트가 동일하다.

## 도구와 검증

- 원본 인벤토리: `Tools/ArtMigration/Audit-UpstreamImages.ps1` (교체 전 실행).
- 상세 대응표: `Documentation/UpstreamImageMigration.json` (이전 경로/원본 해시/새 경로/GUID/스프라이트 정보).
- 교체 후 검사 및 미리보기: `Tools/ArtMigration/Verify-Migration.ps1`.
- Unity 연결 검사: `UpstreamImageMigration.Verify`.
- 전체 참조 검사, 캐릭터/보스 회귀 검사 및 Windows 빌드: `UpstreamImageMigration.VerifyAndBuild`.
- 로그와 도형 미리보기: `Logs/ArtMigration/` (생성 산출물, Git 추적 제외).

초기 교체 검증: 원본 경로 및 원본 바이트 잔존 0개, 405개 스프라이트 식별자/배치 유지, 689개 다른 이미지 유지, 달팽이 검사 96개 통과. 빌드 및 추가 검증 결과는 해당 로그의 PASS 마커로 확인하며, 장시간 플레이나 모든 효과의 육안 검증을 대신하지 않는다.

추가 연결 검사: 직렬화 참조 184곳과 최신 캐릭터 4명의 이미지 프레임 102개가 모두 유효했다. 최초 빌드 시도는 기존 `CharacterDesignTests`의 “캐릭터별 시작 스킬이 동일해야 한다”는 오래된 조건에서 중단됐다(`build.log`). 게임 설정이나 그 테스트를 변경하지 않고, 이번 작업에 맞는 이미지 참조 검사를 분리해 재실행했다(`build-verified.log`). 이 기록을 전체 기존 테스트 모음이 통과한 것으로 해석하지 않는다.

Windows x64 빌드 성공: `build-verified.log`의 `[WindowsDesktopBuild] PASS bytes=551467757`. 로비와 Level 1을 포함한 `Builds/ArtMigrationWindows/24tu.exe`를 생성했다. 빌드 중 자동 변경된 동적 폰트 캐시와 임시 preload 설정은 이번 소스 변경에서 제외했다. 새 실행 파일의 실제 플레이·모든 이펙트 시각 확인과 설치 패키지 재배포는 아직 수행하지 않았다.

## 제거 범위의 한계 및 복구

- 원본 프로젝트의 **이미지 파일**이 대상이다. 폰트와 폰트 아틀라스, 음악/효과음, 코드, Unity 패키지 및 엔진 내장 리소스를 삭제하는 작업은 아니다.
- 코드의 기존 `LICENSE` 및 관련 고지는 보존한다. 이미지 교체만으로 프로젝트 전체의 권리 검토가 완료됐다고 주장하지 않는다. 이후 추가된 외부 리소스의 출처도 별도 검토 대상이다.
- Git 기록은 다시 쓰지 않았다. 삭제된 원본은 이전 커밋에서 복구할 수 있으며 Git 이력에는 남아 있다.
- 기존 `Builds/WindowsDesktop`와 이전 설치 파일, 현재 설치된 게임에는 교체 전 리소스가 포함될 수 있다. 새 소스로 빌드한 결과와 구분해야 하며 이전 설치 파일을 이번 이미지 정리 완료본으로 배포하지 않는다.
- 이번 검증용 새 빌드는 `Builds/ArtMigrationWindows`에 별도로 생성한다. 기존 설치본이나 사용자 저장 데이터를 자동으로 덮어쓰지 않는다.
