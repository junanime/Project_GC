## 확정 선택

- 탕뎅이 `3-Skill1.wav`: 승인한 게임 톤 v1 충전음과 바이트 단위로 동일.
- 후루미 11개: 면발 주음과 동작 박자 유지, 지속 바람·마찰층 및 기존 게임 효과음 인용 제거.

- 5개 Phase 모두 기존 필드 이벤트 알림음 인용 제거.
- 공통 11개 × 5보스 + 롤팽이 Consume + 탕뎅이 Beam = 57개.
- 일부 공통 예비 슬롯은 해당 동작이 없는 보스에서 사용되지 않는다.

탕후루파는 충전음 길이에 맞춰 경고가 유지되고 이후 Beam을 별도로 재생한다.
우동커튼의 빈칸 전환 시 이전 소리는 짧게 감쇠하여 중첩을 줄인다.

## 울음소리 적용 — 2026-10-21 확정

피격/추격 각 5개 총 10개를 추가했다. 전체 오디오 리소스는 기존 패턴 57개 + 울음 10개 = 67개다.
기존 enum 번호를 유지하고 끝에 HurtCry, ChaseCry를 추가했다.

- 피격 울음: 실제 체력이 감소한 유효한 피격마다 19% 확률. 재생에 성공한 시점부터 최소 2초 간격.
- 무효 피해, 방어 중인 회복 기믹, 사망이나 페이즈 전환을 일으킨 피해에는 피격 울음이 나오지 않는다.
- 추격 울음: 정지 상태에서 실제 추격 이동이 시작된 순간에만 35% 확률을 한 번 계산한다.
- 이동 중 매 프레임 반복 추첨하지 않는다. 이전의 4~7초 주기 방식은 적용하지 않는다.
- 경계에 막혀 실제로 이동하지 못하면 추격 시작으로 취급하지 않는다. 대쉬/점프 공격은 일반 추격 울음의 대상이 아니다.
- 패턴 음성 재생 중에는 울음을 생략한다. 울음끼리 겹치지 않으며, 대기열에 넣어 나중에 재생하지 않는다.
- 공격 시작 시 현재 울음을 0.04초 감쇠한다. 울음 우선순위는 공격 효과음보다 낮다.
- 일반 패턴 효과음 기준 약 53% 기본 음량이며 사용자 효과음 음량 설정 및 거리 감쇠를 따른다.
- 일시정지/미니스테이지/비활성화/사망 시 기존 사운드 정지 정책을 따른다.

재생 검사 `FoodBossAudioSmoke.Run`은 67개 로드·PCM·AudioSource 재생 시계 진행을 확인한다.
