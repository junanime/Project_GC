## 첫 등장 안내 · 판정 후속 업데이트 (2026-10-06)

- 위산 두꺼비와 호두 다람쥐(요청의 도토리 다람쥐)는 실제 몬스터 타입으로 첫 스폰을 감지한다. 기존 다람쥐의 안내 확인 기록은 유지한다.
- 체력 회복, 몬스터 증식 물약, 자석의 첫 등장 안내를 추가했다. 폭탄은 제외했다. 저장된 콘텐츠별 확인 기록으로 다음 스폰/다음 실행에서 같은 안내가 반복되지 않는다.
- 기존 특수 몬스터 안내 패널과 일시정지/배경 어둡게/다시 보기/확인을 재사용한다. 혁이와 실제 게임 아트로 만든 런타임 반복 시연이며 별도 GIF 파일은 아니다. 두꺼비 시연은 3구체 → 원형 경고와 점프 → 산성액 발사 순서다.
- 확인 결과 빨간 물약은 지속 회복으로 구현되어 있었다. 사용자의 명시적 확인 후 일반 몬스터 기본 스폰을 30초간 1.5배로 바꿨다. 재사용은 시간만 30초로 갱신한다. 특수 몬스터/보스 스케줄은 늘리지 않으며 미니스테이지나 일시정지 중 시간은 소모하지 않는다.
- 적의 몸 판정은 알파 영역을 사전 분석한 **외접 사각형**에 맞춘다. 월드 크기를 자식 로컬 크기에 다시 적용하던 중복 확대를 제거했다. 픽셀마다 충돌하는 방식은 아니며, 침이 박힐 위치는 별도의 외곽 윤곽으로 보정한다. 일반/특수/엘리트/두꺼비 및 달팽이 본체·소환 미니에 적용한다. 달팽이의 공중 토핑과 잔상은 몸 판정에서 제외한다.
- 붙은 침은 외곽에서 길이의 일부만 몸 안으로 들어가고 몸 렌더러에 붙어 따라간다. 본체와 같은 Sorting Layer에서 order -1, 지상 그림자는 -2이며 Background/GroundEffects 위의 기존 몬스터 레이어를 유지한다. 관통·귀환 침은 기존대로 붙지 않는다. 사망/풀 반환 시 침을 제거한다. 공중 몬스터 그림자 위치는 변경하지 않는다.
- 두꺼비는 실제 얼굴 아트를 미니맵/전체 지도 아이콘으로 사용한다. 화면 밖 방향 버블은 달팽이와 같은 배경이며 두 보스가 동시에 있어도 별도로 표시한다. 화면 안, 미니스테이지, 사망 상태에서는 숨긴다.
- 새로운 몬스터 이미지 추가/변경 시 `Vampire.Editor.DiscoveryArtInstaller.Install`로 알파 크기·윤곽 데이터와 안내 시연 참조를 갱신한다. 빌드에서는 읽기 가능한 대형 텍스처나 매 프레임 픽셀 검사를 요구하지 않는다.
