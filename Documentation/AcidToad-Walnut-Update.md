## 아트 및 재현

기본 제공 이미지 생성 도구로 승인 컨셉을 참조한 투명 PNG 아틀라스를 생성했다. 원본과 Unity Sprite 메타데이터는 `Assets/Resources/ToadUpdate`에 있으며 생성 프롬프트는 `ToadUpdate-art-prompts.json`에 기록했다. 프레임 연결은 실제 게임 애니메이션이며 동영상 파일을 재생하는 방식이 아니다.

Unity 메뉴 `Tools > Junhan2 > Install acid toad and walnut update`는 아틀라스/프리팹/블루프린트를 재생성하는 개발용 도구다. 일반 플레이에는 실행하지 않아도 된다. 저장 시 Unity 직렬화에 따른 관련 에셋 변경을 검토할 것.

## 검증

Unity 2022.3.62f3 실제 Level 1 PlayMode 스모크 테스트로 프레임 로딩, 80% 기준 크기, 모든 공격 중 고정 스케일, 3구체, 공통 산성액, 점프 후 복구, 미니스테이지 중단 정리, 다람쥐 접근/도주, 대쉬 보상 중복 방지, 트레이 및 비전서 펼침을 확인했다. 실행 화면을 캡처해 프레임 잘림, 산성액 질감, UI 배치를 점검했다.

신규 콘텐츠 34개 검사 통과: `Vampire.Tests.Editor.ToadUpdateSmoke.Run` (`toad-smoke4.log`, failed=False). 스케줄러 실제 중복 호출 시 1회만 생성되는 것과 사망 후 LivingMonsters 제거까지 확인했다.

기존 전투 회귀 검사도 `Vampire.Tests.Editor.October6CombatSmoke.Run`으로 통과했다 (`toad-regression3.log`, failed=False). 새 종점개진 3/5/7발 실발사, 재발동 무한 연쇄 방지, 기존 양극침·관통 가속·범위 VFX·겹친 상호작용을 포함한다. 구 규격을 기대하던 테스트 조건과 반사 호출 인수는 새 규격에 맞게 갱신했다.

결과 캡처는 로컬 `Library/ToadUpdateProof`에 저장된다. 장시간 플레이 밸런스와 저사양 성능은 별도 플레이테스트 대상이다. 이번 작업에서는 설치본을 새로 만들지 않았다.
