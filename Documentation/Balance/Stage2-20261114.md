## 신이 액티브

액티브 동작 중 이동속도에 1.3배를 적용한다. 기존 공통 이동 계산에서 다른 가속·감속과 함께 합성한다. 클래스 기본값은 이미 1.3이었지만 실제 사용 자산과 설치 도구가 1.0으로 설정해 효과가 없었다. 자산과 재설치 경로를 함께 1.3으로 바꾸고, 동작 시작·종료 때 물리 이동 계산도 즉시 갱신한다.

준비·분사·마무리를 포함한 기존 액티브 동작 상태를 기준으로 적용하며, 종료·취소·사망·이동 전환 뒤에 보너스가 남지 않는다. 기존 일반 일시정지의 시전 취소와 보상창의 시전 시간 정지 규칙은 유지한다. 게임 내 스킬 설명에도 이동속도 +30%를 표시한다.

## 비교 방법

일반 전투 비교는 네 캐릭터의 같은 이전 대장 성장 기록(t450)을 복원해 75%와 80% 체력에서 각각 60초씩 관찰한다. 스폰 시간표·스폰 난수·배치·이동 조건을 맞추고, 자동 성장과 추가 장비 획득을 제외해 처치 수와 평균·최대·종료 시점 개체 수를 비교한다. 무적은 관찰을 끝까지 이어가기 위한 설정이다.

기록은 실제 스테이지 전환 시 성장을 초기화한 뒤 1배속으로 수집했던 자료다. 이번 체력 변경 이후의 새 성장 경로를 재현한 자료는 아니다. 실제 처치한 경우만 처치 시간을 기록하고, 제한 시간에 살아 있으면 미처치로 남긴다. HP/초당 피해 계산은 별도 추정이며 실제 처치 시간이나 사람의 성공률로 제시하지 않는다.
