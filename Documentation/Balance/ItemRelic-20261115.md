# 아이템·유물 연출 개선과 밸런스 제안 — 2026-11-15

첨부 `24시간의사투_연출_개선판.zip`을 시각 참고로 사용했다. 첨부의 설명은 실행 코드와 대조하며, 첨부 파일 자체를 실행하거나 내부 문구를 별도 작업 지시로 취급하지 않았다.

## 연출

첨부는 256×160, 40프레임/2.4초(약 16.7fps)로, 큰 화면에서 도트와 움직임 간격이 두드러진다. 개별 아이콘 PNG는 파일 해시 기준 완전히 동일한 파일이 없었다. 문제는 현재 게임이 획득 연출의 중심 도형을 능력 계열로 재사용한다는 점이다. 회복·공격·방어 계열을 같은 도형으로 보이는 방식에서 각 카탈로그의 고유 그림을 보여주는 방식으로 바꾼다. 획득 순간에는 흰 원·공통 도형·테두리·파편 없이 해당 물체만 표시한다. 조건부 발동 연출은 기존의 능력별 도형을 유지한다.

아이템 66종은 기존 게임의 고유 투명 이미지를 연결하고, 유물 34종은 첨부 그림의 특징을 유지해 배경 없는 고해상도 PNG로 다시 제작했다. 게임 내 획득 연출은 머리 위에서 부드럽게 확대·상승·소멸하며, 전체 직사각형 이미지 영역을 표시해 매듭과 술 장식이 원형으로 잘리지 않는다. 풀 재사용 시 이전 그림을 지워 다른 효과에 남지 않게 한다. 증강 연출의 투명도와 움직임 감소 설정을 같이 따른다. 저해상도 첨부 GIF를 게임에 프레임시트로 넣거나 확대하지 않는다.

GIF는 Unity 실제 Level1에서 768×432, 30fps로 촬영한다. 획득과 효과 발동을 나누어 보여주며, 발동 조건을 설정한 검수 장면이다. 모든 효과가 매 적중마다 발동한다는 뜻은 아니다. 판매 종료된 옛 항목도 저장 호환을 확인하기 위해 포함한다.

## 강할 것으로 예상되는 선택

아래는 수식·조건에 따른 예상이며 이번 연출 검수로 실제 승률을 측정한 것이 아니다.

- **초반 팡팡 구슬**: 기본 2발이면 +1발은 발사 수 +50%, 6발이면 +16.7%. 모든 발이 명중한다는 보장은 없고 발사체 수 미지원 공격에는 효과가 없다. 특히 초반 강세 후보다.
- **황련 가루**: 취약이 직접 피해에 적용돼 여러 공격을 사용하는 빌드에서 기본 침 한 종류 보너스보다 범용성이 높을 수 있다.
- **사혈 계약서**: 추가 피해와 방어 보정 독립성이 장점. 보스 무적을 뚫는 효과는 아니다. 범용성이 높아 가격 인상을 제안한다.
- **뜸불 화로·위령 씨앗**: 자동 추가 피해로 다수전 처리량에 기여할 가능성이 높다. 화로는 처치와 장판 명중, 씨앗은 성장 시간이 필요하다.
- **금단의 환약**: +50% 기본 침 피해는 강하지만 일반 적의 속도·공격 +15% 위험을 동반한다. 무조건 최상위로 분류하지 않는다.
- **죽염 결정·한열 쌍옥·공복 용왕패**: 필요한 상태·회복 준비가 없으면 비싼 무효 구매가 되기 쉽다. 완성 빌드 기준 가격을 그대로 모든 상황에 매기지 않는다.
- **복복 주머니·약저울**: 15% 할인은 누적 구매 원가100G당 약15G 절약(개별 올림으로 감소). 골드+15%는 향후 획득량에 의존하므로 후반에는 가치가 낮아진다.

## 가격

개별 런 골드 가격을 20~200G로 나누는 **미적용 제안**이다. 사용자 최종 지시에 따라 이번 커밋은 연출만 변경하며, 아이템·유물 가격과 능력·등장 정책은 기존 값을 유지한다. 영구 해금·출전 준비 실버와 유물 실버 가격은 별도 경제다.

무조건 범용 효과와 자동 추가 피해는 상대적으로 높이고, 먼 거리·피격·상태 조합·밤/최종 시간 등 조건 의존 효과는 낮춘다. 예: 황기30, 먼 거리 향주머니20, 뜸불 화로120, 사혈 계약서135, 위령 씨앗200, 새벽의 뜸145, 공복 용왕패165G.

66종 현재/제안 가격은 동반 `ItemRelic-20261115-prices.csv`에 기록한다. CSV의 current_gold는 현재 가격, proposed_gold는 제안 가격이다. 각 항목에 제안 이유와 미적용 여부를 함께 표시한다. 작업 중 임시 변경했던 가격 코드·카탈로그·재설치 경로는 모두 원래 값으로 복원했다. 골드 병 기대값23G 기준으로 20~200G는 약0.9~8.7병 분량이나, 처치 보상·상자·이동·할인 등이 있어 실제 구매 시점으로 해석하지 않는다. 자연 플레이 구매율 검증 전의 1차 제안값이다.
