- 일반 HP의 시간별 가산 기능과 보스의 시간별 HP·피해 배율을 제거했습니다. 이미 존재하는 소화효소 처치 보상에 의한 명시적 버프는 유지합니다. 기본값에서는 표의 HP 그대로 시작합니다.
- 엘리트는 대응 일반 Blueprint를 사용하며 HP 배율을 **4배→2.5배**로 조절했습니다. 일반 스폰 비율을 따라 선택하고, 전체 동시 생존 상한은 4마리입니다.
- 분열 능력이 있는 설탕 큐브와 돌진 포자도 특수 풀로 분리했습니다. 설탕의 기존 분열 수·그림·모션은 유지하고, 트리오 80 / 엘리트 200 / 엘리트 분열 트리오 80 / 최종 단일 개체 25 HP로 맞췄습니다. 현 설정의 자식 수 2를 포함한 총 처리 HP는 일반 130, 엘리트 460입니다.
- 처리하지 못한 몬스터가 끝없이 누적되지 않도록, 필드 개체 수가 **160** 이상일 때 일반 스폰만 보류합니다. 특수·엘리트 및 분열은 별도이므로 총 개체 수가 160을 넘을 수 있습니다. 밀린 일반 스폰을 나중에 한꺼번에 방출하지 않습니다.

## 증강과 보스

기본 침이 5→10으로 바뀌면서 비율 기반 공격은 자동으로 강해집니다. 고정 피해만 뒤처지지 않도록 독 틱, 폭발, 섬유선 초당 피해, 소화액 장판 초당 피해, 장기압착 틱 피해를 각각 **2→4**로 맞췄습니다.

일반 증강의 침 피해 +10%, 치명타 확률 +5%, 치명타 배율 +15%, 공격속도 +6/+8%, 추가 침 +1(최대 5중첩)은 유지합니다. 관통·유도·양극·귀환·표식·부식·거리 보너스, 분신·샷건·조종침·파동 등은 기존 작동 방식과 배율을 유지합니다. 둔화·회복·대시·정지·보호막은 순수 피해로 환산해 중복 가산하지 않습니다. 특수·전설 조건부 강화의 개별 조합은 자동 기능 테스트와 별개로 후속 실제 플레이 관찰 대상입니다.

생명연소는 HP 1의 위험과 피해 3배·추가 침 10발을 유지합니다. 이 선택은 생존 위험 때문에 기준 계산에서 제외하고 별도 민감도 모형으로 봤습니다. 상점 장비·영구 성장·랜덤 필드 이벤트 보정 역시 기준 빌드에 넣지 않았습니다.

보스는 우주선 외형과 다섯 코어를 유지합니다. 기존 전체 HP 500은 후반 피해량에 비해 낮아 **9,000(코어당 1,800)**으로 조절했습니다. 기본 탄환 피해 10, 패턴 탄환 8~10, 드론 15, 투척 폭발 20을 기준으로 합니다. 폭탄의 보스 자해는 최대 HP **49.7%→3%**로 정리했습니다. 매몰 드론은 기존 최대 HP 2.5%, 돌진 관련 2배 보정을 유지해 유도 플레이가 유효합니다. 콜라 회복은 초당 90, 흡수 미니언당 회복은 90으로 전체 체력에 맞췄습니다. 회복 오브젝트를 먼저 처리할 이유를 남깁니다.

게임시간 **15:00에 스포너 호출을 시작**합니다. 기존 화면 점등·안테나 송신 2회·좌우 흔들림 하강이 끝나면 실제 보스가 나타납니다. 수동 호출과 동일한 경로이므로 중복 소환하지 않습니다. 화면 밖의 스포너는 자동 호출 시 화면 안으로 옮겨 송신이 보이게 했습니다. 일시정지·미니스테이지로 게임시간이 멈춘 동안 마감 시간도 멈춥니다. 연출 취소 후에는 재시도할 수 있습니다.

## 필드 이벤트 두 시간표

`StageEventDirector`의 Primary Track은 120초, Secondary Track은 360초입니다. 각각 독립된 구간 안에서 시작 시점을 뽑습니다. 직전 이벤트 종료 시점을 기준으로 시간을 더하지 않습니다. 15분에서는 마지막 불완전 구간까지 포함해 8회+3회, 총 11회입니다.

서로 다른 이벤트는 동시에 실행할 수 있습니다. 동일 효과가 자신의 진행 중인 코루틴을 덮어쓰지 않도록 같은 종류의 실행 구간만 피합니다. 후보를 전부 끄거나 실행 중인 한 종류만 남긴 특수한 인스펙터 설정에서는 경고 후 해당 구간을 건너뜁니다. 기존 일회성 설정 목록은 이벤트 종류·이미지·피해·지속시간의 템플릿으로 사용하며, 기존 개별 시간표와 새 시간표가 이중 실행되지 않습니다. `Use Window Schedule`을 끄면 기존 개별 시간 설정을 사용할 수 있습니다.

## 계산 결과와 한계

`Tools/Balance/simulate_balance.py`는 실제 Level Blueprint와 침 프리팹에서 HP·스폰 비율·경험치·공격 설정을 읽습니다. 4가지 선택 정책에 각각 1,500개 시드, 총 **6,000회**를 계산했습니다.

기준 정책은 카드 선택의 65%에서 공격에 유리한 선택을 우선하고 나머지 35%는 무작위 선택합니다. 이는 관측된 이용자 평균이 아니라 설계 가정입니다. 명중률 58~78%, 경험치 회수율 65~85%, 면적 활용률 90%, 시작 경험치 25 회수를 가정했습니다. 실제 레벨 필요 경험치 증가식(+10/+13/+16/+20)과 초기 2발/0.7초, 일반 증강의 주요 중첩 제한을 사용합니다.

환산 피해에는 평균 치명타, 평균 적중 거리 3, 부식 평균 2스택, 표식의 두 번 중 한 번 추가 피해, 폭발과 제한적인 섬유선 노출을 사용했습니다. 지속 독은 반복 적중 시 갱신되므로 매 적중마다 전체 지속 피해를 더하지 않았습니다. 군중 처리에는 관통·추가 투사체·일부 전설의 가동률을 근사했습니다. 조건부 증강 전 조합, 실제 조준·충돌·몬스터 밀집, 방어 선택의 생존 이득을 정확히 재현하는 전투 엔진은 아닙니다.

무작위 선택 모형의 4/7/10분 평균은 5.65/8.98/7.81타, 공격 우선 모형은 4.51/6.35/4.67타입니다. 따라서 모든 빌드가 5/7/5타에 고정되는 것은 아닙니다. 원시 결과와 분포는 `simulation.json`, 비교 그림은 `balance_overview.png`에 있습니다. 다음 실사용 검증에서는 명중률·회수율·증강 선택 수·분당 처치 수를 기록해 이 가정을 보정하는 것이 필요합니다.
