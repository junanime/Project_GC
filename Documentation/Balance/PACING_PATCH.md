# 전투 밀도·미니스테이지 후속 패치

2026-09-15. `2284ee6`의 15분 밸런스를 기준으로, 실제 플레이에서 느슨하다는 피드백을 반영했다. 몬스터 고정 체력과 기본 공격 피해 10은 유지한다.

## 등장 밀도

- 일반 스폰 곡선의 모든 지점을 **1.4배**로 올렸다. 최대 개체 수 때문에 증가분이 사라지지 않도록 일반 스폰을 멈추는 생존 개체 기준도 160→224로 조정했다. 특수·엘리트는 별도 생성 경로를 유지한다.
- 이벤트·일시정지·개체 상한을 제외한 15분 곡선 적분은 일반 몬스터 1,137→약 **1,592마리**다. 실제 생성 수는 처치 속도와 이벤트에 따라 달라진다.
- 실제 일반 몬스터 **50마리 생성마다 엘리트 1마리**를 추가한다. 현재 시간의 일반 스폰 비중에 대응하는 엘리트를 고른다. 최대 동시 생존 12마리에 도달하면 추가 생성을 보류한다.
- 기존 시간표 엘리트도 유지하면서 주기를 25% 단축하고 구간별 동시 생존 한도를 2마리씩 늘렸다. 엘리트 소환 오브젝트는 첫 180→120초, 이후 150→90초, 최대 활성 2→4개로 변경했다.
- 엘리트 대응표에 YAML 별칭이 저장되어 Unity에서 목록이 비어 읽히는 문제를 발견했다. 두 Level 1 씬의 모든 구간에 대응표를 직접 저장하고, Unity가 6개 매핑을 실제 읽는지 검사한다.
- 사용 아이템 상자는 30초당 2→1개로 절반. 시작 시 배치하는 1개는 유지한다.

## 특수 몬스터 반복 조우

`TimedSpecialMonsterSpawner` 안의 기존 시간표에 반복 간격·후반 동시 등장 확률·동반 종류 설정을 추가했다. 일반 스폰 비율에 합치지 않았다. 첫 조우는 항상 1마리이며, 15분에 가까워질수록 추가 개체마다 등장 확률이 최대 85%까지 선형으로 오른다.

버퍼 1마리 조우에서는 두 종류 중 하나를 고르고, 2마리 조우에서는 두 종류가 동시에 등장한다. 11분 시점 두 마리 확률은 42.5%, 15분 근처는 85%다. 자폭 포자의 3마리 확률은 7분 약 8%, 11분 약 32%, 15분 근처 약 72%다. 보물 몬스터만 보상 공급을 고려해 추가 개체 확률 상한을 50%로 뒀다. 포획 함정은 6분부터 최대 3개, 재등장 70초다. 이전에 보류한 거머리는 이번에도 새로 배치하지 않았다.

## 전투 및 표현

- 대쉬 중에는 공통 무기 경로에서 새 공격 생성을 차단한다. 이미 발사된 투사체의 비행은 유지한다.
- 플레이어 피격 무적 기본 시간을 **0.5초**로 변경했다. 무적 시간 증강 보너스는 추가 적용한다. 흰색 표시 자체는 0.08초여서 무적 내내 하얗게 보이지 않는다.
- 독·화상, 화염병·소화산·장기 압박 장판, 섬유선, 미니스테이지 산성 필드의 지속 피해는 흰색 피격 표시를 생략한다. 피해 계산·버프 보정·기존 VFX는 유지한다. 플레이어 산성 장판과 제산 이벤트의 지속 피해에도 같은 표시 규칙을 사용한다.
- 일반 적중은 흰색 표시 0.06초, 다음 표시까지 최소 0.22초 간격이다. 빠른 연타가 현재 표시를 계속 연장하지 않는다. 보스 파츠·흡수 미니언도 연타 표시를 제한했다.
- 귀환 침은 침 무기의 발사 위치 보정/직접 지정한 발사점을 사용한다. 곡선의 끝도 이동 중인 플레이어를 따라 갱신하고, 마지막 접근에서 목표를 지나쳐 왕복하지 않게 했다.
- 보스 폭탄은 착지와 동시에 유리병 파손·녹색 폭발·피해가 시작된다. 기존 파손 이미지의 0.2초 대기를 제거하고, 파손 잔상은 폭발과 함께 짧게 재생한다.
- 흡수 미니언 이동속도는 **2.4→1.2**로 줄였다.

## 미니스테이지와 씬 이동

- 미니스테이지에서 생성된 경험치·골드를 별도로 추적한다. 방 정리 후 남은 개체는 보상 지급 없이 풀에 반납한다. 기존 메인 필드의 경험치·골드는 보존한다.
- 산성 유인 방은 몬스터가 죽는 순간, 사망 연출과 충돌체 비활성화 전에 장판 위 위치를 확인한다. 플레이어가 한 방에 처치해도 진행도가 오른다. 기존 산성 피해 처치와 중복 집계 방지는 유지한다.
- 진입 시 우주선 보스의 패턴과 기본 공격을 중단하고 진행 중 폭탄·경고·탄환·드론을 정리한다. 별도 과부하/광역 패턴 제어기도 중단한다. 보스 이동·접촉 피해·파츠 피격은 차단하며, 필드 복귀 후 스케줄을 다시 시작한다. 보스 HP는 초기화하지 않는다.
- 다음 씬 전달 스냅샷에 구매 아이템(중복 구매 포함), 활성 시너지와 표시 이름을 저장한다. 소유 정보를 복원할 때 구매 효과를 다시 실행하지 않으므로 기존 캐릭터 능력치 스냅샷과 중복 가산되지 않는다.
- `InfiniteBackground`는 원본 머티리얼 대신 실행용 복사본에 스크롤/파동 값을 기록하고 종료 시 해제한다. `Infinite Background 2.mat`에 남아 있던 실행 좌표도 0으로 정리했다. 외형·텍스처 설정은 보존한다.

## 검증

Unity 2022.3.62f3의 별도 프로젝트 복사본에서 실행한다. 수치·시간표·확률 검사는 편집 모드, 생성·피격·방 전환은 실제 Level 1 실행으로 확인한다. 기능 점검은 무적·강제 조우 등을 사용하며, 정상 플레이 생존률이나 체감 난이도를 측정한 테스트는 아니다. 최종 통과 항목은 `pacing-validation.txt`에 기록한다.

재실행 진입점: `Vampire.Tests.Editor.PacingPatchTests.RunAll`, `Vampire.Tests.Editor.PacingPatchPlaySmoke.Run`. 이전 `simulation.json`과 그래프는 최초 15분 밸런스의 기록이며 이번 스폰 증가 후 측정값이 아니다.
