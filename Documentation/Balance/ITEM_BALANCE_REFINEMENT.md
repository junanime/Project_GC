# 통합 패치 후속 개선

작업 브랜치: `codex/item-feedback-patch1`, 검토: PR #1. hyeon 병합 전 테스트 버전.

| 항목 | 2차 최초 적용 | 이번 개선 |
|---|---|---|
| 로비 선택 | 판매 58종을 페이지로 탐색 | 전체·공격·생존·상태·유틸 필터. 필터 변경 시 선택과 페이지 초기화 |
| 상점 카드 | 등급 표시 | 등급과 주요 역할 함께 표시 |
| 로비 안내 | 최대 2개 | 최대 2개·출전 시 소모를 구매 화면에서 안내 |
| 십이시진 시계 | 게임 매 정각 300% + 감속 | 획득 20초 후부터 20초마다 200% + 2초 35% 감속. 범위 5 유지 |
| 반추 두루마리 | 7초마다 120% | 8초마다 100%. 경로·대상당 1회 유지 |

두루마리의 동일 적중 조건 기준 시간당 피해 잠재력은 원본(10초·80%) 대비 2.14배에서 1.56배로 완화했다. 실제 피해는 이동 경로와 적 배치에 따라 달라진다.

시계는 스테이지 길이·정각까지 남은 시간에 따라 구매 직후 대기 시간이 달라지는 문제를 없앴다. 게임 일시정지 동안 쿨다운은 진행되지 않으며, 기존 cooldownRemaining 스냅샷으로 스테이지 이동 시 남은 시간을 보존한다. 테스트 메뉴의 시간대 고정은 야화 약등·새벽의 뜸에만 영향을 주고 시계의 쿨다운을 건너뛰지 않는다.

역할은 탐색을 위한 대표 분류이며 모든 효과를 제한하는 규칙은 아니다. 여러 역할을 가진 아이템도 한 분류에서만 표시해 같은 아이템의 중복 노출을 막는다. 기존 보유 및 판매 종료 정책은 유지한다.

가격은 골드 25/50/100/180, 실버 80/180/400/900을 유지한다. 추가 삭제·지존 등급·일괄 상향은 하지 않았다. 자연 플레이에서 전설 구매 시점과 포기 이유를 확인한 뒤 조정할 예정이다.

검증: 카탈로그 설명·가격 일치, 역할별 목록 누락·중복, 시계 획득 대기·시간대 변경·스테이지 복원·중복 발동 차단을 자동 테스트한다. 실제 기기 전투·가격 체감 검증은 별도 필요하다.

검증 결과: Unity 2022.3.62f3 전체 EditMode 95개 중 89개 통과. 기존 hyeon과 같은 6개 실패, 신규 실패 없음. Play Mode에서 5개 역할 필터를 실제 클릭했고 설명 영역 넘침 검사와 화면 캡처를 완료했다.
