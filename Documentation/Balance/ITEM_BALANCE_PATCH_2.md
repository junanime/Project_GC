# 아이템 2차 패치 — 판매 목록·가격·전설 체감

1차 패치 위에 적용하는 변경이다. 캐릭터 고유 스킬과 유물 효과는 변경하지 않는다. 별도 브랜치 `codex/item-balance-patch2`에서 검토하고, 1차 패치가 합쳐진 뒤 hyeon에 순서대로 반영한다.

## 판매 후보 66종 → 58종

완전히 동일한 효과라는 뜻은 아니다. 아래는 선택 이유가 겹치는 후보를 줄이는 1차 정리이며, 남기는 아이템에 제거 대상 효과를 덧붙이지 않는다. 종류를 일괄 삭제하지 않고 신규 판매만 종료한다.

| 판매 종료 | 남기는 선택지 | 이유 |
|---|---|---|
| 09 호신 호두 | 32 기혈 장부 | 피격 후 반격 역할을 장부로 집중. 피격을 유도하는 저등급 선택지 축소 |
| 10 후추 환 | 14 박하 향로 / 22 반향 옥구 | 확률 넉백보다 주기·적중 반향의 밀어내기 역할을 명확히 유지 |
| 19 메아리 경혈석 | 07 맥진 팔찌 | 보조 침 자동 발사 역할을 하나로 정리 |
| 23 음양 엽전 | 01 황기 뿌리 / 조건부 피해 아이템 | 단순 무작위 피해 변동을 줄이고 조건이 읽히는 선택지 유지 |
| 35 백출 약편 | 08 위벽 부적 / 26 축기 호리병 | 피해 감소 역할을 정기 보호막·무피격 보상으로 구분 |
| 40 오미자 오색환 | 21 점혈 방울 | 타격 횟수 보상을 시각적으로 확인 가능한 점혈에 집중 |
| 45 쑥 향주머니 | 17 약초 미끼 인형 | 같은 대시 시작 지점 유인 동작의 하위 변형 정리 |
| 53 이중 처방첩 | 12 발효 누룩 / 65 한열 쌍옥 | 상태이상 개수만 늘린 피해 보너스를 줄이고 입문·조합 완성 효과 유지 |

전체 카탈로그, ID, 아이콘, 런타임 효과는 66종 그대로 보존한다. 기존 런·스테이지 이동에서 보유한 아이템은 작동한다. 로비 구매, 상점 최초 진열, 재추첨, 부족 후보 보충, 직접 구매 콜백에 판매 정책을 적용한다. 이미 장착한 로비 아이템은 해제할 수 있도록 표시한다. 도감에서는 판매 종료를 표시한다.

## 가격 — 두 재화를 구분

| 등급 | 런 골드 기존 → 변경 | 로비 실버 기존 → 변경 |
|---|---:|---:|
| 평범 | 25 → 25 | 80 → 80 |
| 희귀 | 45 → 50 | 150 → 180 |
| 영웅 | 80 → 100 | 320 → 400 |
| 전설 | 130 → 180 | 650 → 900 |

기존 대화의 80·150·320·650은 로비 실버였다. 전설 800 초과 목표는 실버 900으로 적용한다. 골드 병은 10·30·50 골드를 각각 50%·35%·15% 확률로 제공한다(기대값 23). 전설 180은 보정 전 병 약 7.8개 분량이다. 처치·상자·배율·탐색에 따라 실제 구매 가능 시점은 달라지므로 한 판의 실측 결과로 확정한 가격은 아니다. 상점 리롤 비용과 등급 등장 확률은 유지한다. 지존 등급은 추가하지 않는다.

가격은 `ItemOfferPolicy`에 모으고, 카탈로그 에셋과 콘텐츠 재생성 도구에도 같은 값을 적용했다. 설명은 실제 효과 수치와 재사용 대기 표현을 카탈로그·밸런스 코드·문서에서 일치시킨다.

## 전설 4종 보강

| 아이템 | 기존 | 변경 |
|---|---|---|
| 십이시진 시계 | 게임 매 정각 반경 5, 침 피해 150% | 피해 300% + 2초 35% 감속. 아이콘 대신 반향 파동 표시 |
| 위령 씨앗 | 1.5초마다 30→40→50→60% | 1.5초마다 50→65→80→95%. 기존 60초 성장 간격 유지 |
| 반추 두루마리 | 10초마다 경로 잔상, 80% | 7초마다 120%. 최근 3초 경로·대상당 1회 유지 |
| 위벽 기억석 | 같은 적 종류 실제 피격당 저항 4%p, 최대 20% | 피격당 6%p, 최대 30%. 종류별 기록·스테이지 이전 유지 |

시계는 24시간 환산의 게임 정각에 발동한다. 실제 1시간을 기다리는 효과가 아니다. 위령 씨앗 성장 기준은 기존 런타임 경과 시간 방식 그대로다. 감속 증폭·지속시간 아이템과 시계의 감속은 기존 상태이상 규칙으로 연동한다.

## 개발용 테스트 메뉴

Unity 메뉴: **Tools → QA → 아이템 밸런스 테스트**

1. 플레이 모드에서 캐릭터가 출전한 뒤 창을 연다.
2. 이름 또는 ID로 검색해서 아이템을 즉시 지급한다. 보유 중인 것은 중복 지급하지 않는다.
3. 런 골드 +1,000, 체력 회복, 에디터 일시정지로 구매·전투 조건을 준비한다.
4. 낮 12시·밤 18시·마지막 23시로 아이템 시간대만 고정한다. 시계는 변경 후 한 번 발동한다. 보스·몬스터 스폰 일정과 실제 런 시간은 건너뛰지 않는다.
5. 실제 시간 버튼 또는 창 닫기로 시간대 고정을 해제한다. 조합을 비우려면 플레이를 재시작한다.

판매 종료 8종도 별도 토글로 불러와 기존 효과를 확인할 수 있다. 메뉴는 Editor 폴더에 있고 시간대 테스트 코드도 UNITY_EDITOR 조건부이므로 플레이어 빌드에는 포함되지 않는다. 지급은 실제 런에 적용되며 결과 저장을 진행하면 기존 게임의 보상 저장 경로가 동작한다.

## 수동 QA

- 로비 신규 구매 목록 58종, 전설 900 실버 표시·차감·해제 환불 확인.
- 상점 최초 진열과 여러 번의 리롤에서 판매 종료 8종 미노출 확인.
- 전설 180 골드, 할인 유물 장착 시 표시·차감 일치 확인.
- 시계 감속, 씨앗 성장, 잔상 경로 중복 타격 방지, 기억석 종류별 저항을 실제 전투에서 비교.
- 1차 패치 연출과 합쳐졌을 때 적 탄환 가독성, 모바일 성능 확인.
- 자연 플레이에서 첫 구매 시간·전설 구매 시 잔액·리롤 횟수 기록. 전설 구매율이 너무 낮으면 수급 또는 가격을 재조정.

Unity 2022.3.62f3 컴파일 성공. 전체 EditMode 93개 중 87개 통과, 6개 실패. 이번 신규 5개와 1차 패치 7개는 모두 통과했다. 실패 6개는 수정 전 hyeon의 baseline-results.xml과 정확히 동일한 테스트 목록이다. 실제 기기 15분 플레이와 구매율 평가는 자동 테스트를 대체할 수 없다.
