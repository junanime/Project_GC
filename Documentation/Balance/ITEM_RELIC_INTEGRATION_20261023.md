# 아이템·유물 선택 통합 및 전용 연출

## 통합 범위

- 대상: `Junhan2`, 시작 커밋 `675b01608a2e657bce3ba66ebbbeedde699ad878`.
- 원본: `origin/codex/item-balance-patch2`, `c3f344d` 및 `b9fdd0e`.
- 공통 조상 `961a957dff1528e0030190d2c6c4a3a466b2ed5a` 이후의 아이템·유물 관련 차이만 3-way patch로 반영했다. 다른 브랜치의 전체 파일로 덮어쓰지 않았다.
- 맵, 보스 패턴, 캐릭터 외형, 최근 UI 변경, 배포 설정은 통합 대상이 아니다. Character 변경은 유물 부활 연출 연결뿐이다.
- 아이템 66개 ID를 유지하고 신규 판매는 58종. 유물 34개 저장 ID를 유지하고 중복 회복 유물은 신규 제안에서 정리한다.
- 등급별 골드 가격 25/50/100/180, 실버 가격 80/180/400/900. 자세한 밸런스는 `ITEM_BALANCE_PATCH_2.md`, `ITEM_FEEDBACK_PATCH_1.md` 참고.

## 연출 연결

- 전장에 아이템 도감을 띄우던 `MakeSprite` 경로를 제거했다. 장판·소환체·추적탄·역행 잔상·충격파가 각각 독립된 벡터 메시 연출을 사용한다. 도감 아이콘은 UI에서 그대로 유지한다.
- 상시 능력치는 획득 시만 짧게 표현한다. 공격 효과가 없는 아이템/유물이 새 공격을 하는 것처럼 보이게 하지 않는다.
- 타격/넉백: 타격선, `톡!`, `통!`; 점혈: 4회 표식과 파열.
- 회복/흡수: 십자·잎, 거품, 경험치 결정의 수렴.
- 방어: 방패 윤곽·확장 파문·봉인 고리. 위벽 기억석은 세 개의 기억 결정.
- 박하/반향: 확대되는 충격파. 야화/시계/새벽은 달·12개 눈금·햇살로 구별.
- 뜸불/위산: 지면의 작은 불꽃과 액체 거품. 흡입컵/귀환문은 회전 방향이 보이는 소용돌이.
- 공전약환: 빛나는 궤도 구슬. 위령씨앗: 작은 잎 정령. 백귀향단: 추적하는 영혼. 반추: 흐르는 잔상.
- 공복용왕패: 실제 전방 부채꼴 판정 방향에 맞춘 물결. 한열쌍옥: 뜨거운 색·찬 색이 섞인 증기.
- 유물 보호막 흡수/재충전, 실제 체력 회복, 반사, 부활은 실제 발동에 연출을 연결했다.
- 봉인옥구는 새 FoodBossBullet도 정지시킨다. 반사 유물은 새 보스의 피해 인터페이스도 처리한다. 보스 무적 규칙은 그대로 따른다.

## 화면 및 소리 예산

- 플레이어별 풀 최대 24개, 이 중 1개는 부활용 예약. 연출 풀이 가득 차도 피해·치유·보호막 판정은 계속 실행한다.
- 재사용 lease를 검사하여 이전 장판/투사체의 종료가 새 연출을 지우지 못하게 했다.
- 지면 연출은 `GroundEffects`, 나머지는 전투 연출 레이어. UI 위로 올라오지 않는다.
- 설정의 증강 VFX 투명도와 모션 줄이기, 일시정지를 따른다. 장판은 월드 위치에 남고 소유자 비활성화/사망 시 정리한다.
- 새 효과음 7종: 획득, 타격, 거품, 회복, 결정, 종, 파동. 원본 합성 도구는 `Tools/Items/generate_proc_audio.py`.
- 효과음은 0.18~0.46초 단발음이며 배경 루프가 없다. 동시 3개, 전체 0.12초/동일 계열 0.3초 제한, 효과음 설정 볼륨을 사용한다.
