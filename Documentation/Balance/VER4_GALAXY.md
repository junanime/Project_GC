- 화상 중첩은 독립 시간 유지. 같은 시각/피해/시전자의 중첩은 합산 보관하여 상한 해제 후 처리량 절감. 실제 적중 피해를 보스 화상 상한 및 가지/쇄빙/충격파의 기준으로 전달.
- 빙결과 신경차단의 종료 시간을 분리. 쇄빙이 신경차단까지 해제하지 않음. 사망 타격도 쇄빙 후처리를 수행.
- 목침 회복 장판 3초 생성 대기시간 > 최대 장판 2.5초라 동일 플레이어 장판 중첩을 방지. 생명연소 회복 금지.

## 갤럭시 / 공통 터치

- 기존 PC 입력 유지. 모바일에서는 Character 초기화 시 터치 UI 생성, 이전 단일 조이스틱 숨김.
- 왼쪽 이동, 오른쪽 조준/차지, DASH, USE, PAUSE, MAP.
- 일반 침은 기존 자동 발사 유지. 대물침은 조준 패드를 누르고 차지 후 떼어 발사.
- 함정 구속 중에만 상하좌우 탈출 버튼. 기존 구속 시 공격/대시 차단 유지.
- 이동+차지+대시 동시 터치의 포인터 소유권 분리. 일시정지/포커스 상실/앱 중단/비활성/씬 교체 때 눌림 상태 초기화.
- 포털·미니스테이지 귀환·미스터리 상자·보스 출구 USE 지원.
- 지도 열림 시 이동 입력 해제, 터치 닫기 버튼. 확대 지도 한 손가락 이동 / 두 손가락 간격으로 확대·축소.
- 모바일에서만 미니맵은 좌측 상단, 인벤토리 HUD는 우측 상단으로 옮겨 조이스틱과 겹침 방지. 기존 프리팹/PC 배치는 유지하고 모바일 조작 컴포넌트 종료 시 원래 배치 복원.
- safe area 및 화면 크기 변경 반영. 화면 PAUSE 버튼 제공. Escape 입력이 전달되면 모바일에서는 지도 닫기/일시정지로 처리하며, Android 시스템 뒤로 가기의 실제 전달 여부는 기기에서 확인해야 함.
- 입력 백엔드를 Input System 하나로 통일. 기존 Inspector KeyCode 값은 어댑터로 유지하고, 각 장면의 기존 EventSystem은 실행 시 UI 입력 모듈만 전환. Android에서 지원하지 않는 Both 설정을 제거.
- Galaxy 테스트 빌드: Android 8(API26)+, ARM64, IL2CPP, target API34, 가로 화면, Development APK, 기본 debug 서명.
- 테스트 package id: com.junanime.projectgc.galaxytest. 스토어 배포용 서명/타깃 정책과 별도.
- Unity 2022.3.62f3 Android Build Support/SDK/NDK/OpenJDK 설치 완료.
- iPhone: 공통 입력 소스 준비. Mac/Xcode/서명 환경이 없어 iOS 빌드·실기기 테스트 미수행.

- Android 최초 빌드에서 기존 ProjectGCMissingScriptScanner / ProjectGCSerializedFieldScanner의 MenuItem 코드가 플레이어 컴파일에 들어가 CS0246 발생. 두 검사 도구 전체를 UNITY_EDITOR로 보호하여 게임 빌드에서 제외. 첫 재빌드 성공(errors=0), 이후 입력 모듈 보완을 포함한 최종 빌드는 후속 갱신.
- 키보드 프레임 검사는 EditorApplication.update에서 실행하면 편집기 상태 버퍼를 읽어 실패. 실제 플레이 루프에서 수행하도록 수정; 편집 모드는 직렬화 키 매핑을 별도 검사.
- USB 실기기 미연결. 실제 기기 터치/프레임률/발열/장시간 생존/앱 전환 복귀는 아직 미검증.
- 원본 기획 전체에 대한 장시간 밸런스 검수 완료로 간주하지 않는다. 아이템 이관, 이전 버전 런 저장본 마이그레이션, iOS는 후속 범위.

## 갤럭시 설치 후 확인 순서

1. 테스트 APK를 휴대폰에 복사해 설치. 기존 배포 앱과 구분되는 galaxytest 패키지이며, 개발 테스트용 서명이다.
2. 메인 메뉴 → 새 런 시작 → 왼쪽 MOVE로 이동 → DASH. 오른쪽 AIM / CHARGE는 중침 차지용이며 일반 침은 기존 자동 발사 방향 규칙을 유지한다.
3. 레벨업 시 세 카드 중 선택하고 새로고침을 확인. 조작 버튼이 보상 창 위를 가리지 않아야 한다.
4. USE로 포털/상호작용, 함정에 묶이면 방향 버튼으로 탈출. MAP 열기/닫기와 한 손가락 이동·두 손가락 확대/축소 확인.
5. 일시정지·홈 화면 이동·복귀 후 이동/차지가 붙잡힌 상태로 남지 않는지 확인.
6. 10분 이상 플레이하며 프레임 저하·발열·메모리 종료 여부, 노치/내비게이션 영역의 버튼 가림을 확인. 기종·Android 버전과 함께 기록한다.
