# 첫 아이템 피드백 패치 (2026-10-18)

목표: 아이템이 언제 활약했는지 보이게 만들고, 완전히 같은 선택지를 줄인다. 가격·등급·상점 확률·기존 저장 ID는 유지한다.

## 변경 내용

| 대상 | 이전 | 이번 패치 |
|---|---|---|
| 바삭 연근칩 / 팡팡 구슬 | 같은 발사체 +1 효과를 별도 신규 선택지로 제공 | 신규 로비 해금·보급 후보는 팡팡 구슬로 대표. 이미 해금한 연근칩은 계속 표시·장착 가능. 연근칩 보유 런에서는 구슬을 중복 보급하지 않음 |
| 반향 옥구 (22) | 기본 침 넉백 +30% | 기존 효과 + 기본 침 적중 시 반경 1.5, 침 피해 40%, 밀치기 1.2의 반향. 내부 간격 3초. 보조 공격은 재발동하지 않음 |
| 새벽의 뜸 (31) | 마지막 게임 시간 1시간에만 효과 | 평상시 4초마다 반경 3에 침 피해 30%. 마지막 시간은 기존 1초·180% 유지 |
| 추적 향낭 (56) | 거리 2 이내 기본 침 피해 +25% | 같은 거리 조건에서 +35% |

66종 아이템 전체를 임의로 40종에 맞춰 제거하지 않는다. 발사 횟수·시간·연속 적중처럼 실제 조건이 다른 효과는 유지한다. 중복 유물 1종의 신규 노출부터 축소하는 제한된 첫 패치다. 카탈로그는 34개를 보존하고, 신규 계정의 로비 선택 목록은 33개다.

## 대표 연출 5종

1. 점혈 방울: 같은 적에 기본 침을 적중하면 4개 표식이 차며, 네 번째에 타격선과 `점혈!` 표시.
2. 뜸불 화로: 아이템 이미지 대신 실제 반경에 맞는 경계·불씨·불꽃. 종료 직전 흐려짐.
3. 백귀 향단: 아이템 카드 대신 눈과 꼬리가 있는 부적 영혼이 실제 추적 경로를 따라 이동.
4. 한열 쌍옥: 붉고 푸른 증기와 원형 팽창, `증기 폭발!` 표시. 죽염 결정이 먼저 감속을 소모했다면 같은 감속을 중복 소비하지 않음.
5. 다시 꽃봉오리: 실제 유물 부활이 소비된 경우, 이동 보정 후 플레이어 위치에서 꽃잎이 펼쳐짐. 다른 부활 효과에는 적용하지 않음.

반향 옥구의 새 공격에도 얇은 동심원 피드백을 추가한다. 추가 효과는 기존 공격 판정 경로를 사용한다.

## 구현·성능

- `ItemFeedback`은 연출만 담당한다. 풀이 가득 차도 공격·회복·영혼 이동 및 적중 판정은 계속된다.
- 플레이어별 최대 24개의 메시 연출을 재사용하며 희귀한 부활을 위한 공간을 둔다. 문구는 0.45초 간격으로 제한한다.
- 아이템 원본 이미지를 수정하거나 새 외부 아트를 추가하지 않는다. 절차적 메시로 형태를 구분한다.
- 일시정지 시 애니메이션도 멈춘다. 기존 효과 불투명도·동작 줄이기 설정을 반영한다. 사망·비활성화·씬 종료 시 연출을 정리한다.
- 풀의 대여 번호로 오래된 장판 정리가 재사용된 다른 효과를 끄지 않게 한다.
- 탄환 탐색용 배열 할당을 재사용 목록으로 바꾸고, 반추 두루마리를 보유할 때만 이동 경로를 기록한다.
- 카탈로그 에셋·생성기의 설명 원본·문서의 세 아이템 설명을 함께 갱신한다.
