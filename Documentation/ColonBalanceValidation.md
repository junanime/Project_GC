## 범위와 방법

- 아시·아리·혁이·신이 각각 스테이지 1과 2를 885초씩 실제 게임 속도로 자동 관찰했다. 이동·자동 공격·액티브·대쉬·상자·상점·증강 선택을 실행했다.
- 이 관찰은 무적 상태의 안정성·성장량 테스트다. 885초 시점에 전환 도우미로 대장에 진입했으므로 자연스러운 보스 클리어 기록이나 사람의 평균 클리어 빌드를 뜻하지 않는다. 실제 보스 격파→캡슐→대장 경로는 별도 회귀 검사로 확인했다.
- 경험치 조정 후에는 위장 관찰에서 저장한 네 진입 빌드를 복원해 대장 885초를 2배 시뮬레이션 속도로 다시 실행했다. 경로와 증강 후보의 난수는 서로 다르므로 완전히 통제된 짝 비교는 아니다.
- 자동 관찰은 미니스테이지 스킬 보상을 수집하지 않는다. 사람의 스킬 강화·이동 숙련도·선택 전략을 포함한 승률은 이번 수치에서 추정하지 않는다.

## 안정성·표현 검증

- 초기 배치 128개 난수 시드: 시드마다 상자24·상인12·혈전14·엘리트제단8·골드병20·실버병8, 합계86개. 실제 생성 위치와 벽 여유 거리도 확인했다.
- 1.5월드 단위 격자의 이동 가능 7,791칸은 하나의 연결영역이고 초기 배치 가능 4,648칸에 고립된 칸이 없다.
- 콘텐츠 검사 9,252개: 시간별 확률·종류 제한·크기·피격 범위·미니방 원복·콩 2→4 분열·3회 보호막·여러 혈전 입구 유지·미니방 귀환·실제 엘리트 보상.
- 캡슐 이동 및 스테이지 전환 검사70개. 보스 격파와 대장 탈출도 포함한다.
- 실제 Unity 화면 및 이동·분열 프레임을 촬영했다. 재사용 미역의 흰 사각형은 소멸 셰이더의 RGB/alpha 혼합을 수정하고 GPU 렌더링 검사로 확인했다.
- 승인된 일반·특수 외형14장은 원본과 파일 내용이 같다. 전용 팝콘·아기콩 아틀라스 포함 PNG15장 약1.70MB이며 투명도를 유지한다.
