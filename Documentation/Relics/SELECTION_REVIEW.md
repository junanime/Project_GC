# 유물 선택 이유와 정리 결과

> 이 문서는 제외 판단 당시의 기록입니다. 이후 수치·가격 변경은 [유물 밸런스 조정](BALANCE_PASS.md)을 기준으로 합니다.

현재 34종 데이터를 유지하며 신규 후보는 기존 33종에서 26종으로 줄인다. 새 제외 7종과 기존 제외 1종은 아래 표에 표시했다. 해금·장착 기록과 기존 효과는 보존한다. 로비와 보급 신규 후보에서 제외하며 능력치·가격은 변경하지 않는다.

판단 기준: 동일한 발동 조건과 계산식에서 수치만 낮은 변형은 전투 역할이 겹친다. 더 싼 영구 해금 가격은 초반 구매 이점이지만 별도 전투 역할은 아니므로 이번 정리에서 제외했다. 완전히 같은 구슬·연근칩 외에는 저장 ID를 합치지 않으며, 하위 유물을 가진 상태에서도 상위 유물을 보급으로 얻을 수 있다.

## 캐릭터 기준 추가 판단과 관찰 대상

- 튼튼 하트 +20과 홍삼젤리 기본 체력 +25%는 기본 체력 80에서 같아진다. 현재 출전 캐릭터는 모두 기본 체력 100이므로 +25인 젤리가 +20 하트를 대체한다. 하트는 신규 제외했다. 기본 체력 80 미만 캐릭터가 도입되면 재검토한다.
- 산들 날개는 +0.2이며 +0.08은 생강 절편 아이템 수치다. 귤조각은 기본 이동 속도 +12%로, 기본 속도 약 1.667에서 날개와 같아진다. 현재 출전 캐릭터는 모두 기본 이동 속도 1.15로, 귤조각 +0.138보다 날개 +0.2가 높아 귤조각을 신규 제외했다. 기본 속도 1.667 초과 캐릭터 도입 시 재검토한다.
- 자석은 위험한 보상 회수, 주머니는 리롤을 포함한 골드 확보, 약저울은 구매 비용 절약 역할이다. 단순 능력치라는 이유만으로 제외하지 않는다.
- 밤송이의 피격 반격, 깃털의 확률 회피, 베개의 정지 회복은 독자적인 역할이 있으나 실제 선택 가치가 충분하다는 뜻은 아니다. 자연 플레이에서 효용을 확인한다.
- 구슬·침통·부활처럼 효과가 큰 유물은 다른 유물과의 격차 확인이 필요하다. 이번 작업은 선택 이유와 중복 정리이며, 모든 유물의 균형을 입증한 결과는 아니다.

변경은 codex/item-feedback-patch1 및 PR #1에 누적한다. hyeon에는 직접 병합하지 않는다.

검증: Unity 2022.3.62f3 EditMode 97개 중 91개 통과. 수정 전 hyeon과 동일한 6개 실패 외 신규 실패 없음. Play Mode에서 전체 34종 선택 이유를 표시하고 설명 영역 넘침 검사를 통과했다. 기존 해금·장착 보존 및 신규 후보 26종, 모든 제외 항목의 대체 유물을 검사했다.
