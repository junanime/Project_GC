# 승인된 증강 연출 교체 — 2026-11-03

대상은 봉명진혼, 천공봉침(대물침), 봉인흡진, 목침 회복 장판, 봉황파동이다. 아이템·유물 연출은 이번 변경에 포함하지 않는다.

## 동작

- 봉명진혼: 화면 상단 모래시계와 옅은 시간 정지 효과. 실제 정지 종료 시각에 맞춰 모래가 줄어든다. 정지 중 새로 등장한 몬스터도 기존 규칙대로 정지한다. 다른 아이템이 사용하는 개별 기절 표시는 유지한다.
- 천공봉침: 발사 지점에 일곱 깃털이 퍼졌다 사라지고 발사체는 그대로 진행한다. 충전량을 비행 연출에도 전달한다. 충돌·피해·비행 속도는 바꾸지 않는다.
- 봉인흡진: 청록·보라 나선이 중앙으로 흐르고 금색 깃털과 압착 잔광을 더한다. 끝날 때 축소·소멸한다. 기존 흡입과 주기 피해는 그대로다.
- 목침 회복 장판: 옅은 초록 바닥빛, 잎맥, 일곱 새싹과 떠오르는 잎으로 표시한다. 회복 반경·회복량·주기는 그대로다. 빙결침 장판은 변경하지 않는다.
- 봉황파동: 기존 봉황 소환과 황금 링을 무지개 날개 전개·날갯짓·분리된 바람결로 바꾼다. 0.32초 전개 후 기존 피해 파동을 발사한다. 바람은 화면의 가장 먼 모서리까지 진행한 다음 잦아든다. 화면 비율과 카메라 위치에 맞춰 도달 거리를 계산한다. 기존 피해 반경 바깥의 바람은 시각 효과이며 추가 피해나 충돌체를 만들지 않는다.

## 설정과 자원

- 증강 효과 투명도와 움직임 감소 설정을 적용한다.
- 일시정지 때 애니메이션 진행도 함께 멈춘다.
- 종료·사망·비활성화 시 시각 오브젝트를 정리한다.
- 기존 무지개 깃털·날개 텍스처를 재사용한다. 새 대형 이미지나 동영상은 빌드에 추가하지 않는다.
