## 공통 규칙
- 초과 회복은 최대 체력의 25%, 연속 처치 피해는 30%, 같은 적 종류 저항은 20% 상한. 불장판은 동시에 3개까지.
- 보조 침은 추가 발사/회복/처치 장판 발동을 다시 생성하지 않는다. 상태 피해는 직접 피해 취약을 재적용하지 않는다.
- 밤/정각/마지막 한 시간 효과는 해당 스테이지 전체 길이를 24시간으로 환산한다. 혈전에서는 본 스테이지 시간이 정지한다.
- 샷건침·대물침·이기어침의 기본 침 적중에도 아이템 피해/적중 효과를 연결. 상태 감속 증폭은 꿀/빙결침에도 적용하되 최대 70% 감속.
- 씬 전환 스냅샷은 아이템 보유, 대기 경험치, 초과 회복, 처치·적중 카운터, 저항 기억, 재사용 대기/충전 상태를 보존. 디스크 런 이어하기를 새로 도입한 것은 아니다.
- 기존 고귀 11종과 특수 침 수치 테이블은 유지. 아이템 수치는 `OctoberItemBalance.cs`, 실제 효과는 `OctoberItemRuntime.cs`가 기준.
