24시간의 사투 — 출전 로딩 / 혈전 모션 크기 수정 (2026-10-06)

기획 및 적용 범위
- 출전준비의 출전하기 버튼 → 실제 Level 1 비동기 로딩 → 플레이 시작에 적용.
- 현재 공유 중인 웹 빌드, 기존 설치본은 교체하지 않음. 새 빌드 시 포함됨.
- 반복 미니스테이지 혈전 다이빙 / 배출과 캐릭터 뒷모습 로딩은 서로 별개 연출.

혈전 크기 수정
- 원인: 원본은 투명 여백을 포함하는 셀인데 여행 스프라이트는 외형에 맞게 잘라져 있음.
  Renderer.bounds 높이를 여행 이미지에 맞추면 원래 몸보다 과대 확대됨.
- 캐릭터별 첫 대기 이미지의 알파 외형을 VisibleBodyGeometry에 베이크.
  실제 몸 높이 / 기존 사각형 높이: 아시 0.623, 아리 0.631, 혁이 0.715, 신이 0.795.
- 해당 대기 외형 + 현재 캐릭터 Transform 배율을 기준으로 여정 시작 때 한 번 보정.
  프레임마다 높이를 다시 맞추지 않아 수축/늘어남/무릎 굽힘/공중 회전은 보존.
- 혁이의 웅크린 고정 자세는 실제 서 있는 몸 높이의 72%. 도약 전 걷기와 두 번 튕김 유지.
- 공통 다이빙/배출 1.8초, 발 위치, 마지막 자세 유지 및 이동 입력 복귀 유지.

로딩 디자인
- 시작 화면과 같은 부드러운 분홍/산호색 픽셀 통로. 실사 조직, 핏줄, 과한 약재 장식 제외.
- 선택 캐릭터 혁이/신이/아리/아시 각각 등 보이는 달리기 8프레임.
  동일한 프레임 크기와 바닥 기준점으로 화면상 크기 흔들림 최소화.
- 실제 씬의 세균/슬라임 애니메이션을 참조하여 벽 틈에 3마리 배치.
- 짙은 민트 패널, 크림색 글자, 금색 가장자리, 민트 게이지와 침 모양 포인터.
  설명과 수치는 실시간 UI로 표시하며 배경에 글자를 합성하지 않음.
- 화면 비율이 달라도 1280x720 디자인을 유지하면서 전체 화면에 맞춰 여백 처리.

로딩 동작
- 장면 데이터를 비동기로 읽는 진행도 0~0.9를 화면상 0~94%로 대응.
- 로딩 목표 진행도를 넘지 않는 부드러운 게이지 이동. 캐릭터 이동/축소가 같은 진행도를 사용.
- 데이터 준비가 완료되면 마지막 6%에서 통로 끝으로 달려가며 투명해짐.
- 캐릭터가 완전히 사라진 다음 장면 활성화. 활성화 순간 게임 시간을 멈춰 로딩 뒤에서 전투가 먼저 시작되는 것을 방지.
- 장면 초기화 후 로딩 UI와 로딩 소유 일시정지 해제. 중복 출전/로딩 중 메뉴 입력 방지.
- 움직임 줄이기 설정에서는 달리기 프레임/바운스/장식 흔들림 제거, 진행도는 계속 표시.
