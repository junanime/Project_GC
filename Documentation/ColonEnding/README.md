# 스테이지 2 봉인 출구 · 지스타 데모

2026-11-14 사용자 확정 디자인을 실제 게임에 적용한 변경이다. 2026-11-13 기록의 ‘변비왕 처치 직후 자동 복귀’를 이 흐름으로 대체한다.

## 플레이 흐름

1. 대장 진입 때 좌측 하단 출구를 C 굳은 봉인석 자물쇠와 금 체인이 봉인한다. 보스가 살아 있으면 상호작용해도 열리지 않는다.
2. 변비왕은 휴지 장식 금 열쇠 지팡이를 들고 전투한다. 최종 처치 시 손의 지팡이가 떨어지고, 처치 연출이 끝나면 주울 수 있다.
3. 가까이 가서 상호작용하면 지팡이를 머리 위로 번쩍 든다. 이동해도 열쇠와 들어 올린 팔이 캐릭터를 따라간다.
4. 열쇠를 든 채 봉인 앞에서 상호작용하면 열쇠를 구멍에 꽂아 돌리고 자물쇠가 갈라지며 금 체인이 떨어진다. 이후 벽 안쪽 막이 열려 통로를 드러낸다.
5. 열린 출구에 다시 상호작용하면 ‘데모 버전은 여기까지입니다!’ 안내창을 보여 준다. ‘출전준비로 돌아가기’를 확인하면 성공과 재화를 한 번 저장하고 출전준비로 복귀한다.

상호작용은 기존 공통 입력·가까운 오브젝트 선택 체계를 사용한다. 컷씬 도중 전투를 정지하고, 안내창에서는 뒤쪽 메뉴 입력을 막는다. 열쇠 없이 옛 완료 호출로 승리하는 경로도 차단한다.

## 디자인 보존 범위

- D안의 밝은 윗면, 분홍 옆면, 접지 그림자를 부드러운 원래 대장 색감에 맞췄다.
- 출입구를 별도 원판 대신 장벽과 이어진 어깨·안쪽 통로·다섯 조각 막으로 표현한다.
- 기존 바닥의 물결·입자·색상 계산은 그대로 유지한다. 맵 지형과 충돌, 배치는 변경하지 않는다.
- 스테이지 1의 공용 출입구 셰이더는 변경하지 않는다.
- 자물쇠/열쇠 PNG와 프롬프트는 이 기록과 함께 보존한다. 원래 변비왕 15개 PNG 바이트는 보존하며 지팡이를 별도 표시 레이어로 연결한다.
